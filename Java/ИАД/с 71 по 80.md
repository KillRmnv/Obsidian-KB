## 71. Понятие искусственного нейрона и искусственной нейронной сети

Искусственный нейрон — упрощённая математическая модель биологического нейрона, представляющая собой вычислительную единицу, которая принимает несколько входных сигналов, преобразует их и выдаёт один выходной сигнал. Формально нейрон вычисляет взвешенную сумму входов **z = Σ wᵢ·xᵢ + b**, к которой применяется функция активации φ(z), дающая выходное значение y = φ(z). Здесь xᵢ — входы, wᵢ — синаптические веса (степень влияния каждого входа), b — смещение (bias), φ — нелинейная функция. Веса и смещение — настраиваемые параметры, изменяющиеся в процессе обучения. Искусственная нейронная сеть (ИНС, ANN) — совокупность связанных между собой искусственных нейронов, объединённых в слои, способная аппроксимировать сложные функции и решать задачи классификации, регрессии, кластеризации, генерации данных. Стандартная архитектура включает входной слой (получает признаки), один или несколько скрытых слоёв (выполняют преобразование) и выходной слой (формирует ответ). Глубокие нейронные сети (deep learning) — сети с большим числом скрытых слоёв, способные автоматически извлекать иерархические признаки из сырых данных. Знания в сети распределены по весам соединений, и обучение сводится к их настройке для минимизации ошибки.

## 72. История нейронных сетей. Основные успехи и недостатки

История ИНС насчитывает несколько волн интереса и «зим». 1943 — модель нейрона МакКаллока-Питтса, первая математическая формализация. 1958 — персептрон Розенблатта, первый обучаемый алгоритм. 1969 — книга Минского и Пейперта «Перцептроны» показала ограничения однослойного персептрона (неспособность решать XOR), что привело к первой «зиме ИИ». 1986 — Румельхарт, Хинтон, Уильямс — алгоритм обратного распространения ошибки (backpropagation), открывший практическое обучение многослойных сетей. 1990-е — успехи в распознавании рукописных цифр (LeCun, LeNet), но затем вторая «зима» из-за нехватки данных и мощностей. 2006 — Хинтон вводит «глубокое обучение» (deep belief networks), начало нового подъёма. 2012 — AlexNet (Крижевский, Хинтон) выиграл ImageNet с огромным отрывом, революция в компьютерном зрении. Далее последовали успехи в распознавании речи (DeepSpeech), машинном переводе (Seq2Seq, Transformer 2017), играх (AlphaGo 2016), генеративных моделях (GAN, VAE, диффузионные модели), больших языковых моделях (GPT, BERT, ChatGPT 2022). Успехи: state-of-the-art в зрении, речи, языке, генерации контента, играх. Недостатки: огромная потребность в данных и вычислениях, низкая интерпретируемость («чёрный ящик»), уязвимость к атакам (adversarial examples), плохая обобщающая способность вне распределения, высокое энергопотребление, риск галлюцинаций в LLM.

## 73. Искусственная модель нейрона

Стандартная искусственная модель нейрона (McCulloch & Pitts, 1943, в современной форме) — вычислительный элемент с n входами и одним выходом. Этапы работы: 1) на вход подаются значения x₁, x₂, …, xₙ; 2) каждому входу соответствует синаптический вес wᵢ, отражающий силу связи; 3) вычисляется взвешенная сумма (линейная комбинация): **z = Σᵢ wᵢ·xᵢ + b**, где b — смещение (порог со знаком минус); 4) к z применяется функция активации φ, обычно нелинейная: y = φ(z). Веса и смещение — обучаемые параметры. Геометрически нейрон с пороговой активацией реализует разделяющую гиперплоскость в признаковом пространстве: положительные и отрицательные значения z соответствуют разным сторонам плоскости. Функция активации обеспечивает нелинейность, без которой сеть из любого числа слоёв сводилась бы к одной линейной модели. Различные типы нейронов отличаются функцией активации: пороговый нейрон МакКаллока-Питтса (step function), сигмоидальный, ReLU-нейрон, tanh-нейрон. Несмотря на простоту, ансамбли таких нейронов в многослойных архитектурах способны аппроксимировать произвольные непрерывные функции (теорема универсальной аппроксимации Цыбенко, 1989).

## 74. Однослойный персептрон Розенблатта

Однослойный персептрон Розенблатта — первая обучаемая модель искусственной нейронной сети, предложенная Фрэнком Розенблаттом в 1957–1958 годах; реализация была воплощена в виде физического устройства «Mark I Perceptron» для распознавания изображений. Архитектура: входной слой признаков x₁, …, xₙ напрямую соединён с одним выходным нейроном через настраиваемые веса w₁, …, wₙ; нейрон вычисляет z = Σwᵢxᵢ + b и применяет пороговую функцию активации (sign или step), выдавая бинарный ответ (+1 или −1 / 0 или 1). Геометрически персептрон строит линейную разделяющую гиперплоскость в признаковом пространстве, реализуя бинарную классификацию. Правило обучения персептрона: для каждого неверно классифицированного объекта веса корректируются по формуле **wᵢ ← wᵢ + η·(y − ŷ)·xᵢ**, где y — истинная метка, ŷ — предсказание, η — скорость обучения. Главное ограничение, показанное Минским и Пейпертом в 1969 году: персептрон способен решать только линейно разделимые задачи и не справляется с простейшей нелинейной задачей XOR. Это открытие на десятилетие практически остановило развитие нейронных сетей до изобретения алгоритма обратного распространения ошибки. Тем не менее, персептрон стал концептуальной основой для всех современных нейронных сетей.

## 75. Теоремы об обучении персептрона

Главный теоретический результат — теорема о сходимости персептрона (Perceptron Convergence Theorem), доказанная Розенблаттом и формализованная Новиковым в 1962 году. Формулировка: если обучающая выборка линейно разделима (то есть существует гиперплоскость, идеально разделяющая классы), то алгоритм обучения персептрона за конечное число итераций найдёт такую разделяющую гиперплоскость, независимо от начальных значений весов. Более того, верхняя граница числа итераций до сходимости составляет **(R/γ)²**, где R — максимальный радиус векторов признаков, γ — отступ (margin) — минимальное расстояние от объектов до оптимальной разделяющей гиперплоскости. Чем больше отступ между классами, тем быстрее сходится алгоритм. Обратное следствие — теорема о неразделимости: если выборка не является линейно разделимой, то алгоритм не сходится, веса осциллируют, и идеального разделения достичь невозможно. Это формальное доказательство ограниченности однослойного персептрона. Для нелинейно разделимых задач требуется либо переход в более высокоразмерное пространство признаков (kernel trick в SVM), либо переход к многослойным архитектурам с нелинейными функциями активации. Теорема сходимости имеет фундаментальное значение, поскольку гарантирует обучаемость в линейном случае и тем самым обосновывает применимость градиентных методов в обучении нейронных сетей.

## 76. Многослойный персептрон (MLP)

Многослойный персептрон (MLP, Multi-Layer Perceptron) — нейронная сеть прямого распространения (feedforward), состоящая из последовательности слоёв нейронов: входного слоя, одного или нескольких скрытых слоёв и выходного слоя. Каждый нейрон каждого слоя соединён со всеми нейронами следующего (полносвязная архитектура), сигнал распространяется только в одном направлении — от входа к выходу, без обратных связей и циклов. Ключевое отличие от однослойного персептрона — наличие скрытых слоёв с нелинейными функциями активации (сигмоида, tanh, ReLU), что позволяет сети моделировать сложные нелинейные зависимости и решать линейно неразделимые задачи (в том числе XOR). Теоретическое обоснование — теорема универсальной аппроксимации (Цыбенко, 1989; Хорник, 1991): MLP с одним скрытым слоем, достаточным числом нейронов и нелинейной функцией активации способен аппроксимировать любую непрерывную функцию на компактном множестве с произвольной точностью. На практике глубокие сети (с многими слоями) эффективнее широких, так как иерархически выделяют признаки разной степени абстракции. Обучение MLP осуществляется методом обратного распространения ошибки (backpropagation, Румельхарт-Хинтон-Уильямс, 1986) совместно с градиентным спуском или его вариантами (SGD, Adam, RMSprop). MLP применяется в задачах классификации, регрессии, аппроксимации функций, является базовой архитектурой современного глубокого обучения и компонентом более сложных сетей (CNN, Transformer).

## 77. Понятие функции активации. Виды функций активации

Функция активации — нелинейное преобразование, применяемое к взвешенной сумме входов нейрона, преобразующее z = Σwᵢxᵢ + b в выходное значение y = φ(z). Главное назначение — внесение нелинейности в модель: без неё многослойная сеть математически сводилась бы к одному линейному преобразованию независимо от числа слоёв, что лишает смысла построение глубоких архитектур. Функция активации также определяет диапазон выходных значений и свойства градиента, влияющие на обучаемость. Основные виды функций активации. 1) Пороговая (step function): φ(z) = 1 при z ≥ 0, иначе 0; используется в исходном персептроне, не дифференцируема — непригодна для обратного распространения. 2) Сигмоида (логистическая): **φ(z) = 1/(1 + e⁻ᶻ)**, диапазон (0, 1), гладкая, дифференцируемая, исторически популярна; недостатки — насыщение и затухание градиента в краях (vanishing gradient), несимметричность относительно нуля. 3) Гиперболический тангенс (tanh): φ(z) = (eᶻ − e⁻ᶻ)/(eᶻ + e⁻ᶻ), диапазон (−1, 1), симметрична, но также страдает от насыщения. 4) ReLU (Rectified Linear Unit): **φ(z) = max(0, z)**, современный стандарт, простая, не насыщается при положительных z, ускоряет сходимость; недостаток — «умирающие» нейроны (dying ReLU) при отрицательных z. 5) Leaky ReLU: φ(z) = max(αz, z) с малым α (0,01), решает проблему «умирающих» нейронов. 6) ELU, SELU, GELU, Swish, Mish — современные гладкие варианты, применяются в архитектурах вроде BERT и GPT. 7) Softmax — для выходного слоя многоклассовой классификации: **softmax(zᵢ) = eᶻⁱ / Σⱼ eᶻⱼ**, возвращает распределение вероятностей по K классам. Выбор функции активации: ReLU и её варианты для скрытых слоёв, sigmoid для бинарной классификации на выходе, softmax для многоклассовой, линейная для регрессии.

## 78. Обучение (настройка) нейронной сети

Обучение нейронной сети — процесс настройки её параметров (весов wᵢ и смещений b) для минимизации функции потерь на обучающей выборке, то есть для того чтобы предсказания сети максимально соответствовали истинным значениям. Это задача оптимизации в многомерном пространстве параметров, решаемая итерационно. Основной алгоритм — градиентный спуск (gradient descent): на каждом шаге параметры корректируются в направлении, противоположном градиенту функции потерь: **w ← w − η·∂L/∂w**, где η — скорость обучения (learning rate), L — функция потерь. Для эффективного вычисления градиентов в многослойной сети применяется алгоритм обратного распространения ошибки (backpropagation, 1986): сначала прямой проход — вычисление выходов сети для входных данных; затем сравнение с истинными значениями и расчёт ошибки на выходном слое; далее обратное распространение ошибки от выходного слоя к входному с применением цепного правила дифференцирования для вычисления градиентов по всем весам; наконец, обновление весов. Варианты градиентного спуска: batch gradient descent — использование всей обучающей выборки на каждом шаге (медленно для больших данных); stochastic gradient descent (SGD) — обновление по одному объекту (быстро, но шумно); mini-batch gradient descent — компромисс с группами по 32–512 объектов (стандартный подход). Современные оптимизаторы с адаптивной скоростью обучения: Momentum, Nesterov, AdaGrad, RMSprop, Adam (стандарт по умолчанию), AdamW. Процесс обучения происходит в течение нескольких эпох (проходов по всей обучающей выборке) до достижения сходимости. Контроль за переобучением: разделение на обучающую/валидационную/тестовую выборки, ранняя остановка (early stopping), регуляризация (L1, L2, dropout, batch normalization).

## 79. Основные типы правил обучения

Правила обучения нейронных сетей классифицируются по характеру использования данных и обратной связи. 1) Обучение с учителем (supervised learning) — наиболее распространённый тип; используется размеченная выборка с парами (x, y), и сеть обучается минимизировать ошибку между предсказаниями и истинными метками. Правило Розенблатта (правило персептрона): wᵢ ← wᵢ + η·(y − ŷ)·xᵢ — коррекция весов пропорционально ошибке. Дельта-правило (Видроу-Хоффа, LMS): обобщение Розенблатта на непрерывные функции активации, минимизация квадратичной ошибки. Правило обратного распространения ошибки (backpropagation) — обобщение дельта-правила на многослойные сети. 2) Обучение без учителя (unsupervised learning) — без меток, сеть самостоятельно выявляет структуру в данных. Правило Хебба (1949): «нейроны, активирующиеся вместе, связываются вместе»: wᵢⱼ ← wᵢⱼ + η·xᵢ·xⱼ — усиление связи между совместно активными нейронами; биологически правдоподобный принцип, лежащий в основе многих ассоциативных моделей. Конкурентное обучение (competitive learning) — нейроны соревнуются за «право» представить входной вектор; обновляется только победивший («winner-takes-all»); основа самоорганизующихся карт Кохонена (SOM). 3) Обучение с подкреплением (reinforcement learning) — агент учится через взаимодействие со средой, получая вознаграждение или штраф за действия; правила обновления основаны на сигналах вознаграждения (Q-learning, policy gradient, actor-critic, в том числе с использованием нейронных сетей — DQN, A3C, PPO). 4) Полу-обучение с учителем (semi-supervised) и обучение с самообучением (self-supervised) — гибридные подходы, использующие частично размеченные данные или формирующие задачи разметки автоматически. Современные большие модели (BERT, GPT) обучаются преимущественно по самообучающимся правилам на огромных корпусах неразмеченного текста.

## 80. Функции потерь и стоимости

Функция потерь (loss function) — мера расхождения между предсказанием модели и истинным значением для одного объекта; функция стоимости (cost function) — усреднённая функция потерь по всей обучающей выборке (J = (1/n)·ΣL), которая минимизируется в процессе обучения. Корректный выбор функции потерь критически важен — она должна соответствовать характеру задачи и желаемым свойствам решения. Функции потерь для регрессии. 1) MSE (Mean Squared Error, среднеквадратичная ошибка): **L = (y − ŷ)²**; стандартная функция потерь, штрафует большие ошибки сильнее, гладкая и дифференцируемая, удобна для градиентных методов; чувствительна к выбросам. 2) MAE (Mean Absolute Error): L = |y − ŷ|; устойчива к выбросам, но недифференцируема в нуле. 3) Huber loss: гибрид MSE и MAE — квадратичная при малых ошибках и линейная при больших; компромисс между чувствительностью и устойчивостью. 4) Log-cosh, quantile loss — для специальных задач. Функции потерь для классификации. 1) Binary Cross-Entropy (логистическая потеря, log-loss) для бинарной классификации: **L = −[y·log(ŷ) + (1−y)·log(1−ŷ)]**; используется с сигмоидой на выходе. 2) Categorical Cross-Entropy для многоклассовой классификации: **L = −Σ yᵢ·log(ŷᵢ)**; используется с softmax на выходе; основана на принципе максимального правдоподобия. 3) Sparse Categorical Cross-Entropy — оптимизация для случаев, когда метки представлены целыми числами, а не one-hot. 4) Hinge loss: L = max(0, 1 − y·ŷ); используется в SVM. 5) Focal loss — модификация cross-entropy для задач с сильным дисбалансом классов. Специализированные функции потерь. 1) KL-дивергенция — мера расхождения распределений, применяется в вариационных автоэнкодерах. 2) Triplet loss, contrastive loss — для задач метрического обучения и эмбеддингов. 3) IoU loss, Dice loss — для семантической сегментации изображений. 4) CTC loss — для распознавания речи и рукописного текста. Регуляризация добавляется к функции потерь для контроля переобучения: L1 (Lasso) — λ·Σ|wᵢ|; L2 (Ridge) — λ·Σwᵢ²; elastic net — комбинация. Выбор функции потерь — один из ключевых архитектурных шагов; неподходящая функция (например, MSE для классификации) может привести к плохой сходимости и низкому качеству модели.

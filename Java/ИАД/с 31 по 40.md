## 31. Модели ARIMA(p,d,q), ARIMAX(p,d,q)

ARIMA (AutoRegressive Integrated Moving Average) — обобщённая модель Бокса-Дженкинса для прогнозирования нестационарных временных рядов, объединяющая авторегрессию (AR), интегрирование (I) и скользящее среднее (MA). Параметры модели: p — порядок авторегрессии (число лагов yₜ), d — порядок интегрирования (число последовательных дифференцирований для приведения ряда к стационарности), q — порядок скользящего среднего (число лагов ошибки). Общая идея: исходный нестационарный ряд преобразуется в стационарный с помощью d-кратного взятия разностей Δyₜ = yₜ − yₜ₋₁, после чего к преобразованному ряду применяется модель ARMA(p,q). Формула в операторной записи: **(1 − Σφᵢ Lⁱ)(1 − L)ᵈ yₜ = c + (1 + Σθⱼ Lʲ)εₜ**, где L — оператор сдвига. Этапы построения модели (методология Бокса-Дженкинса): 1) проверка стационарности (тест Дики-Фуллера ADF, KPSS), при необходимости — дифференцирование для определения d; 2) идентификация порядков p и q по графикам ACF и PACF; 3) оценка параметров методом максимального правдоподобия; 4) диагностика остатков (тест Льюнга-Бокса на отсутствие автокорреляции); 5) прогнозирование с расчётом доверительных интервалов. Выбор оптимальных p, d, q обычно осуществляется по информационным критериям AIC, BIC. Расширения модели: SARIMA(p,d,q)(P,D,Q)ₘ — добавляет сезонные компоненты с периодом m; ARIMAX(p,d,q) — включает экзогенные (внешние) объясняющие переменные X, влияющие на ряд (например, цены конкурентов, погодные условия при прогнозировании продаж). Преимущества ARIMA: статистически обоснованная модель, подходит для широкого класса рядов, даёт интервальные прогнозы. Недостатки: требует стационарности после дифференцирования, чувствительна к выбору порядков, плохо работает на длинных горизонтах, не учитывает нелинейности.

## 32. Модель экспоненциального сглаживания

Простое (одинарное) экспоненциальное сглаживание (Simple Exponential Smoothing, SES) — метод прогнозирования временных рядов без выраженного тренда и сезонности, в котором сглаженное значение представляет собой взвешенную сумму всех прошлых наблюдений с экспоненциально убывающими весами. Основная формула рекуррентного вида: **Sₜ = α·yₜ + (1 − α)·Sₜ₋₁**, где Sₜ — сглаженное значение в момент t, yₜ — фактическое наблюдение, α — параметр сглаживания (0 < α < 1). Прогноз на любой горизонт вперёд равен последнему сглаженному значению: ŷₜ₊ₕ = Sₜ. Раскрытие рекуррентной формулы показывает, что каждое прошлое наблюдение учитывается с весом α(1−α)ᵏ, то есть веса убывают по геометрической прогрессии — более свежие данные влияют сильнее. Параметр α определяет «скорость забывания»: при α близком к 1 модель быстро реагирует на изменения, опираясь почти только на последние наблюдения (низкое сглаживание); при α близком к 0 модель инертна, сильно сглаживает, медленно реагирует на изменения уровня. Оптимальное значение α подбирается путём минимизации MSE (или другой метрики ошибки) на исторических данных. Инициализация: S₁ обычно полагается равным y₁ или среднему по первым нескольким значениям. Преимущества: простота вычислений, малое число параметров, малая потребность в данных, легко реализуется в реальном времени. Недостатки: не учитывает тренд (плохо прогнозирует растущие/убывающие ряды), не учитывает сезонность, прогноз на любой горизонт — константа. Для устранения этих ограничений разработаны расширения: модель Хольта (с трендом) и Хольта-Уинтерса (с трендом и сезонностью). Простое экспоненциальное сглаживание широко применяется в управлении запасами и оперативном прогнозировании.

## 33. Модель Хольта (двойное экспоненциальное сглаживание)

Модель Хольта (Holt's Linear Trend Method) — расширение простого экспоненциального сглаживания для прогнозирования временных рядов с трендом, но без сезонности. Также называется двойным экспоненциальным сглаживанием, так как использует два уравнения сглаживания: одно для уровня ряда, другое для тренда. Уравнения модели: **уровень Lₜ = α·yₜ + (1 − α)·(Lₜ₋₁ + Tₜ₋₁)**, **тренд Tₜ = β·(Lₜ − Lₜ₋₁) + (1 − β)·Tₜ₋₁**, где Lₜ — оценка текущего уровня, Tₜ — оценка текущего тренда (среднего прироста за период), α и β — параметры сглаживания (0 < α, β < 1). Формула прогноза на h периодов вперёд: ŷₜ₊ₕ = Lₜ + h·Tₜ — прогноз представляет прямую линию с наклоном, равным текущей оценке тренда. Содержательно: уровень обновляется как взвешенная сумма нового наблюдения и предсказания (прошлый уровень плюс тренд), тренд обновляется как взвешенная сумма свежей оценки наклона (разность уровней) и прошлой оценки тренда. Параметр α управляет скоростью реакции уровня на изменения, β — устойчивостью оценки тренда. Инициализация: L₁ = y₁, T₁ = y₂ − y₁ (или среднее приращение по первым нескольким точкам). Параметры α и β подбираются оптимизацией ошибки прогноза (минимизация MSE). Недостаток базовой модели Хольта — линейный тренд экстраполируется бесконечно, что нереалистично на длинных горизонтах. Для исправления применяется модификация с затухающим трендом (damped trend method) с дополнительным параметром φ (0 < φ < 1), при котором рост постепенно замедляется. Применяется для прогнозирования продаж, спроса и других показателей с устойчивым трендом без выраженной сезонности.

## 34. Модель Хольта-Уинтерса (тройное экспоненциальное сглаживание)

Модель Хольта-Уинтерса (Holt-Winters Method) — обобщение модели Хольта на временные ряды с трендом и сезонностью; называется также тройным экспоненциальным сглаживанием, так как использует три уравнения: для уровня, тренда и сезонной компоненты. Существуют две версии модели в зависимости от характера сезонности. Аддитивная модель (применяется при постоянной амплитуде сезонных колебаний): уровень Lₜ = α·(yₜ − Sₜ₋ₘ) + (1 − α)·(Lₜ₋₁ + Tₜ₋₁); тренд Tₜ = β·(Lₜ − Lₜ₋₁) + (1 − β)·Tₜ₋₁; сезонность Sₜ = γ·(yₜ − Lₜ) + (1 − γ)·Sₜ₋ₘ; прогноз: **ŷₜ₊ₕ = Lₜ + h·Tₜ + Sₜ₊ₕ₋ₘ**. Мультипликативная модель (применяется при росте амплитуды сезонности пропорционально уровню ряда): уровень Lₜ = α·(yₜ / Sₜ₋ₘ) + (1 − α)·(Lₜ₋₁ + Tₜ₋₁); тренд аналогично; сезонность Sₜ = γ·(yₜ / Lₜ) + (1 − γ)·Sₜ₋ₘ; прогноз: ŷₜ₊ₕ = (Lₜ + h·Tₜ)·Sₜ₊ₕ₋ₘ. Здесь m — период сезонности (12 для месячных данных с годовой сезонностью, 4 для квартальных, 7 для недельных), α, β, γ — параметры сглаживания (0 < α, β, γ < 1). Параметры оптимизируются минимизацией ошибки прогноза. Инициализация требует данных хотя бы за один-два полных сезонных цикла для оценки начальных сезонных коэффициентов. Преимущества: учитывает все три компоненты ряда (уровень, тренд, сезонность), интуитивно понятна, хорошо работает на относительно коротких рядах, низкая вычислительная сложность. Недостатки: не учитывает экзогенные факторы, плохо реагирует на структурные сдвиги, требует данных за несколько сезонных циклов. Модель Хольта-Уинтерса входит в семейство ETS-моделей (Error-Trend-Seasonality) и активно применяется в розничной торговле, энергетике, туризме.

## 35. Общие проблемы методов классического прогнозирования

Классические методы прогнозирования (регрессия, ARIMA, экспоненциальное сглаживание) обладают рядом общих ограничений и проблем, которые могут существенно снижать точность и надёжность прогнозов. 1) Гипотеза инерционности — все классические методы предполагают сохранение в будущем тех же закономерностей, что наблюдались в прошлом, что нарушается при структурных сдвигах, кризисах, изменении внешних условий (пандемия COVID-19 — классический пример). 2) Чувствительность к качеству данных — пропуски, выбросы, ошибки измерений могут существенно искажать оценки параметров моделей и прогноз. 3) Линейность — большинство моделей предполагают линейные связи, что плохо описывает реальные нелинейные процессы, пороговые эффекты, насыщение. 4) Проблема стационарности — модели ARIMA требуют стационарности, что часто требует преобразований и не всегда полностью достигается. 5) Узкое использование информации — модели временных рядов опираются только на историю самой переменной, игнорируя внешние факторы (за исключением ARIMAX). 6) Снижение точности с увеличением горизонта прогноза — доверительные интервалы быстро расширяются, прогноз становится практически бесполезным на длинных горизонтах. 7) Сложность работы с короткими рядами и редкими событиями — методы требуют достаточного количества наблюдений. 8) Чувствительность к выбору параметров (порядки p, d, q в ARIMA; параметры α, β, γ в экспоненциальном сглаживании; число лагов в регрессии) — требуется экспертный подбор. 9) Слабая работа с категориальными признаками и неструктурированными данными (текст, изображения). 10) Сложность учёта неопределённости и редких сценариев. 11) Проблема переобучения — особенно при большом числе параметров и малых выборках. 12) Игнорирование вариативности на уровне отдельных групп при усреднении (агрегационное смещение). Эти ограничения стимулировали развитие современных методов на базе машинного обучения, нейросетей и гибридных моделей.

## 36. Нейросетевые модели прогнозирования

Нейронные сети — класс моделей машинного обучения, имитирующих принцип работы биологических нейронов, способных выявлять сложные нелинейные зависимости в данных. В задачах прогнозирования временных рядов и регрессии применяются различные архитектуры. 1) Многослойный персептрон (MLP) — классическая нейросеть прямого распространения с входным, скрытыми и выходным слоями; для прогнозирования временного ряда на вход подаётся окно прошлых значений, на выходе — будущее значение. 2) Рекуррентные нейронные сети (RNN) — сети с обратными связями, специально разработанные для последовательных данных; имеют «память» о предыдущих состояниях, но страдают от проблемы исчезающего/взрывающегося градиента. 3) LSTM (Long Short-Term Memory) — усовершенствованная RNN с механизмом ячеек памяти и вентилей (forget, input, output), эффективно работающая с длинными зависимостями; стандарт для прогнозирования временных рядов. 4) GRU (Gated Recurrent Unit) — упрощённая версия LSTM с меньшим числом параметров. 5) Свёрточные сети (CNN, TCN) — применяются для извлечения локальных паттернов в рядах. 6) Трансформеры (Transformer, Informer, Autoformer) — современные модели на основе механизма внимания, эффективно обрабатывающие длинные последовательности параллельно. 7) Гибридные модели и специализированные архитектуры — N-BEATS, DeepAR (вероятностный прогноз), Temporal Fusion Transformer. Обучение нейросетей происходит методом обратного распространения ошибки с использованием градиентных оптимизаторов (Adam, SGD), функция потерь — обычно MSE или MAE. Преимущества: способность моделировать сложные нелинейности, работа с многомерными и разнородными данными, учёт экзогенных факторов, высокая точность при достаточном объёме данных. Недостатки: требуют больших объёмов обучающих данных, низкая интерпретируемость («чёрный ящик»), высокая вычислительная сложность, риск переобучения, сложность подбора архитектуры и гиперпараметров. Применяются в энергетике, финансах, прогнозировании спроса, обработке датчиков, климатических моделях.

## 37. Модели на базе цепей Маркова

Цепь Маркова — стохастическая модель случайного процесса с дискретным временем, в котором будущее состояние системы зависит только от текущего состояния и не зависит от предыстории (марковское свойство, или свойство отсутствия памяти). Формально: P(Xₜ₊₁ = j | X₀, X₁, …, Xₜ) = P(Xₜ₊₁ = j | Xₜ). Модель задаётся: 1) множеством возможных состояний {s₁, s₂, …, sₙ}; 2) начальным распределением вероятностей по состояниям; 3) матрицей переходных вероятностей P, где элемент pᵢⱼ — вероятность перехода из состояния i в состояние j за один шаг (строки матрицы суммируются в 1). Существуют цепи с дискретным временем (DTMC) и непрерывным временем (CTMC); по числу состояний — конечные и бесконечные; по характеру — однородные (вероятности перехода не зависят от времени) и неоднородные. Цепь Маркова n-го порядка учитывает n предыдущих состояний — обобщение базовой модели. Вероятности перехода оцениваются эмпирически из исторических данных как доля переходов из i в j от всех переходов из i. Для прогнозирования распределения вероятностей через k шагов используется возведение матрицы P в степень k: π_k = π₀·Pᵏ. Стационарное распределение π удовлетворяет уравнению π = π·P и существует для эргодических цепей. Расширение — скрытые марковские модели (HMM), где состояния не наблюдаются напрямую, а доступны только связанные с ними наблюдения. Применения: моделирование поведения клиентов и оттока (CRM), кредитный скоринг и миграция кредитных рейтингов, анализ последовательностей кликов на сайтах, распознавание речи и текста, прогнозирование погоды на категориальном уровне, моделирование надёжности систем, генетический анализ. Преимущества: математическая простота, интерпретируемость, эффективность для категориальных и дискретных процессов. Недостатки: марковское допущение часто нарушается в реальности, плохо описывает долгосрочные зависимости, неприменима к непрерывным числовым данным без предварительной дискретизации.

## 38. Модели на базе классификационно-регрессионных деревьев

Классификационно-регрессионные деревья (CART — Classification And Regression Trees), предложенные Брейманом в 1984 году — непараметрический метод машинного обучения, представляющий модель в виде иерархической древовидной структуры. Каждый внутренний узел дерева содержит правило разделения по одному из признаков (например, X₂ < 5,2), каждая ветвь соответствует исходу проверки, каждый лист — итоговому предсказанию (класс для классификации или числовое значение для регрессии). Процесс построения дерева — рекурсивное разбиение обучающей выборки: на каждом шаге выбирается признак и порог разделения, обеспечивающие наилучшее разделение по выбранному критерию. Критерии разделения для классификации: индекс Джини, энтропия (прирост информации); для регрессии: уменьшение суммы квадратов отклонений (дисперсии) в узлах. Алгоритм останавливается при достижении одного из условий: минимальное число объектов в узле, максимальная глубина дерева, отсутствие значимого улучшения критерия. Для борьбы с переобучением применяется обрезка (pruning) — удаление маловажных ветвей по критерию минимальной стоимости-сложности (cost-complexity pruning). Преимущества: высокая интерпретируемость (модель легко представить визуально и в виде набора правил), работа с числовыми и категориальными признаками без предварительной обработки, нечувствительность к масштабу и распределению данных, автоматическое обнаружение взаимодействий между признаками, устойчивость к выбросам. Недостатки: склонность к переобучению (особенно глубокие деревья), высокая дисперсия (небольшое изменение данных может полностью изменить структуру дерева), кусочно-постоянные предсказания, плохая аппроксимация гладких зависимостей, склонность к смещению в сторону признаков с большим числом уникальных значений. Для устранения недостатков отдельных деревьев разработаны ансамблевые методы: случайный лес (Random Forest), бустинг (AdaBoost, GBM, XGBoost, LightGBM, CatBoost), которые объединяют сотни и тысячи деревьев и обеспечивают высокую точность прогнозов. Применения: кредитный скоринг, медицинская диагностика, прогнозирование оттока, классификация клиентских сегментов, прогнозирование спроса.

## 39. Достоинства и недостатки моделей прогнозирования

Различные классы моделей прогнозирования имеют свои сильные и слабые стороны, и выбор зависит от конкретной задачи. Регрессионные модели — достоинства: интерпретируемость, статистическое обоснование, учёт внешних факторов, малое число параметров; недостатки: предположение о линейности (для базовой формы), чувствительность к нарушению допущений, потребность в прогнозе самих факторов. Модели временных рядов (ARIMA, SARIMA) — достоинства: математическая обоснованность, интервальные прогнозы, работа с автокорреляцией; недостатки: требование стационарности, чувствительность к выбору порядков, линейность, ограниченное использование внешней информации. Экспоненциальное сглаживание (SES, Хольт, Хольт-Уинтерс) — достоинства: простота, малое число параметров, работа на коротких рядах, низкая вычислительная сложность, удобство реального времени; недостатки: не учитывают экзогенные факторы, плохо реагируют на структурные сдвиги, ограничены классом ETS. Нейронные сети (MLP, LSTM, Transformer) — достоинства: моделирование сложных нелинейностей, работа с многомерными данными, высокая точность на больших выборках; недостатки: «чёрный ящик» (низкая интерпретируемость), требуют большого объёма данных, высокая вычислительная сложность, риск переобучения, сложность настройки. Деревья решений — достоинства: интерпретируемость, работа с разнотипными данными, нечувствительность к масштабу; недостатки: переобучение, высокая дисперсия, плохая аппроксимация гладких зависимостей. Ансамбли деревьев (Random Forest, XGBoost) — достоинства: высокая точность, устойчивость, работа с большим числом признаков; недостатки: потеря интерпретируемости, вычислительная сложность. Цепи Маркова — достоинства: простота, интерпретируемость для категориальных процессов; недостатки: марковское допущение, ограничение коротких зависимостей. Экспертные/интуитивные методы — достоинства: применимы при дефиците данных, учёт качественных факторов; недостатки: субъективность, низкая воспроизводимость. Общая тенденция — гибридные модели, объединяющие классические статистические подходы с машинным обучением, обеспечивают наилучший компромисс между точностью и интерпретируемостью.

## 40. Кластерный анализ: сущность, цели, приложения

Кластерный анализ — метод многомерного статистического анализа и машинного обучения, направленный на разбиение множества объектов на группы (кластеры) таким образом, чтобы объекты внутри одного кластера были максимально похожи между собой, а объекты из разных кластеров — максимально различны. Это задача обучения без учителя (unsupervised learning), в которой заранее неизвестны ни метки классов, ни количество групп — кластеры выявляются на основе самой структуры данных. Сходство объектов измеряется через метрики расстояния: евклидово, манхэттенское, Чебышёва, косинусное расстояние, метрика Махаланобиса; для категориальных данных — расстояние Хэмминга, Жаккара. Цели кластерного анализа: 1) выявление естественной структуры данных и скрытых закономерностей; 2) сегментация объектов по похожести для последующих специфических действий; 3) сжатие данных и снижение размерности (представление через центроиды кластеров); 4) обнаружение аномалий — объекты, не вошедшие ни в один кластер; 5) предварительный анализ перед применением других методов; 6) построение таксономии и классификации в предметных областях. Основные классы методов кластеризации: иерархические (агломеративные и дивизивные, дендрограмма), методы на основе разбиения (k-means, k-medoids/PAM, fuzzy c-means), плотностные (DBSCAN, OPTICS, HDBSCAN), на основе моделей (Gaussian Mixture Models, EM-алгоритм), сеточные (STING, CLIQUE), спектральные, ансамблевые. Оценка качества кластеризации: внутренние метрики (силуэт, индекс Дэвиса-Болдина, индекс Калински-Харабаса), внешние метрики (при наличии эталонных меток — индекс Рэнда, ARI, NMI). Приложения: маркетинговая сегментация клиентов (RFM-анализ), биоинформатика (классификация генов и белков), медицина (выделение групп пациентов и подтипов заболеваний), компьютерное зрение (сегментация изображений), обработка текстов (тематическое моделирование), обнаружение мошенничества и аномалий, анализ социальных сетей и сообществ, рекомендательные системы, городское планирование (зонирование), обработка геоданных. Кластерный анализ — один из ключевых инструментов разведочного анализа данных (EDA).

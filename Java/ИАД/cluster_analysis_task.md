# Кластерный анализ — разбор задач

Разбираем два классических типа задач:
1. **Иерархическая агломеративная кластеризация** (с дендрограммой).
2. **Алгоритм k-средних** (k-means).

---

## Часть 1. Иерархическая кластеризация

### Теоретическая основа

Алгоритм работает «снизу вверх»: каждый объект — отдельный кластер, затем на каждом шаге объединяются два **ближайших** кластера, пока не останется один. Способ измерения расстояния между кластерами определяет метод:

- **Single linkage (ближайший сосед):** $d(A,B) = \min_{x\in A,\,y\in B} d(x,y)$
- **Complete linkage (дальний сосед):** $d(A,B) = \max_{x\in A,\,y\in B} d(x,y)$
- **Average linkage:** среднее по всем парам
- **Ward:** минимум прироста внутрикластерной дисперсии

Расстояние между объектами обычно — **евклидово**:
$$
d(x,y) = \sqrt{\sum_{i=1}^{n}(x_i - y_i)^2}
$$

### Условие задачи

Даны 5 объектов на плоскости:

| Объект | $x_1$ | $x_2$ |
|--------|-------|-------|
| A      | 1     | 1     |
| B      | 2     | 1     |
| C      | 4     | 3     |
| D      | 5     | 4     |
| E      | 5     | 2     |

Выполнить иерархическую кластеризацию методом **ближайшего соседа** (single linkage), построить дендрограмму.

### Решение

#### Шаг 1. Матрица попарных расстояний

Считаем евклидовы расстояния, например:
$$
d(A,B) = \sqrt{(1-2)^2 + (1-1)^2} = 1
$$
$$
d(A,C) = \sqrt{(1-4)^2 + (1-3)^2} = \sqrt{9+4} = \sqrt{13} \approx 3{,}61
$$

Полная матрица (округлено до сотых):

|   | A    | B    | C    | D    | E    |
|---|------|------|------|------|------|
| A | 0    | 1,00 | 3,61 | 5,00 | 4,12 |
| B | 1,00 | 0    | 2,83 | 4,24 | 3,16 |
| C | 3,61 | 2,83 | 0    | 1,41 | 1,41 |
| D | 5,00 | 4,24 | 1,41 | 0    | 2,00 |
| E | 4,12 | 3,16 | 1,41 | 2,00 | 0    |

#### Шаг 2. Объединение 1 — минимум $d(A,B) = 1{,}00$

Объединяем $A$ и $B$ в кластер $\{AB\}$. Пересчитываем расстояния по правилу **минимума**:
$$
d(\{AB\}, X) = \min\bigl(d(A,X),\, d(B,X)\bigr)
$$

|     | AB   | C    | D    | E    |
|-----|------|------|------|------|
| AB  | 0    | 2,83 | 4,24 | 3,16 |
| C   | 2,83 | 0    | 1,41 | 1,41 |
| D   | 4,24 | 1,41 | 0    | 2,00 |
| E   | 3,16 | 1,41 | 2,00 | 0    |

#### Шаг 3. Объединение 2 — минимум $d(C,D) = d(C,E) = 1{,}41$

Здесь два равных минимума — выбираем любой, пусть $\{C,D\}$. Пересчёт:

|     | AB   | CD   | E    |
|-----|------|------|------|
| AB  | 0    | 2,83 | 3,16 |
| CD  | 2,83 | 0    | 1,41 |
| E   | 3,16 | 1,41 | 0    |

#### Шаг 4. Объединение 3 — минимум $d(CD, E) = 1{,}41$

Объединяем $\{CD\}$ с $E$, получаем $\{CDE\}$:

|     | AB   | CDE  |
|-----|------|------|
| AB  | 0    | 2,83 |
| CDE | 2,83 | 0    |

#### Шаг 5. Объединение 4 — последнее, $d(AB, CDE) = 2{,}83$

Получаем один общий кластер $\{ABCDE\}$.

#### Сводка объединений

| Шаг | Кластеры        | Расстояние |
|-----|-----------------|------------|
| 1   | A + B           | 1,00       |
| 2   | C + D           | 1,41       |
| 3   | CD + E          | 1,41       |
| 4   | AB + CDE        | 2,83       |

#### Дендрограмма

```
Расстояние
   |
2,83 ┤                ┌────────┴────────┐
     │                │                 │
1,41 ┤                │            ┌────┴────┐
     │                │            │         │
1,00 ┤           ┌────┴────┐       │      ┌──┴──┐
     │           │         │       │      │     │
   0 ┴───────────A─────────B───────E──────C─────D
```

**Естественное разбиение на 2 кластера** (горизонтальный разрез на уровне ~2,0):
- $\{A, B\}$
- $\{C, D, E\}$

## Часть 2. Алгоритм k-средних (k-means)

### Теоретическая основа

Алгоритм минимизирует **суммарную внутрикластерную дисперсию**:
$$
J = \sum_{i=1}^{k} \sum_{x \in C_i} \|x - \mu_i\|^2
$$

Шаги:
1. Задать число кластеров $k$ и начальные центроиды $\mu_1,\dots,\mu_k$.
2. **Assignment:** приписать каждый объект к ближайшему центроиду.
3. **Update:** пересчитать центроиды как среднее объектов кластера.
4. Повторять 2–3 до стабилизации.

### Условие задачи

Те же 5 объектов:

| Объект | $x_1$ | $x_2$ |
|--------|-------|-------|
| A      | 1     | 1     |
| B      | 2     | 1     |
| C      | 4     | 3     |
| D      | 5     | 4     |
| E      | 5     | 2     |

$k = 2$. Начальные центроиды: $\mu_1 = A = (1,1)$, $\mu_2 = C = (4,3)$.

### Решение

#### Итерация 1

**Шаг 1. Расстояния до центроидов (евклидовы, в квадрате — для скорости).**

| Объект | до $\mu_1 = (1,1)$  | до $\mu_2 = (4,3)$  | Ближе к |
|--------|---------------------|---------------------|---------|
| A(1,1) | $0$                 | $\sqrt{13}\approx3{,}61$ | $\mu_1$ |
| B(2,1) | $1$                 | $\sqrt{8}\approx2{,}83$  | $\mu_1$ |
| C(4,3) | $\sqrt{13}\approx3{,}61$ | $0$            | $\mu_2$ |
| D(5,4) | $5$                 | $\sqrt{2}\approx1{,}41$  | $\mu_2$ |
| E(5,2) | $\sqrt{17}\approx4{,}12$ | $\sqrt{2}\approx1{,}41$ | $\mu_2$ |

**Кластеры:** $C_1 = \{A,B\}$, $C_2 = \{C,D,E\}$.

**Шаг 2. Пересчёт центроидов** (среднее координат):
$$
\mu_1' = \left(\tfrac{1+2}{2},\,\tfrac{1+1}{2}\right) = (1{,}5;\,1{,}0)
$$
$$
\mu_2' = \left(\tfrac{4+5+5}{3},\,\tfrac{3+4+2}{3}\right) = \left(\tfrac{14}{3},\,3\right) \approx (4{,}67;\,3{,}00)
$$

#### Итерация 2

**Шаг 1. Расстояния до новых центроидов.**

| Объект | до $\mu_1' = (1{,}5;\,1)$ | до $\mu_2' = (4{,}67;\,3)$ | Ближе к |
|--------|------|------|---------|
| A(1,1) | 0,50 | 4,28 | $\mu_1'$ |
| B(2,1) | 0,50 | 3,28 | $\mu_1'$ |
| C(4,3) | 3,20 | 0,67 | $\mu_2'$ |
| D(5,4) | 4,61 | 1,05 | $\mu_2'$ |
| E(5,2) | 3,64 | 1,20 | $\mu_2'$ |

**Кластеры не изменились** $\Rightarrow$ алгоритм сошёлся.

### Итог

Финальные кластеры:
- $C_1 = \{A, B\}$ с центром $\mu_1 = (1{,}5;\,1{,}0)$
- $C_2 = \{C, D, E\}$ с центром $\mu_2 \approx (4{,}67;\,3{,}00)$

**Внутрикластерная сумма квадратов:**
$$
J = \underbrace{(0{,}5^2 + 0{,}5^2)}_{C_1} + \underbrace{(0{,}67^2 + 1{,}05^2 + 1{,}20^2)}_{C_2}
$$
$$
= 0{,}5 + (0{,}449 + 1{,}103 + 1{,}440) \approx 3{,}49
$$

## Визуализация расположения точек

```
y
 4 ┤              D
 3 ┤          C
 2 ┤                  E
 1 ┤ A  B
 0 └─────────────────────── x
   0  1  2  3  4  5  6
```

Хорошо видно, что точки делятся на две естественные группы: **{A, B}** в левом нижнем углу и **{C, D, E}** в правом верхнем — это согласуется с результатами и иерархической кластеризации, и k-means.

---

## Краткий шаблон решения

### Для иерархической кластеризации:
1. Построить матрицу попарных расстояний.
2. Найти минимум, объединить ближайшую пару.
3. Пересчитать расстояния по выбранному правилу (min / max / avg / Ward).
4. Повторять до одного кластера.
5. Построить дендрограмму, выбрать срез по числу кластеров.

### Для k-means:
1. Задать $k$ и начальные центроиды.
2. Приписать объекты к ближайшим центроидам (евклидово расстояние).
3. Пересчитать центроиды как среднее.
4. Повторять до стабилизации.
5. Посчитать внутрикластерную сумму квадратов $J$.

---

## Сравнение методов

| Критерий            | Иерархическая             | k-means                  |
|---------------------|---------------------------|--------------------------|
| Нужно задавать $k$  | Нет (выбор по дендрограмме) | Да (заранее)           |
| Сложность           | $O(n^2 \log n)$ — $O(n^3)$ | $O(n \cdot k \cdot d)$  |
| Форма кластеров     | Любая (зависит от метода)  | Сферические             |
| Чувствительность к выбросам | Высокая (особенно single linkage) | Высокая    |
| Результат           | Иерархия (дендрограмма)    | Плоское разбиение       |
| Возможность пересмотра ранних решений | Нет (greedy) | Да       |

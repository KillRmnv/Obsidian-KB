# Контекст

Применительно к предприятию в общем, контекст — это обстоятельства и факторы, которые влияют на решение, затрагиваются им или определяют его смысл.

Контекст — это часть окружения (среды), которые помогают понять, что должно представлять собой решение (характеристики) и какие требования (какие функции она будет реализовывать) к нему необходимо определить.

## К контексту относятся

1. Рыночная среда (домен)
2. Организационная структура (подразделения, структура управления)
3. Корпоративная культура (видение, миссия)
4. Активы (здания, оборудование, и т. п.)
5. Управление (бизнес-процессы, правила)
6. Информационные системы и данные (технологии, инфраструктура)

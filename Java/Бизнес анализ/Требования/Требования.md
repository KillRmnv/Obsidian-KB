# Требования

**Требование** — пригодное для использования представление потребности.

Требования сосредоточены на понимании того, какая ценность может быть получена в результате выполнения требования.

По сути, это представление может быть документом (или набором документов) и может значительно варьироваться в зависимости от обстоятельств.

**Требование** — условие или способность, необходимая пользователю, чтобы решить проблему или достигнуть цели.

**Требование (requirement)** — описание того, какие функции и с соблюдением каких условий должно выполнять разрабатываемое ПО в процессе решения полезной для пользователя задачи.

Требования к ПО = модель (информационная модель) будущей системы.

# 4
Великолепная постановка.  Крепкий простой сюжет и отлично прописанные персонажи, хорошо срежиссированный сцены.  Графические дизайнеры хорошо поработали, освещение в игре по большей части запеченное и заранее выставленно, даже на минимальных игра не перестает радовать глаз.  По геймплею—динамичный шутер с укрытиями, если играть на нормальной сложности.  На сложной становится душно, превращается в плохую копию гирсов.  Загадки не душные.  Паркур приятный.  Отличный блокбастер своего поколения, надеюсь не слишком быстро морально устареет

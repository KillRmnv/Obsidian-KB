### Подмена адреса (IP Spoofing)

Это использование произвольных адресов злоумышленниками для DDoS-атак.

В протоколе IPv4 нет встроенной проверки того, кто отправляет пакет. Хакер может сформировать сетевой пакет, написать в графе «Отправитель» **любой произвольный IP-адрес** (например, адрес сайта конкурента) и отправить его на тысячи серверов в интернете. Серверы получат запрос и отправят свои ответы не хакеру, а по указанному поддельному адресу, обрушив сайт конкурента шквалом мусорного трафика (это называется атакой с усилением / Amplification DDoS).

Чтобы с этим бороться, современные провайдеры настраивают технологию **uRPF (Unicast Reverse Path Forwarding)**. Провайдерский роутер проверяет каждый исходящий пакет от клиента: если клиент пытается отправить пакет с чужим или произвольным IP-адресом, роутер его немедленно уничтожает (марсианские пакеты).

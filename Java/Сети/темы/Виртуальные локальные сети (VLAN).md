# Виртуальная локальная сеть (VLAN)

## Связанные темы

- [[Устройства канального уровня]]

**VLAN (Virtual Local Area Network)** — это технология логического разделения одной физической локальной сети на несколько изолированных подсетей (широковещательных доменов) на канальном уровне (Layer 2) модели OSI.[etherwan][1]

С помощью VLAN администратор может группировать устройства логически (по отделам, функциям, типу трафика), независимо от их физического расположения и подключения к конкретному коммутатору.

**Стандарт:** IEEE 802.1Q[study-ccna][2]

---

## 1. Зачем нужны VLAN?

1. **Разделение широковещательных доменов:**
 Без VLAN широковещательный запрос (Broadcast) от одного компьютера получают все устройства в сети. Это создает "шум" и загружает каналы. VLAN ограничивает broadcast только пределами одной виртуальной сети.[allgeekery][3]

2. **Безопасность (Изоляция трафика):**
 Устройства в разных VLAN **не могут** общаться друг с другом напрямую на канальном уровне. Бухгалтерия не увидит трафик Гостей, даже если они подключены к одному коммутатору. Связь между VLAN возможна только через маршрутизатор (Layer 3).[jumpcloud+1][4]

3. **Гибкость и масштабируемость:**
 Можно переместить сотрудника в другой кабинет (на другой этаж), просто перенастроив порт на коммутаторе в нужный VLAN, без перекладки кабелей.[etherwan][1]

---

## 2. Принцип работы: Тегирование (IEEE 802.1Q)

Чтобы коммутаторы понимали, какому VLAN принадлежит кадр, используется **тегирование (Tagging)**. Самый распространенный протокол — **IEEE 802.1Q** (или dot1q).[wikipedia+1][5]

## Формат кадра 802.1Q

При передаче кадра между коммутаторами (через транк) в заголовок Ethernet вставляется специальный **4-байтовый тег** (802.1Q Tag). Он размещается между MAC-адресом отправителя и полем EtherType.[study-ccna+1][2]

**Структура тега (4 байта):**[wikipedia+1][5]

1. **TPID (Tag Protocol Identifier) — 16 бит:**

 - Всегда равен `0x8100`. Это сообщает принимающему устройству: «Внимание, это кадр с VLAN-тегом!».

2. **TCI (Tag Control Information) — 16 бит:**

 - **PCP (Priority Code Point) — 3 бита:** Приоритет трафика (CoS) для QoS (например, голос имеет высший приоритет).

 - **DEI (Drop Eligible Indicator) — 1 бит:** Указывает, можно ли отбросить кадр при перегрузке.

 - **VID (VLAN Identifier) — 12 бит:** Самое главное поле. Номер VLAN (от 1 до 4094).[wikipedia][5]

**Влияние на размер кадра:**[wikipedia][5]
Добавление тега увеличивает максимальный размер кадра с 1518 до **1522 байт** (так называемые _baby giant frames_).

## 3. Типы портов коммутатора

В зависимости от того, как порт обрабатывает теги, он может быть настроен в одном из двух режимов:[optcore+1][6]

## 1) Порт доступа (Access Port)

- **Назначение:** Для подключения конечных устройств (компьютеров, принтеров), которые **не понимают** тегированные кадры.[nice+1][7]

- **Работа:**

 - Принадлежит **только одному** VLAN.

 - **Отправка:** Перед отправкой кадра компьютеру коммутатор **удаляет** VLAN-тег. Компьютер получает обычный Ethernet-кадр.

 - **Прием:** Любой кадр, пришедший от компьютера, коммутатор автоматически помечает как принадлежащий VLAN этого порта.

## 2) Магистральный порт (Trunk Port)

- **Назначение:** Для соединения между коммутаторами (Switch-to-Switch) или с маршрутизатором/сервером.[optcore+1][6]

- **Работа:**

 - Передает трафик **нескольких** (или всех) VLAN одновременно по одному кабелю.[optcore][6]

 - Все кадры (кроме Native VLAN) передаются **с тегами 802.1Q**, чтобы принимающий коммутатор знал, к какой сети они относятся.

---

## 4. Native VLAN

**Native VLAN** (Нативный VLAN) — это особый VLAN на транковом порту, трафик которого передается **без тега (untagged)**.[ruijie+1][8]

- По умолчанию это **VLAN 1**.

- **Зачем нужен:** Для совместимости с устройствами, которые не понимают тегирование, и для передачи служебного трафика (CDP, DTP, STP, LLDP).[reddit][9]

- **Правило:** Native VLAN должен быть настроен **одинаково** с обеих сторон транка (иначе возникнет "VLAN mismatch" и трафик потеряется или попадет не туда).

---

## Резюме для ответа:

VLAN логически делит сеть на изолированные сегменты. Это нужно для безопасности и уменьшения "шума" (broadcast).

- Внутри одного коммутатора изоляция работает на уровне портов.

- Между коммутаторами используется **Транк (Trunk)**, где каждый кадр помечается тегом **802.1Q** (номер VLAN вставляется в заголовок).

- Компьютеры подключаются к **Access-портам** и ничего не знают о тегах.

- Коммутаторы соединяются через **Trunk-порты** и обмениваются тегированным трафиком.

## Связь L2 и L3: заметка

### Основная идея

L3 (IP) отвечает за маршрутизацию между сетями. L2 (Ethernet) отвечает за доставку кадра внутри одного локального сегмента или VLAN. IP-пакет сам по себе по проводу не передаётся: он инкапсулируется в L2-кадр.

### Инкапсуляция

IP-пакет помещается в Ethernet-кадр:

- **Src IP** и **Dst IP** находятся внутри IP-заголовка и в обычном случае не меняются на всём пути.
- **Src MAC** и **Dst MAC** находятся в Ethernet-заголовке и меняются на каждом прыжке.
- MAC-адреса имеют значение только в пределах одного L2-сегмента.

### Как выбирается Dst MAC

Маршрутизатор или хост сначала выполняет поиск по таблице маршрутизации. В результате определяется выходной интерфейс и IP next-hop.

Далее возможны два случая:

1. **IP next-hop находится в той же подсети**, что и выходной интерфейс.  
   Нужен MAC этого next-hop. Если он неизвестен, используется ARP.

2. **IP next-hop не находится в直接 подключённой подсети**.  
   Для отправки всё равно нужен MAC следующего маршрутизатора, который находится в直接 подключённой подсети на выходном интерфейсе.

### Роль ARP

ARP связывает L3-адрес с L2-адресом в пределах одного сегмента.

Если MAC next-hop неизвестен:

1. IP-пакет ставится в очередь.
2. Отправляется ARP-запрос с широковещательным MAC назначения: `FF:FF:FF:FF:FF:FF`.
3. Коммутатор рассылает этот кадр во все порты своей VLAN.
4. Нужное устройство отвечает unicast-кадром со своим MAC.
5. Отправитель записывает соответствие IP-MAC в ARP-кэш.
6. Только после этого отправляется кадр с настоящим IP-пакетом, где `Dst MAC` равен MAC next-hop.

Важно: широковещательный MAC используется в ARP-запросе, а не в кадре с полезным IP-пакетом.

### Роли устройств

**Коммутатор:**

- работает на L2;
- пересылает кадры по `Dst MAC` внутри VLAN;
- широковещательные кадры рассылает во все порты;
- запоминает MAC-адреса и соответствующие порты в MAC-таблице;
- IP-адреса не анализирует, кроме специальных функций.

**Маршрутизатор:**

- работает на L3;
- принимает кадр, снимает L2-заголовок;
- смотрит на `Dst IP` и ищет маршрут;
- определяет next-hop и выходной интерфейс;
- при необходимости использует ARP;
- формирует новый L2-кадр для следующего сегмента.

### Что меняется на каждом прыжке

- IP-адреса отправителя и получателя остаются прежними, если нет NAT.
- MAC-адреса отправителя и получателя меняются на каждом L2-сегменте.
- Коммутаторы обеспечивают доставку внутри сегмента.
- Маршрутизаторы обеспечивают переход между сегментами.

### Краткая последовательность

1. L3 определяет `Dst IP` и маршрут.
2. L3 определяет IP next-hop.
3. Для next-hop нужен MAC.
4. Если MAC неизвестен, выполняется ARP.
5. IP-пакет инкапсулируется в L2-кадр с MAC next-hop.
6. Кадр передаётся через коммутаторы внутри сегмента.
7. Маршрутизатор снимает L2, анализирует L3 и строит новый L2-кадр для следующего сегмента.

### Формула

- IP-пакет: `Src IP`, `Dst IP`.
- Ethernet-кадр: `Src MAC`, `Dst MAC`.
- MAC next-hop определяется через ARP в пределах直接 подключённого сегмента.
- IP-адреса несут сквозной смысл, MAC-адреса обеспечивают доставку в пределах текущего L2-сегмента.

Когда `main` завершается и все не‑демон потоки завершены:

- JVM останавливает JIT, GC, освобождает свои структуры памяти (heap, metaspace и т.д.).[synergy](https://synergy.ru/akademiya/programming/java_virtual_machine_v_detalyax_kak_ona_rabotaet_iznutri)
    
- Закрывает нативные ресурсы (файлы, сокеты, дескрипторы) и выгружается из процесса ОС.sky+1
    

Если остаются только daemon‑потоки (например, таймеры, фоновые GC‑потоки), JVM всё равно завершит процесс после завершения всех обычных (non‑daemon) потоков.

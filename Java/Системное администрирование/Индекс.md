## Как готовиться по этому разделу

1. Читать блок → закрыть заметку → рассказать вслух за 2 минуты.
2. На каждый «Чек-лист диагностики» отвечать по шагам, без подглядывания.
3. «Вопросы на собеседовании» — отвечать письменно, коротко (1–3 предложения).
4. Всё, что описано, пробовать в лабе: Windows Server + 2 клиента + Linux в виртуалках.
5. Повторять не чтением, а действием: сломать → починить → записать в тикет.

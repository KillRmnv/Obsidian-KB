# Сетевые принтеры и сканирование

Сетевой принтер — это устройство со своим IP, веб-интерфейсом и набором служб, поэтому диагностика делится на сеть, порт, драйвер и права. Сканирование в сеть добавляет учётные записи и доступ к папкам, и там ломается чаще всего.

## Адресация

| Вариант | Плюсы | Минусы |
|---|---|---|
| Статический IP на устройстве | адрес не меняется, простые правила firewall | легко ошибиться и получить конфликт адресов |
| Reservation в DHCP | централизованно, нет конфликтов, адрес стабилен | зависит от доступности DHCP-сервера |

Практика: резервирование по MAC в DHCP удобнее статики — адрес не меняется, но и не приходится помнить, какие адреса заняты. Вне сети DHCP (гости, филиал) — статика вне пула.

## Веб-интерфейс (EWS)

Embedded Web Server открывается по `http://<ip>` и даёт состояние, счётчики, настройки сети и сканирования.

- Первое действие — сменить пароль администратора по умолчанию.
- Проверить имя устройства, адрес, маску, шлюз, DNS.
- Отключить неиспользуемые протоколы: Telnet, FTP, UPnP, IPv6, если не нужны.
- Обновление прошивки — только с официального сайта и при стабильном питании.

## Порты печати

| Порт | Протокол | Когда используется |
|---|---|---|
| 9100 | RAW (JetDirect) | самый распространённый, драйвер шлёт готовый поток |
| 515 | LPR/LPD | старые системы и Unix, нужен queue name |
| 631 | IPP | кроссплатформенная печать, драйвер-less, AirPrint |
| 5357 | WSD | обнаружение и установка в Windows без указания IP |
| 161 | SNMP | статус, уровень тонера, счётчики |
| 445 | SMB | сканирование в папку |
| 21 | FTP | сканирование по FTP, реже из-за безопасности |

## TCP/IP-порт в Windows

1. Панель управления → Устройства и принтеры → Добавить принтер.
2. «Нужный принтер отсутствует» → «Добавить по IP-адресу».
3. Тип устройства — TCP/IP, адрес, имя порта.
4. Драйвер — с диска, из Windows Update или универсальный.
5. Проверить печать тестовой страницы.

```powershell
Add-PrinterPort -Name 'IP_10.0.5.20' -PrinterHostAddress '10.0.5.20'
Add-Printer -Name 'PRN-01' -DriverName 'HP Universal Printing PCL 6' -PortName 'IP_10.0.5.20'
Get-Printer | Select-Object Name, PortName, PrinterStatus
Test-NetConnection 10.0.5.20 -Port 9100
```

## Общий принтер и GPO

- Публикация: на ПК с USB-принтером включить общий доступ, задать имя без пробелов и кириллицы, проверить права.
- Клиент подключается по `\\PC-01\PRN-01`; для этого нужны SMB, открытые порты и права.
- GPO: Print Management → Deploy with Group Policy, отдельно per-user и per-machine.
- После PrintNightmare установка драйверов ограничена: `RestrictDriverInstallationToAdministrators`, Point and Print restrictions. Поэтому пакет драйверов лучше разворачивать заранее.

## Universal Print и IPP Everywhere

- **Universal Print** — облачная очередь Microsoft 365: принтер регистрируется в Azure, клиент получает его без локального драйвера.
- **IPP Everywhere** и **Mopria** — печать без драйвера по стандарту IPP с автоматическим подбором параметров.
- **AirPrint** — IPP + mDNS (5353) + PDF/URF; нужен тот же широковещательный домен, иначе только по IP.

## Scan-to-SMB, FTP, E-mail

Сканирование в папку требует трёх вещей: учётной записи, прав на шару и сетевого пути.

```text
\\server\scan          — путь для SMB
\\10.0.5.10\scan       — то же по IP, если имя не резолвится
scan@corp.local        — учётная запись для Scan-to-E-mail (SMTP)
```

1. Создать отдельную учётную запись с правом записи только в папку сканов.
2. Открыть шару, проверить права NTFS и SMB.
3. В EWS указать путь, логин и пароль, выбрать формат (PDF, JPEG, TIFF) и разрешение.
4. Проверить с устройства, затем посмотреть событие входа на сервере.

Старые МФУ умеют только SMBv1, который отключён в современных Windows из-за WannaCry. Варианты: обновить прошивку до SMBv2/v3, поставить промежуточный сервер с SMBv1 в изолированном сегменте или отказаться от Scan-to-SMB в пользу FTP или E-mail. Включать SMBv1 на файловом сервере ради принтера — плохая идея.

## Scan-to-PC и WSD

- Scan-to-PC работает через драйвер сканера на конкретном ПК и часто требует запущенной службы и открытого порта.
- WSD-сканирование находит устройство автоматически, но привязано к подсети и хуже переживает смену адреса.

## Типовые сбои

| Симптом | Причина | Действие |
|---|---|---|
| По IP печатает, по имени нет | нет записи DNS, NetBIOS отключён, другое имя | `nslookup`, добавить A-запись или использовать IP |
| Скан не пишет на шару | неверный путь, права, пароль, SMBv1 | проверить вход в журнале, права NTFS, версию SMB |
| Ошибка 0x00000709 | параметры принтера по умолчанию, RPC, обновление Windows | задать принтер по умолчанию вручную, `LegacyDefaultPrinterMode`, перезапуск спулера |
| Ошибка 0x0000011b | ужесточение RPC-шифрования для Point and Print | обновить драйверы и клиент, не отключать защиту без нужды |
| «Принтер не найден» после смены подсети | сменился адрес, WSD не видит устройство | reservation в DHCP, пересоздать TCP/IP-порт |
| Печать идёт, статус неверный | закрыт SNMP или 9100 | открыть 161/udp и 9100/tcp |
| AirPrint не видит принтер | разные VLAN, mDNS не проходит | разрешить mDNS или печатать по IP |
| Долгая печать первого задания | WSD-обнаружение, энергосбережение | перейти на 9100, отключить глубокий сон |

## Безопасность

- Сменить пароль EWS и отключить Web-доступ из внешней сети.
- Отключить Telnet, FTP, UPnP и неиспользуемые протоколы.
- Обновлять прошивку: сетевые МФУ — полноценные хосты с ОС.
- Изолировать печать в отдельный VLAN с правилами только на нужные порты.

## Чек-лист диагностики

1. Проверить питание, кабель и индикаторы устройства.
2. `ping` по адресу, затем `Test-NetConnection -Port 9100`.
3. Открыть EWS: адрес, маска, шлюз, DNS, состояние.
4. Напечатать тест-страницу из меню.
5. Проверить статус и порт принтера в Windows.
6. Перезапустить спулер и очистить очередь.
7. Сверить драйвер и язык печати.
8. Для сканирования — проверить учётку, права на шару и версию SMB.
9. Сравнить поведение по IP и по имени — локализовать DNS.
10. Зафиксировать адрес, модель и что изменено.

## Вопросы на собеседовании

**Статический IP или reservation в DHCP?** Резервирование удобнее: адрес стабилен и управляется централизованно, без риска конфликта. Статику оставляют для сетей без DHCP.

**Зачем принтеру порт 9100?** Это RAW-порт, по которому драйвер отправляет готовый поток печати. Самый совместимый вариант для TCP/IP-порта в Windows.

**Почему печатает по IP, но не по имени?** Не разрешается имя: нет A-записи, неверный DNS-суффикс или отключён NetBIOS. Проверяется `nslookup` и запись на DNS-сервере.

**Почему старое МФУ не сканирует на шару?** Оно использует SMBv1, который отключён. Решение — прошивка с SMBv2/v3, промежуточный сервер или FTP/E-mail.

**Что такое WSD и чем он хуже TCP/IP-порта?** Протокол обнаружения устройств в Windows. Зависит от широковещания и подсети, поэтому между сегментами ненадёжен.

**Как защитить сетевой принтер?** Сменить пароль EWS, отключить лишние службы, обновлять прошивку, вынести печать в отдельный VLAN.

**Почему после смены подсети «принтер не найден»?** Изменился адрес или клиент ищет устройство через WSD в старой подсети. Нужен reservation и пересозданный TCP/IP-порт.

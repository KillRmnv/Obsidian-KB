# Установка и настройка Windows

Базовая заметка про чистую установку Windows 10/11 и приведение свежей системы к рабочему состоянию: разметка диска, драйверы, активация, оснастки и типовые настройки. На собеседовании это проверяют вопросом «как вы ставите Windows с нуля и что делаете после установки».

## Редакции и требования

| Редакция | Что даёт | Где встречается |
|---|---|---|
| Home | нет домена, GPO, RDP-сервера, BitLocker (только Device Encryption) | домашние ноутбуки |
| Pro | домен, GPO, RDP-приём, BitLocker, Hyper-V, Remote Desktop Host | корпоративные ПК |
| Enterprise / Education | то же + расширенное управление, AppLocker, BranchCache | крупные организации, лицензия по подписке |

Windows 11: 64-битный CPU (2+ ядра, 1 ГГц), 4 ГБ RAM, 64 ГБ диск, UEFI + Secure Boot, **TPM 2.0**, DirectX 12/WDDM 2.0. Windows 10 — снята с поддержки 14.10.2025, поэтому новые рабочие места ставят на 11.

## Чистая установка

1. Скачать образ через Media Creation Tool или получить ISO из центра лицензий; записать на USB (Rufus, режим GPT/UEFI).
2. Загрузиться с USB: в BIOS/UEFI выключить Secure Boot только если образ этого требует, выставить boot order, режим UEFI (не Legacy/CSM).
3. Разметка диска под UEFI/GPT — обязательный минимум:

| Раздел | Размер | Назначение |
|---|---|---|
| EFI System (ESP) | 100–300 МБ, FAT32 | загрузчик `bootmgfw.efi` |
| MSR | 16 МБ | служебный, без ФС |
| Windows (C:) | остальное | система |
| Recovery | 500–1000 МБ | WinRE |

4. Установка, OOBE: регион, раскладка, имя устройства, локальная учётка или доменная (в Pro можно сразу `Присоединиться к домену`).
5. Первый вход → драйверы в порядке: **чипсет → сеть → видео → периферия**. Без драйвера чипсета возможны «неизвестные устройства» и нестабильность.

## После установки: обязательный чек-лист

- Имя компьютера и рабочая группа/домен (`sysdm.cpl`), перезагрузка.
- Обновления Windows и драйверы с сайта производителя (не «драйвер-паки»).
- Активация: цифровая лицензия привязывается к железу, KMS/MAK — в корпоративной среде (`slmgr /dlv`, `slmgr /ato`).
- Точки восстановления и размер файла подкачки (по умолчанию — системный диск).
- Антивирус/EDR, брандмауэр, включённый BitLocker при необходимости.
- Удаление предустановленного ПО, отключение ненужных автозапусков (`msconfig`, `autorun` в Task Manager, Autoruns).
- Настройка электропитания (сон/гибернация), быстрый запуск — часто мешает диагностике.
- Создание учётной записи пользователя (не работать под встроенным Administrator).
- Проверка сети: `ipconfig /all`, `ping` шлюза, `nslookup`.

## Развёртывание на несколько ПК

- **Sysprep** (`sysprep /generalize /oobe /shutdown`) — сброс SID и уникальных данных перед клонированием; образ снимают в audit-режиме.
- **WDS / MDT** — загрузка по сети и установка с ответами (`unattend.xml`).
- **Intune / Autopilot** — современный вариант для распределённых компаний.
- Клонирование диска (Clonezilla, Macrium) допустимо для одинаковых машин, но без sysprep в домене будут конфликты имён и SID.

## Чек-лист диагностики

1. Уточнить: это чистая установка, переустановка после сбоя или апгрейд? Сохранились ли данные?
2. Проверить, видит ли BIOS/UEFI диск и в каком режиме (UEFI/Legacy, RAID/AHCI).
3. Если установщик не видит диск — подгрузить драйвер контроллера (F6/«Загрузить драйвер»), проверить режим SATA.
4. Если установка падает — проверить RAM (MemTest86), диск (SMART), целостность ISO/USB.
5. После установки — `devmgmt.msc` на неизвестные устройства, `winver`, `slmgr /dlv`.
6. Проверить `ipconfig /all`: адрес, шлюз, DNS, суффикс; `ping` и `nslookup`.
7. Убедиться, что установлены обновления и создана точка восстановления.
8. Зафиксировать в заявке: редакция, версия сборки, что установлено, какие драйверы, серийный номер.

## Вопросы на собеседовании

**Чем отличается Windows 10 Pro от Home?** Домен/AD, GPO, RDP-приёмник, BitLocker, Hyper-V, Remote Desktop Host — в Home этого нет.

**Что нужно для установки Windows 11?** UEFI + Secure Boot, TPM 2.0, 4 ГБ RAM, 64 ГБ, 2 ядра; иначе установщик блокирует.

**Зачем sysprep?** Сбросить уникальные идентификаторы (SID), настройки OOBE и драйверную привязку, чтобы образ можно было тиражировать.

**Какие разделы создаются при установке на GPT?** ESP, MSR, Windows, Recovery.

**Что делать, если установщик не видит SSD?** Драйвер контроллера (Intel RST/VMD), режим SATA в BIOS, проверить, что диск не в RAID без драйвера.

# Диагностика и восстановление Windows

Порядок действий при «компьютер не работает»: от питания и POST до загрузчика, драйверов и ОС. Главное правило — идти от простого к сложному и не переустанавливать систему, пока не собраны симптомы.

## Куда смотреть в первую очередь

| Инструмент | Что даёт |
|---|---|
| `eventvwr.msc` | журналы System/Application/Security/Setup |
| `perfmon /rel` | Reliability Monitor: сбои и установки по дням |
| Task Manager → Startup | автозагрузка и её влияние |
| `resmon.exe` | ЦП/память/диск/сеть по процессам |
| `msconfig` | службы, автозагрузка, безопасный режим |
| `devmgmt.msc` | конфликты и неизвестные устройства |
| `dxdiag`, `winver`, `systeminfo` | версия, железо, сборка |

Ключевые Event ID: **41** (некорректное выключение/Kernel-Power), **6008** (неожиданная перезагрузка), **1001** (BugCheck, код BSOD), **7000/7009** (служба не стартовала), **7036** (смена состояния службы), **51/153** (ошибки диска), **55** (повреждение NTFS), **4625** (неудачный вход), **4740** (блокировка учётки), **1074** (кто инициировал выключение).

## Загрузка: где именно ломается

1. **Нет реакции на кнопку** — питание, БП, кнопка, материнская плата.
2. **Кулеры крутятся, изображения нет** — RAM, видеокарта, монитор/кабель, BIOS.
3. **POST проходит, но ОС не грузится** — загрузчик/BCD, диск, файловая система.
4. **ОС грузится и падает** — драйвер, обновление, повреждённые системные файлы, диск.
5. **ОС грузится, приложение падает** — профиль, права, зависимости, само ПО.

## Восстановление загрузчика

WinRE: `Shift` + перезагрузка, либо три прерывания загрузки подряд, либо загрузка с установочного USB → «Восстановление системы» → «Командная строка».

```text
bootrec /fixmbr
bootrec /fixboot      :: на UEFI может ответить "Отказано в доступе" — это нормально
bootrec /scanos
bootrec /rebuildbcd
bcdedit /enum all
bcdboot C:\Windows /s S: /f UEFI   :: пересоздать загрузчик на ESP (диск S:)
chkdsk C: /f /r
sfc /scannow /offbootdir=C:\ /offwindir=C:\Windows
```

Порядок: `chkdsk` → `sfc` офлайн → `bootrec`/`bcdboot` → восстановление из точки → установка поверх → сброс → чистая установка.

## Восстановление системы и обновлений

- **Точка восстановления**: `SystemPropertiesProtection.exe`, откат из WinRE или из работающей системы.
- **Откат драйвера**: `devmgmt.msc` → свойство устройства → «Откатить».
- **Откат обновления**: `wusa /uninstall /kb:<номер обновления>`, либо «Центр обновления» → история → удалить; если не грузится — WinRE → «Удалить последнее обновление».
- **Сброс ПК**: «Сохранить мои файлы» / «Удалить всё» — переустановка с сохранением данных или без.
- **Установка поверх** (repair install): запуск `setup.exe` из работающей системы с тем же языком/редакцией — сохраняет программы и данные, лечит системные файлы.
- **Образ**: восстановление из бэкапа (Veeam/WSB/клон) — самый быстрый путь, если бэкап был.

## Типовые сбои и что проверять

| Симптом | Вероятная причина | Действия |
|---|---|---|
| BSOD с кодом | драйвер, память, диск, обновление | код из Event 1001, `C:\Windows\Minidump`, Driver Verifier, MemTest86, SMART |
| «Загрузка» бесконечно | профиль, служба, диск | безопасный режим, `perfmon /rel`, отключить сторонний антивирус |
| Система тормозит | диск 100%, RAM, автозагрузка, майнер | Resource Monitor, `Get-PhysicalDisk`, Autoruns, проверка на malware |
| Нет места на C: | обновления, `WinSxS`, логи, hiberfil | `cleanmgr`, `Dism /Online /Cleanup-Image /StartComponentCleanup`, `powercfg /h off` |
| Приложение не запускается | зависимости, права, антивирус | Event Viewer → Application, `sfc`, переустановка |
| Профиль не загружается | повреждён `ProfileList` | правка реестра, `.bak`, создание нового профиля |
| Часы сбиваются | CMOS-батарейка, NTP | замена батарейки, `w32tm /resync` |

## Безопасный режим и чистая загрузка

- Безопасный режим: «Параметры» → «Восстановление» → «Особые варианты загрузки», либо `msconfig` → «Загрузка» → «Безопасный режим».
- Чистая загрузка: `msconfig` → «Службы» → скрыть службы Microsoft → отключить остальные + автозагрузка. Если проблема ушла — включать группами.
- Autoruns (Sysinternals) — полный список автозапуска, включая задачи и расширения Explorer.

## Чек-лист диагностики

1. Записать симптом, когда началось, что менялось (обновление, драйвер, ПО, железо).
2. Проверить питание и POST; при необходимости — RAM по одной, диск, БП.
3. Загрузиться в безопасный режим: проблема осталась? значит не сторонний драйвер/ПО.
4. Посмотреть Event Viewer за момент сбоя и `perfmon /rel`.
5. Проверить диск: SMART, `chkdsk`, `Get-PhysicalDisk`.
6. Проверить целостность: `sfc /scannow`, затем `DISM /Online /Cleanup-Image /RestoreHealth`.
7. Пробовать откат: драйвер → обновление → точка восстановления.
8. Если не грузится — WinRE: `bootrec`, `bcdboot`, офлайн-`sfc`, откат обновления.
9. Крайние меры: установка поверх → сброс → чистая установка; данные сохранить заранее.
10. Зафиксировать причину и что сделано, чтобы не повторять диагностику.

## Вопросы на собеседовании

**Компьютер не включается — с чего начнёте?** Питание и кабель, кнопка, БП (мультиметр/перемычка), POST, RAM по одной, затем плата.

**Синий экран: где смотреть код?** Event Viewer ID 1001, `C:\Windows\Minidump`, BlueScreenView/WinDbg; код и драйвер указывают направление.

**Чем `sfc` отличается от `DISM`?** `sfc` чинит файлы из локального хранилища, `DISM ... /RestoreHealth` чинит само хранилище (в т.ч. из Windows Update/ISO).

**Не грузится после обновления — что делать?** WinRE → удалить последнее обновление/точка восстановления, затем `bootrec`/`bcdboot` при повреждении загрузчика.

**Когда переустанавливать, а когда чинить?** Если данные и настройки восстановимы и проблема не воспроизводится после ремонта — чинить; при повреждении системных файлов и потере времени — восстановление из образа.

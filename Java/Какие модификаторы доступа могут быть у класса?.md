Для **класса** в Java допускается не весь набор модификаторов доступа, который есть для полей/методов.

## Верхнеуровневые классы (в файле .java)

У обычного (top‑level) класса можно указать только **два** варианта:

- `public` — класс виден из любого пакета.
    
- _package‑private_ (модификатор по умолчанию, когда вы ничего не пишете) — класс виден только внутри своего пакета.
    

Модификаторы `private` и `protected` для верхнеуровневого класса запрещены.

## Вложенные (inner / nested) классы

Для **вложенных классов** (объявленных внутри другого класса) доступны все четыре модификатора доступа:

- `public`
    
- `protected`
    
- _package‑private_ (без модификатора)
    
- `private`
    

То есть внутренний класс можно сделать даже `private`, чтобы его никто не видел за пределами внешнего класса.

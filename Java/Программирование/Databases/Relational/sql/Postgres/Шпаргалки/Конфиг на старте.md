# Конфиг на старте

Стартовая конфигурация для одного сервера PostgreSQL 16–18. Не истина в последней инстанции: подстраивай под метрики ([[Оптимизация/Тюнинг параметров сервера]]).

---

## Ориентиры по RAM

| Параметр | 4 ГБ | 16 ГБ | 64 ГБ | 128 ГБ |
|---|---|---|---|---|
| `shared_buffers` | 1GB | 4GB | 16GB | 32GB |
| `effective_cache_size` | 3GB | 12GB | 48GB | 96GB |
| `maintenance_work_mem` | 256MB | 1GB | 2GB | 2GB |
| `work_mem` | 4MB | 8MB | 16MB | 16MB |
| `autovacuum_work_mem` | 256MB | 1GB | 1GB | 1GB |

`work_mem` — **на узел плана**, не общий. Поднимай точечно: `SET LOCAL work_mem = '256MB'`.

---

## postgresql.conf (пример на 16 ГБ, SSD, OLTP)

```conf
# ---------- Подключения ----------
listen_addresses = '*'
max_connections = 200
superuser_reserved_connections = 3
idle_in_transaction_session_timeout = '60s'
statement_timeout = '30s'
lock_timeout = '5s'

# ---------- Память ----------
shared_buffers = 4GB
effective_cache_size = 12GB
work_mem = 8MB
maintenance_work_mem = 1GB
autovacuum_work_mem = 1GB
wal_buffers = 16MB

# ---------- Диск (SSD) ----------
random_page_cost = 1.1
seq_page_cost = 1.0
effective_io_concurrency = 200
maintenance_io_concurrency = 100

# ---------- WAL ----------
wal_level = replica
max_wal_size = 8GB
min_wal_size = 2GB
checkpoint_timeout = '15min'
checkpoint_completion_target = 0.9
wal_compression = lz4
synchronous_commit = on
full_page_writes = on

# ---------- Autovacuum ----------
autovacuum = on
autovacuum_max_workers = 4
autovacuum_naptime = '30s'
autovacuum_vacuum_cost_delay = '2ms'
autovacuum_vacuum_cost_limit = 1000

# ---------- Планировщик ----------
default_statistics_target = 100
max_parallel_workers_per_gather = 4
max_parallel_maintenance_workers = 2
parallel_setup_cost = 1000
jit = on
jit_above_cost = 100000

# ---------- Логи и диагностика ----------
log_min_duration_statement = '500ms'
log_checkpoints = on
log_lock_waits = on
log_temp_files = 0
log_autovacuum_min_duration = '1s'
log_line_prefix = '%m [%p] %q%u@%d '
track_io_timing = on
track_activity_query_size = 2048

# ---------- Расширения (нужен рестарт) ----------
shared_preload_libraries = 'pg_stat_statements,auto_explain'

# ---------- PG18+ ----------
# io_method = 'worker'
```

---

## Что НЕ делать

| Плохо | Почему |
|---|---|
| `shared_buffers = 80% RAM` | ОС тоже кэширует файлы; PG не отдаёт память |
| `work_mem = 1GB` глобально | `max_connections × узлы × work_mem` → OOM |
| `fsync = off` | потеря/повреждение данных при сбое |
| `synchronous_commit = off` «для скорости» без понимания | теряются последние коммиты при краше |
| `random_page_cost = 4` на SSD | планировщик недооценивает индексы |
| `max_connections = 1000` без пулера | процессы, память, latency |
| `autovacuum = off` | bloat и wraparound |
| копировать чужой конфиг целиком | параметры зависят от RAM, диска, нагрузки |

## Проверка

```sql
SHOW shared_buffers;
SHOW work_mem;
SHOW random_page_cost;
SHOW shared_preload_libraries;

SELECT name, setting, source FROM pg_settings
WHERE name IN ('shared_buffers','work_mem','effective_cache_size','random_page_cost');

SELECT pg_reload_conf();   -- для параметров с context=sighup; часть требует рестарта
```

## Стартовый набор расширений

```sql
CREATE EXTENSION pg_stat_statements;   -- обязательное
CREATE EXTENSION pgstattuple;          -- bloat
CREATE EXTENSION pg_trgm;              -- LIKE '%…%'
CREATE EXTENSION pageinspect;          -- внутренности страниц
CREATE EXTENSION pg_visibility;        -- VM/FSM
CREATE EXTENSION amcheck;              -- проверка индексов
```

`auto_explain` не требует `CREATE EXTENSION`, только `shared_preload_libraries`.

# PostgreSQL

Ветка заметок про то, **как PostgreSQL устроен внутри** и **как на этом основании ускорять запросы**. Не справочник по SQL (он в [[SQL]]), а разбор механики: страницы и кортежи → MVCC → WAL → индексы → планировщик → оптимизация.

Базовые версии — **16–18**. Отличия по версиям помечены явно: `PG17+`, `PG18+` и т.д. Клиент в системе: PostgreSQL 18.

---

## Как читать

1. **Одна заметка = один эксперимент.** Теорию без `psql` можно выучить, но не понять. Все эксперименты воспроизводимы в [[Практикум/Лаборатория на Docker|лаборатории на Docker]].
2. **Порядок важен только внутри итерации.** Итерация 1 объясняет, что видно в `EXPLAIN`; без неё итерация 2 превращается в заучивание советов.
3. **Отмечай пройденное** — чекбоксы ниже.
4. Каждая заметка заканчивается разделами «Грабли и мифы» и «Связанное» — это самые полезные части при возврате к теме.

## Соглашения

| Термин | Значение |
|---|---|
| **Страница (page/block)** | 8 КБ единица хранения и чтения; всё измеряется в страницах |
| **Кортеж (tuple)** | Физическая версия строки на странице (не строка таблицы!) |
| **Отношение (relation)** | Таблица/индекс/последовательность — объект с `relfilenode` |
| **Snapshot** | Набор транзакций, которые «видит» запрос в момент старта |
| **Bloat** | Мусорные мёртвые кортежи, раздувающие файл таблицы/индекса |

Смежные заметки вне ветки: [[ACID]], [[изоляция транзакций]], [[Партиции]], [[продвинутые техники]], [[шардирование]], [[Реализации кэширования]]. Файл `BLOB,CLOB.md` в этой же папке — про хранение больших объектов.

## Минимальный набор источников

- **Официальная документация**, раздел *Internals*: Storage, WAL, MVCC, Query Planner/Optimizer — единственный первоисточник, всегда сверяйся с версией.
- **Егор Рогов, «PostgreSQL 14 Internals»** (postgrespro) — лучший старт по внутрянке, главы про страницы/MVCC/WAL/планировщик.
- **Hironobu Suzuki, «The Internals of PostgreSQL»** — бесплатно, много схем.
- **Use The Index, Luke** (Markus Winand) — индексы и SQL-антипаттерны без привязки к СУБД.
- **CYBERTEC blog**, **pgexercises**, **PG wiki**, **pev2 / explain.dalibo.com** — для разбора реальных планов.

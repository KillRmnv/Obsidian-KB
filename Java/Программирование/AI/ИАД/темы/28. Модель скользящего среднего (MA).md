# 28. Модель скользящего среднего (MA)

Модель скользящего среднего (Moving Average, MA) — стохастическая модель временного ряда, в которой текущее значение выражается как линейная комбинация текущего и нескольких прошлых значений случайной ошибки (шока). Важно не путать её с методом скользящей средней для сглаживания временных рядов — это разные концепции. Формула модели MA порядка q: **yₜ = μ + εₜ + θ₁εₜ₋₁ + θ₂εₜ₋₂ + … + θ_q εₜ₋_q_**, где μ — математическое ожидание ряда, θᵢ — коэффициенты скользящего среднего, εₜ — белый шум, q — порядок модели. Содержательно модель MA отражает ситуацию, когда временный ряд испытывает влияние случайных шоков, эффект которых сохраняется в течение q последующих моментов времени, а затем исчезает («короткая память»). MA-процесс всегда стационарен по построению, так как является конечной линейной комбинацией стационарных случайных величин. Условие обратимости MA-процесса (возможность представления в виде бесконечной AR): корни характеристического полинома 1 + θ₁z + … + θ_q z^q = 0 должны лежать вне единичного круга. Параметры модели оцениваются методом максимального правдоподобия (МНК не применим напрямую, так как εₜ ненаблюдаемы). Порядок q определяется по графику автокорреляционной функции (ACF): значимые лаги в ACF при затухающей PACF указывают порядок MA. Применение в чистом виде встречается редко; чаще MA используется в составе моделей ARMA(p, q) и ARIMA(p, d, q), которые объединяют сильные стороны обеих компонент: AR описывает инерционность, MA — реакцию на шоки. Идентификация AR/MA/ARMA по корреляционным функциям — ключевой элемент методологии Бокса-Дженкинса.

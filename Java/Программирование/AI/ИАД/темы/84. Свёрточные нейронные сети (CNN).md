# 84. Свёрточные нейронные сети (CNN)

Свёрточные нейронные сети (Convolutional Neural Networks, CNN) — специализированный класс нейронных сетей, разработанный для обработки данных с пространственной или временной структурой, в первую очередь изображений. Архитектура биологически вдохновлена работой зрительной коры (Хьюбел и Визел) и формализована Яном Лекуном (LeNet, 1998); прорыв CNN в массовом машинном обучении — AlexNet (Крижевский, Хинтон, 2012), победитель ImageNet. Ключевые компоненты CNN. 1) Свёрточный слой (convolution) — основной строительный блок: применяет небольшие обучаемые фильтры (ядра, kernels, обычно 3×3 или 5×5) к входному изображению; каждый фильтр «скользит» по изображению, на каждой позиции вычисляется свёртка (поэлементное умножение со сложением), результат — карта признаков (feature map), отражающая активацию данного фильтра в разных областях входа. 2) Параметры свёртки: размер фильтра, шаг (stride), дополнение (padding), число фильтров. 3) Функция активации (обычно ReLU) применяется к карте признаков. 4) Слой подвыборки (pooling, обычно max pooling 2×2) — снижает пространственное разрешение, выделяя наиболее значимые активации, уменьшает число параметров и обеспечивает инвариантность к малым сдвигам. 5) После нескольких пар свёртка+пулинг следуют полносвязные слои (fully connected) для финальной классификации; современные архитектуры заменяют их global average pooling. Ключевые принципы CNN: разделяемые веса (один и тот же фильтр применяется ко всем позициям — резкое снижение числа параметров), локальная связность (нейрон видит только малую область входа — рецептивное поле), иерархическое извлечение признаков (нижние слои — края, верхние — сложные паттерны и объекты). Известные архитектуры: LeNet (распознавание цифр), AlexNet (2012), VGG (2014), GoogLeNet/Inception, ResNet (2015, с остаточными связями для очень глубоких сетей), DenseNet, EfficientNet, MobileNet (мобильные устройства). Применения: классификация изображений, детекция объектов (YOLO, R-CNN), сегментация (U-Net, Mask R-CNN), генерация изображений, медицинская визуализация, распознавание лиц, видеоаналитика, обработка одномерных сигналов и временных рядов (1D-CNN), обработка текстов. С 2020-х CNN постепенно вытесняются Vision Transformer (ViT) в задачах высокой сложности, но остаются стандартом во многих практических применениях.

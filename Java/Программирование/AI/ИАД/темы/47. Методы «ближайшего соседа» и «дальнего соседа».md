# 47. Методы «ближайшего соседа» и «дальнего соседа»

Методы «ближайшего соседа» (Single Linkage) и «дальнего соседа» (Complete Linkage) — два классических способа определения расстояния между кластерами в иерархической агломеративной кластеризации, лежащие в основе многих алгоритмов. Метод ближайшего соседа (Single Linkage, метод одиночной связи) — определяет расстояние между двумя кластерами как минимальное расстояние между парой объектов, по одному из каждого кластера: **d(A, B) = min{d(x, y) : x ∈ A, y ∈ B}**. Геометрически кластеры объединяются по «ближайшим» точкам, что позволяет выявлять кластеры произвольной, в том числе вытянутой и сложной (несферической) формы. Достоинства: способность выявлять кластеры произвольной формы, простота, эффективная реализация через алгоритм минимального остовного дерева. Недостатки: высокая чувствительность к шуму и выбросам, склонность к эффекту «цепочки» (chaining effect) — последовательное присоединение объектов через тонкие «мосты» приводит к образованию вытянутых, размытых кластеров, объединяющих фактически разные группы; в результате выделяемые кластеры часто плохо различимы. Метод дальнего соседа (Complete Linkage, метод полной связи) — определяет расстояние между двумя кластерами как максимальное расстояние между парой объектов, по одному из каждого кластера: **d(A, B) = max{d(x, y) : x ∈ A, y ∈ B}**. Кластеры объединяются по «самым дальним» точкам, что приводит к консервативному объединению. Достоинства: образует компактные, плотные кластеры с малым диаметром, устойчив к эффекту цепочки, хорошо разделяет шарообразные группы. Недостатки: высокая чувствительность к выбросам (одна крайняя точка определяет всё расстояние между кластерами), склонность к образованию кластеров примерно одинакового размера, может разрывать естественные вытянутые кластеры. Промежуточный вариант — метод средней связи (Average Linkage, UPGMA): расстояние определяется как среднее по всем парам объектов из разных кластеров; обеспечивает компромисс между свойствами single и complete linkage, обычно даёт сбалансированные результаты. Выбор метода зависит от ожидаемой формы кластеров и характеристик данных.

# 16. Логистическая регрессия: сущность, приложения

Логистическая регрессия — метод бинарной классификации, моделирующий вероятность принадлежности объекта к одному из двух классов на основе значений независимых переменных. Несмотря на название «регрессия», это классификационный алгоритм, но в его основе лежит регрессионная модель. Сущность: линейная комбинация факторов z = β₀ + β₁X₁ + … + βₙXₙ преобразуется через логистическую (сигмоидную) функцию для получения вероятности: **P(Y=1|X) = 1 / (1 + e^(-z))**. Сигмоида отображает любое значение z из диапазона (−∞, +∞) в интервал (0, 1), что соответствует вероятности. Для классификации задаётся порог (обычно 0,5): если P ≥ порог — класс 1, иначе — класс 0. Коэффициенты оцениваются методом максимального правдоподобия (MLE), а не МНК. Коэффициенты βᵢ интерпретируются через отношение шансов (odds ratio = e^β): показывают, во сколько раз изменятся шансы события при увеличении фактора на единицу. Качество модели оценивается метриками классификации: accuracy, precision, recall, F1-score, ROC-кривая и AUC, log-loss. Приложения: кредитный скоринг (вероятность дефолта), медицинская диагностика (вероятность заболевания), маркетинг (отклик на кампанию, отток клиентов), антифрод-системы, прогнозирование исхода события. Существует обобщение на множество классов — мультиномиальная логистическая регрессия (softmax-регрессия). Преимущества — простота, интерпретируемость, вероятностный выход; недостаток — допущение линейной разделимости в пространстве признаков.

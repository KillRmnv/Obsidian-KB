# 53. Классификационные правила

Классификационные правила — простейшая и наиболее интерпретируемая форма представления знаний в задачах классификации, имеющая вид логических выражений «если-то» (if-then rules): «ЕСЛИ выполняется условие на признаки, ТО объект относится к классу C». Общая форма правила: IF (X₁ = a₁) AND (X₂ < a₂) AND … AND (Xₙ ∈ A) THEN Class = C. Левая часть (антецедент, условие) — конъюнкция простых условий на признаки; правая часть (консеквент, заключение) — предсказываемый класс. Совокупность правил образует классификатор: при классификации нового объекта проверяются условия правил, и принимается решение по сработавшему правилу. Виды наборов правил. 1) Упорядоченные списки правил (decision lists) — правила проверяются последовательно, первое сработавшее определяет класс; включает финальное правило «по умолчанию» для неклассифицированных объектов. 2) Неупорядоченные множества правил (rule sets) — все правила равноправны; при срабатывании нескольких применяются стратегии разрешения конфликтов (голосование, выбор по достоверности). Свойства качественных правил — каждое правило характеризуется метриками: покрытие (coverage, support) — доля объектов выборки, для которых выполняется условие; точность (accuracy, confidence) — доля правильно классифицированных среди покрываемых объектов; ёмкость (capture) — доля объектов класса, охваченных правилом. Хорошие правила имеют высокое покрытие и высокую точность, но обычно есть компромисс. Методы построения правил. 1) Прямое извлечение из деревьев решений: каждый путь от корня к листу соответствует одному правилу. 2) Алгоритмы покрытия (covering algorithms): последовательно строят правила, каждое покрывает часть оставшихся объектов одного класса (CN2, RIPPER, AQ, PRISM). 3) Ассоциативные классификаторы — на основе ассоциативных правил с фильтрацией по классу (CBA, CMAR). 4) 1R — простейший алгоритм одиночных правил. Преимущества классификационных правил: высокая интерпретируемость (легко объяснить решение), компактность, возможность экспертной проверки и редактирования, эффективная классификация. Недостатки: трудность построения оптимального набора, склонность к переобучению при большом числе правил, сложность работы с непрерывными признаками (требуется дискретизация), потенциальные конфликты между правилами. Применения: экспертные системы, медицинская диагностика, кредитный скоринг, диагностика технических неисправностей — задачи, где важна прозрачность решения.

# 38. Модели на базе классификационно-регрессионных деревьев

Классификационно-регрессионные деревья (CART — Classification And Regression Trees), предложенные Брейманом в 1984 году — непараметрический метод машинного обучения, представляющий модель в виде иерархической древовидной структуры. Каждый внутренний узел дерева содержит правило разделения по одному из признаков (например, X₂ < 5,2), каждая ветвь соответствует исходу проверки, каждый лист — итоговому предсказанию (класс для классификации или числовое значение для регрессии). Процесс построения дерева — рекурсивное разбиение обучающей выборки: на каждом шаге выбирается признак и порог разделения, обеспечивающие наилучшее разделение по выбранному критерию. Критерии разделения для классификации: индекс Джини, энтропия (прирост информации); для регрессии: уменьшение суммы квадратов отклонений (дисперсии) в узлах. Алгоритм останавливается при достижении одного из условий: минимальное число объектов в узле, максимальная глубина дерева, отсутствие значимого улучшения критерия. Для борьбы с переобучением применяется обрезка (pruning) — удаление маловажных ветвей по критерию минимальной стоимости-сложности (cost-complexity pruning). Преимущества: высокая интерпретируемость (модель легко представить визуально и в виде набора правил), работа с числовыми и категориальными признаками без предварительной обработки, нечувствительность к масштабу и распределению данных, автоматическое обнаружение взаимодействий между признаками, устойчивость к выбросам. Недостатки: склонность к переобучению (особенно глубокие деревья), высокая дисперсия (небольшое изменение данных может полностью изменить структуру дерева), кусочно-постоянные предсказания, плохая аппроксимация гладких зависимостей, склонность к смещению в сторону признаков с большим числом уникальных значений. Для устранения недостатков отдельных деревьев разработаны ансамблевые методы: случайный лес (Random Forest), бустинг (AdaBoost, GBM, XGBoost, LightGBM, CatBoost), которые объединяют сотни и тысячи деревьев и обеспечивают высокую точность прогнозов. Применения: кредитный скоринг, медицинская диагностика, прогнозирование оттока, классификация клиентских сегментов, прогнозирование спроса.

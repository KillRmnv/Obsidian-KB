# 79. Основные типы правил обучения

Правила обучения нейронных сетей классифицируются по характеру использования данных и обратной связи. 1) Обучение с учителем (supervised learning) — наиболее распространённый тип; используется размеченная выборка с парами (x, y), и сеть обучается минимизировать ошибку между предсказаниями и истинными метками. Правило Розенблатта (правило персептрона): wᵢ ← wᵢ + η·(y − ŷ)·xᵢ — коррекция весов пропорционально ошибке. Дельта-правило (Видроу-Хоффа, LMS): обобщение Розенблатта на непрерывные функции активации, минимизация квадратичной ошибки. Правило обратного распространения ошибки (backpropagation) — обобщение дельта-правила на многослойные сети. 2) Обучение без учителя (unsupervised learning) — без меток, сеть самостоятельно выявляет структуру в данных. Правило Хебба (1949): «нейроны, активирующиеся вместе, связываются вместе»: wᵢ ← wᵢ + η·xᵢ·x — усиление связи между совместно активными нейронами; биологически правдоподобный принцип, лежащий в основе многих ассоциативных моделей. Конкурентное обучение (competitive learning) — нейроны соревнуются за «право» представить входной вектор; обновляется только победивший («winner-takes-all»); основа самоорганизующихся карт Кохонена (SOM). 3) Обучение с подкреплением (reinforcement learning) — агент учится через взаимодействие со средой, получая вознаграждение или штраф за действия; правила обновления основаны на сигналах вознаграждения (Q-learning, policy gradient, actor-critic, в том числе с использованием нейронных сетей — DQN, A3C, PPO). 4) Полу-обучение с учителем (semi-supervised) и обучение с самообучением (self-supervised) — гибридные подходы, использующие частично размеченные данные или формирующие задачи разметки автоматически. Современные большие модели (BERT, GPT) обучаются преимущественно по самообучающимся правилам на огромных корпусах неразмеченного текста.

# 42. Геометрическая интерпретация задачи кластеризации

Геометрически объекты, подлежащие кластеризации, представляются как точки в n-мерном признаковом пространстве, где n — число признаков, описывающих каждый объект. Координатами каждой точки служат значения признаков соответствующего объекта. Кластеризация в этой интерпретации сводится к выявлению в этом пространстве плотных скоплений точек, разделённых областями с малой плотностью. Хороший кластер геометрически представляет собой компактную «облако» точек, расположенных близко друг к другу, при этом разные кластеры пространственно разделены. Близость точек измеряется через метрики расстояния (евклидово, манхэттенское и др.), а плотность — через число точек в окрестности заданного радиуса. Различные алгоритмы кластеризации соответствуют различным геометрическим интерпретациям: k-means ищет сферические кластеры, минимизируя расстояния до центроидов и разбивая пространство на ячейки Вороного; иерархическая кластеризация последовательно объединяет ближайшие точки/группы, формируя древовидную структуру; DBSCAN ищет связные области высокой плотности произвольной формы, разделённые редкими областями; модельные методы (GMM) описывают кластеры как многомерные распределения с эллипсоидальными формами. Граница между кластерами геометрически интерпретируется как поверхность раздела в пространстве. Проблемы геометрической интерпретации возникают в высокоразмерных пространствах (проклятие размерности): с ростом числа признаков расстояния между всеми точками становятся примерно одинаковыми, и понятие близости теряет смысл; для борьбы применяются методы снижения размерности (PCA, t-SNE, UMAP), позволяющие также визуализировать результаты в 2D или 3D. Сложности также возникают при наличии разномасштабных признаков (требуется нормализация) и кластеров сложной формы (полумесяцев, спиралей), которые не выявляются стандартными методами. Геометрическая визуализация — важный инструмент валидации результатов кластеризации.

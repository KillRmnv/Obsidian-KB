# 73. Искусственная модель нейрона

Стандартная искусственная модель нейрона (McCulloch & Pitts, 1943, в современной форме) — вычислительный элемент с n входами и одним выходом. Этапы работы: 1) на вход подаются значения x₁, x₂, …, xₙ; 2) каждому входу соответствует синаптический вес wᵢ, отражающий силу связи; 3) вычисляется взвешенная сумма (линейная комбинация): **z = Σᵢ wᵢ·xᵢ + b**, где b — смещение (порог со знаком минус); 4) к z применяется функция активации φ, обычно нелинейная: y = φ(z). Веса и смещение — обучаемые параметры. Геометрически нейрон с пороговой активацией реализует разделяющую гиперплоскость в признаковом пространстве: положительные и отрицательные значения z соответствуют разным сторонам плоскости. Функция активации обеспечивает нелинейность, без которой сеть из любого числа слоёв сводилась бы к одной линейной модели. Различные типы нейронов отличаются функцией активации: пороговый нейрон МакКаллока-Питтса (step function), сигмоидальный, ReLU-нейрон, tanh-нейрон. Несмотря на простоту, ансамбли таких нейронов в многослойных архитектурах способны аппроксимировать произвольные непрерывные функции (теорема универсальной аппроксимации Цыбенко, 1989).

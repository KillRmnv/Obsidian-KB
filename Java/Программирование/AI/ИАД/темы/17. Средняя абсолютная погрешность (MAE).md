# 17. Средняя абсолютная погрешность (MAE)

Средняя абсолютная погрешность (Mean Absolute Error, MAE) — одна из базовых метрик качества регрессионных моделей. Формула: **MAE = (1/n)·Σ|yᵢ − ŷᵢ|**, где yᵢ — фактическое значение, ŷᵢ — предсказанное, n — число наблюдений. Метрика показывает среднюю величину абсолютного отклонения предсказаний от истинных значений в исходных единицах измерения зависимой переменной, что делает её интуитивно понятной. Например, если Y — цена в долларах, то MAE = 50 означает, что модель в среднем ошибается на $50. Чем меньше значение MAE, тем выше качество модели; минимальное возможное значение — 0 (идеальное предсказание). Главное преимущество MAE — устойчивость к выбросам: одиночные большие ошибки не доминируют над общей оценкой, так как ошибки не возводятся в квадрат. По той же причине MAE менее чувствительна к выбросам по сравнению с MSE/RMSE. Недостаток — недифференцируемость функции модуля в нуле, что усложняет применение в алгоритмах градиентной оптимизации (но решается субградиентными методами). MAE особенно подходит, когда важна линейная штрафная функция и все ошибки равноценны независимо от величины. Часто используется совместно с MSE/RMSE для получения более полной картины качества модели.

# 85. Ассоциативные запоминающие сети. Сеть Хопфилда

Ассоциативные запоминающие сети — класс нейронных сетей, имитирующих ассоциативную память: способность восстанавливать полный образ по частичному или искажённому фрагменту. Главный представитель — сеть Хопфилда, предложенная Джоном Хопфилдом в 1982 году; его работа возродила интерес к нейронным сетям и заложила основы современной науки о нейровычислениях (за неё Хопфилд получил Нобелевскую премию по физике в 2024 году). Архитектура: рекуррентная сеть с полной взаимной связью, состоящая из N нейронов с бинарными состояниями (±1 или 0/1); каждый нейрон соединён с каждым (кроме самого себя), связи симметричны (wᵢ = wᵢ, wᵢᵢ = 0). Принцип работы: сети «обучаются» запоминать набор паттернов (образов) через формирование весов по правилу Хебба: **wᵢ = (1/N)·Σₖ ξᵢᵏ·ξᵏ**, где ξᵏ — k-й запоминаемый паттерн. При предъявлении искажённого или неполного входа сеть итеративно обновляет состояния нейронов до достижения устойчивого состояния (аттрактора), которое и является «восстановленным» воспоминанием. Динамика сети управляется функцией энергии: E = −(1/2)·Σ wᵢ·sᵢ·s, которая монотонно убывает при асинхронных обновлениях, гарантируя сходимость к локальному минимуму. Запомненные паттерны соответствуют локальным минимумам энергии; неточный вход «скатывается» в ближайший минимум. Ёмкость сети ограничена: число надёжно запоминаемых паттернов ≈ 0,14·N. Недостатки: ограниченная ёмкость, ложные аттракторы (паттерны, не входившие в обучение, но являющиеся локальными минимумами), застревание в плохих минимумах. Развитие: машина Больцмана (стохастическая версия), современные «современные сети Хопфилда» (Ramsauer et al., 2020) с экспоненциальной ёмкостью, тесно связанные с механизмом внимания в Transformer. Применения: ассоциативная память, восстановление образов, распознавание с шумом, оптимизационные задачи (задача коммивояжёра через формулировку энергии).

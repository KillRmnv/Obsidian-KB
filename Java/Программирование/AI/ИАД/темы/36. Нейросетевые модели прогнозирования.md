# 36. Нейросетевые модели прогнозирования

Нейронные сети — класс моделей машинного обучения, имитирующих принцип работы биологических нейронов, способных выявлять сложные нелинейные зависимости в данных. В задачах прогнозирования временных рядов и регрессии применяются различные архитектуры. 1) Многослойный персептрон (MLP) — классическая нейросеть прямого распространения с входным, скрытыми и выходным слоями; для прогнозирования временного ряда на вход подаётся окно прошлых значений, на выходе — будущее значение. 2) Рекуррентные нейронные сети (RNN) — сети с обратными связями, специально разработанные для последовательных данных; имеют «память» о предыдущих состояниях, но страдают от проблемы исчезающего/взрывающегося градиента. 3) LSTM (Long Short-Term Memory) — усовершенствованная RNN с механизмом ячеек памяти и вентилей (forget, input, output), эффективно работающая с длинными зависимостями; стандарт для прогнозирования временных рядов. 4) GRU (Gated Recurrent Unit) — упрощённая версия LSTM с меньшим числом параметров. 5) Свёрточные сети (CNN, TCN) — применяются для извлечения локальных паттернов в рядах. 6) Трансформеры (Transformer, Informer, Autoformer) — современные модели на основе механизма внимания, эффективно обрабатывающие длинные последовательности параллельно. 7) Гибридные модели и специализированные архитектуры — N-BEATS, DeepAR (вероятностный прогноз), Temporal Fusion Transformer. Обучение нейросетей происходит методом обратного распространения ошибки с использованием градиентных оптимизаторов (Adam, SGD), функция потерь — обычно MSE или MAE. Преимущества: способность моделировать сложные нелинейности, работа с многомерными и разнородными данными, учёт экзогенных факторов, высокая точность при достаточном объёме данных. Недостатки: требуют больших объёмов обучающих данных, низкая интерпретируемость («чёрный ящик»), высокая вычислительная сложность, риск переобучения, сложность подбора архитектуры и гиперпараметров. Применяются в энергетике, финансах, прогнозировании спроса, обработке датчиков, климатических моделях.

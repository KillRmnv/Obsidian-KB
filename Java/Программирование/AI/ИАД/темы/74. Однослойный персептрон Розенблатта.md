# 74. Однослойный персептрон Розенблатта

Однослойный персептрон Розенблатта — первая обучаемая модель искусственной нейронной сети, предложенная Фрэнком Розенблаттом в 1957–1958 годах; реализация была воплощена в виде физического устройства «Mark I Perceptron» для распознавания изображений. Архитектура: входной слой признаков x₁, …, xₙ напрямую соединён с одним выходным нейроном через настраиваемые веса w₁, …, wₙ; нейрон вычисляет z = Σwᵢxᵢ + b и применяет пороговую функцию активации (sign или step), выдавая бинарный ответ (+1 или −1 / 0 или 1). Геометрически персептрон строит линейную разделяющую гиперплоскость в признаковом пространстве, реализуя бинарную классификацию. Правило обучения персептрона: для каждого неверно классифицированного объекта веса корректируются по формуле **wᵢ ← wᵢ + η·(y − ŷ)·xᵢ**, где y — истинная метка, ŷ — предсказание, η — скорость обучения. Главное ограничение, показанное Минским и Пейпертом в 1969 году: персептрон способен решать только линейно разделимые задачи и не справляется с простейшей нелинейной задачей XOR. Это открытие на десятилетие практически остановило развитие нейронных сетей до изобретения алгоритма обратного распространения ошибки. Тем не менее, персептрон стал концептуальной основой для всех современных нейронных сетей.

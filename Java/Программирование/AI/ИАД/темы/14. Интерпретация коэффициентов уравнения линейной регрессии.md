# 14. Интерпретация коэффициентов уравнения линейной регрессии

Коэффициенты линейной регрессии имеют содержательную интерпретацию, что является важным преимуществом метода. Свободный член β₀ (intercept) — это ожидаемое значение зависимой переменной Y при равенстве всех факторов нулю; его экономическая интерпретация осмысленна не всегда (например, при X — рост человека). Коэффициент регрессии βᵢ показывает, на сколько единиц в среднем изменится Y при увеличении фактора Xᵢ на одну единицу при условии, что остальные факторы зафиксированы (ceteris paribus). Знак коэффициента указывает направление связи: положительный — прямая зависимость, отрицательный — обратная. Величина коэффициента отражает силу влияния, однако коэффициенты в исходных единицах несопоставимы между собой из-за разных масштабов переменных. Для сравнения влияния факторов используют стандартизованные (бета) коэффициенты, рассчитанные на нормированных данных — они показывают, на сколько стандартных отклонений изменится Y при изменении Xᵢ на одно стандартное отклонение. Статистическая значимость коэффициентов проверяется t-критерием Стьюдента: если p-value меньше уровня значимости (обычно 0,05), коэффициент признаётся значимым. Для каждого коэффициента строится доверительный интервал. При наличии мультиколлинеарности интерпретация коэффициентов становится затруднительной — они теряют устойчивость и могут менять знак. В моделях с логарифмированием коэффициенты интерпретируются как эластичности или процентные изменения.

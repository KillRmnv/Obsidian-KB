# 71. Понятие искусственного нейрона и искусственной нейронной сети

Искусственный нейрон — упрощённая математическая модель биологического нейрона, представляющая собой вычислительную единицу, которая принимает несколько входных сигналов, преобразует их и выдаёт один выходной сигнал. Формально нейрон вычисляет взвешенную сумму входов **z = Σ wᵢ·xᵢ + b**, к которой применяется функция активации φ(z), дающая выходное значение y = φ(z). Здесь xᵢ — входы, wᵢ — синаптические веса (степень влияния каждого входа), b — смещение (bias), φ — нелинейная функция. Веса и смещение — настраиваемые параметры, изменяющиеся в процессе обучения. Искусственная нейронная сеть (ИНС, ANN) — совокупность связанных между собой искусственных нейронов, объединённых в слои, способная аппроксимировать сложные функции и решать задачи классификации, регрессии, кластеризации, генерации данных. Стандартная архитектура включает входной слой (получает признаки), один или несколько скрытых слоёв (выполняют преобразование) и выходной слой (формирует ответ). Глубокие нейронные сети (deep learning) — сети с большим числом скрытых слоёв, способные автоматически извлекать иерархические признаки из сырых данных. Знания в сети распределены по весам соединений, и обучение сводится к их настройке для минимизации ошибки.

# 15. Типы нелинейных регрессионных моделей и их линеаризация

Когда зависимость между переменными не описывается прямой линией, применяются нелинейные регрессионные модели. Различают два типа нелинейности: нелинейность по переменным (модель линейна по параметрам β) и нелинейность по параметрам. Модели, нелинейные только по переменным, легко сводятся к линейным заменой переменных. Основные типы и способы линеаризации: 1) Полиномиальная модель Y = β₀ + β₁X + β₂X² + ... + ε — линеаризуется введением новых переменных X₁=X, X₂=X² и т.д.; применяется для описания изгибов. 2) Степенная модель Y = β₀·X^β₁ — логарифмированием обеих частей сводится к ln Y = ln β₀ + β₁·ln X; коэффициент β₁ интерпретируется как эластичность. 3) Показательная (экспоненциальная) модель Y = β₀·e^(β₁X) — логарифмированием: ln Y = ln β₀ + β₁X. 4) Логарифмическая модель Y = β₀ + β₁·ln X — линейна после замены Z = ln X. 5) Гиперболическая модель Y = β₀ + β₁/X — линеаризуется заменой Z = 1/X. 6) Обратная (S-образная) модель Y = 1/(β₀ + β₁X) — линеаризуется заменой Z = 1/Y. Модели, нелинейные по параметрам и не поддающиеся линеаризации (например, логистическая или Гомпертца), оцениваются итерационными численными методами (метод Гаусса-Ньютона, Левенберга-Марквардта). Выбор модели основывается на содержательных соображениях, анализе диаграммы рассеяния и сравнении качества подгонки (R², AIC, BIC).

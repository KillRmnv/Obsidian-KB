# 66. Случайный лес (Random Forest)

Случайный лес (Random Forest) — один из самых популярных и эффективных алгоритмов машинного обучения, предложенный Лео Брейманом в 2001 году; представляет собой ансамбль деревьев решений, объединяющий идеи бэггинга и случайного отбора признаков. Random Forest широко применяется в задачах классификации и регрессии и считается одним из лучших универсальных алгоритмов «из коробки». Алгоритм. 1) Генерация B бутстрап-подвыборок из исходных данных размера n (как в бэггинге). 2) На каждой подвыборке строится решающее дерево без обрезки (часто очень глубокое), но с важной модификацией: в каждом узле для выбора лучшего разделения рассматривается не все p признаков, а только случайно выбранное подмножество размера m (random subspace в каждом узле). Типичные значения m: для классификации — m = √p, для регрессии — m = p/3, но это гиперпараметр для настройки. 3) Каждое дерево обучается полностью (или с мягкими ограничениями: min_samples_leaf, max_depth) — деревья сознательно делаются переобученными (высокая дисперсия, низкое смещение), это компенсируется ансамблированием. 4) Финальное предсказание: для классификации — мажоритарное голосование, для регрессии — усреднение предсказаний всех деревьев. Двойная рандомизация (бутстрап объектов + случайный отбор признаков) обеспечивает низкую корреляцию между деревьями, что усиливает эффект ансамблирования по сравнению с обычным бэггингом деревьев. OOB-оценка и важность признаков: Random Forest предоставляет OOB-error без отдельной валидации; важность признаков (feature importance) рассчитывается двумя способами — на основе среднего уменьшения нечистоты (Mean Decrease in Impurity, MDI) и на основе перестановки значений (Permutation Importance). Достоинства Random Forest. 1) Высокая точность из коробки без тонкой настройки гиперпараметров; конкурентоспособен с современными методами на задачах со структурированными данными. 2) Устойчивость к переобучению благодаря двойной рандомизации; добавление новых деревьев не приводит к переобучению (в отличие от градиентного бустинга). 3) Работа с числовыми и категориальными признаками без сложной предобработки. 4) Нечувствительность к выбросам и шуму. 5) Не требует масштабирования признаков. 6) Естественная работа с пропусками в данных. 7) Высокая параллелизуемость (деревья независимы) — обучение легко распараллеливается. 8) Встроенная OOB-валидация. 9) Оценка важности признаков для интерпретации. 10) Работает на больших выборках и в высокой размерности. 11) Эффективен при дисбалансе классов (с параметром class_weight). 12) Универсальность: классификация, регрессия, выявление аномалий (Isolation Forest — связанный метод). Недостатки. 1) Снижение интерпретируемости по сравнению с одиночным деревом (тысячи деревьев нельзя визуализировать). 2) Большой размер модели в памяти (сотни мегабайт на больших задачах). 3) Медленное предсказание для больших ансамблей (обход всех деревьев). 4) Уступает градиентному бустингу по точности на хорошо настроенных задачах. 5) Смещённая оценка важности признаков в пользу признаков с большим числом уникальных значений (особенно для категориальных). 6) Плохо экстраполирует за пределы диапазона обучающей выборки в регрессии (свойство деревьев). 7) Менее эффективен на разреженных данных (текст с TF-IDF) по сравнению с линейными моделями. Применения: кредитный скоринг, медицинская диагностика, биоинформатика, прогнозирование оттока клиентов, ранжирование, рекомендательные системы.

# 83. Самоорганизующиеся нейронные сети. Сети Кохонена

Самоорганизующиеся карты Кохонена (SOM, Self-Organizing Maps), предложенные Теуво Кохоненом в 1980-х годах — класс нейронных сетей, обучающихся без учителя на основе принципа конкурентного обучения. Главная цель — снижение размерности и визуализация многомерных данных с сохранением топологии: близкие в исходном пространстве объекты остаются близкими и в спроецированном (обычно двумерном) пространстве. Архитектура: входной слой соответствует признакам объектов; выходной слой — двумерная (реже одномерная) решётка нейронов, каждому из которых соответствует свой вектор весов wᵢ той же размерности, что и входы. Алгоритм обучения. 1) Инициализация весов нейронов случайно или с использованием PCA. 2) Для каждого объекта обучающей выборки находится «нейрон-победитель» (Best Matching Unit, BMU) — нейрон с минимальным расстоянием своих весов до входа: **i* = argmin ‖x − wᵢ‖**. 3) Обновляются веса нейрона-победителя и его соседей в решётке по правилу: **wᵢ ← wᵢ + η·h(i, i*)·(x − wᵢ)**, где h(i, i*) — функция соседства (обычно гауссова), убывающая с расстоянием от победителя; η — скорость обучения. 4) В ходе обучения радиус соседства и скорость обучения постепенно уменьшаются. Результат — упорядоченная карта, в которой близкие нейроны представляют похожие области входного пространства. Преимущества: визуализация и интерпретация многомерных данных, кластеризация без задания числа кластеров, сохранение топологии, устойчивость к шумам. Недостатки: чувствительность к начальной инициализации, сложность интерпретации границ кластеров, фиксированный размер карты, низкое качество на сложных нелинейных структурах по сравнению с современными методами (t-SNE, UMAP). Применения: визуализация данных, сегментация клиентов, биоинформатика, анализ финансовых данных, обработка изображений и текстов.

# 58. Энтропия. Прирост информации

Энтропия (entropy, информационная энтропия Шеннона) — фундаментальная мера неопределённости, или «беспорядка», в распределении значений случайной величины, введённая Клодом Шенноном в 1948 году в теории информации. В задачах построения деревьев решений энтропия используется для количественной оценки однородности выборки по целевому признаку (классу). Формула энтропии для дискретного распределения по K классам: **H(S) = − Σᵢ pᵢ·log₂(pᵢ)**, где pᵢ — доля объектов класса i в множестве S. Свойства энтропии: 1) H(S) = 0, если все объекты принадлежат одному классу (полная определённость, «чистое» множество); 2) H(S) максимальна и равна log₂(K), когда классы представлены равными долями (максимальная неопределённость); 3) для бинарной классификации максимум H = 1 бит при p = 0,5; 4) энтропия неотрицательна и симметрична относительно перестановок классов. Интуитивно энтропия отвечает на вопрос: «сколько в среднем бит информации нужно для определения класса случайно взятого объекта из выборки?». Чем выше однородность по классу, тем ниже энтропия. Прирост информации (Information Gain, IG) — ключевой критерий выбора признака для разделения в алгоритме ID3 и его развитии C4.5; показывает, насколько уменьшается энтропия (неопределённость) при разделении выборки по выбранному признаку. Формула: **IG(S, A) = H(S) − Σᵥ (|Sᵥ|/|S|)·H(Sᵥ)**, где A — признак разделения, Sᵥ — подмножество S, где признак A принимает значение v; второе слагаемое — взвешенная средняя энтропия дочерних подмножеств. Большое значение IG означает, что разделение по признаку A существенно повышает «чистоту» получаемых подмножеств — такой признак является информативным. Алгоритм построения дерева на основе IG: на каждом узле перебираются все доступные признаки, вычисляется IG для разделения по каждому, и выбирается признак с максимальным IG. Недостаток прироста информации: смещение в сторону признаков с большим числом уникальных значений (например, ID-номера) — такие признаки дают идеальное разделение на множество мелких чистых подмножеств с высоким IG, но не несут реальной обобщающей способности (пример переобучения). Решение — нормированная версия Gain Ratio (коэффициент прироста), используемая в C4.5: GR(S, A) = IG(S, A) / SplitInfo(A), где SplitInfo учитывает количество и размеры подмножеств, штрафуя излишне дробящие признаки. Альтернативные критерии разделения: индекс Джини (используется в CART) и χ²-критерий (CHAID); все они служат той же цели — выбору признака, максимально уменьшающего неоднородность.

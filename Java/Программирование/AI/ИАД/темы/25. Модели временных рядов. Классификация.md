# 25. Модели временных рядов. Классификация

Модели временных рядов — математические описания, отражающие структуру и закономерности изменения наблюдений во времени, используемые для анализа и прогнозирования. Классификация моделей. 1) По характеру компонентов: трендовые (описывают долгосрочную тенденцию полиномами, экспонентой, логистической кривой), сезонные, трендово-сезонные (декомпозиционные модели Census X-12, STL), модели цикличности. 2) По способу формирования: аддитивные Y = T + S + C + ε (когда амплитуда сезонности постоянна) и мультипликативные Y = T·S·C·ε (когда амплитуда сезонности растёт со значением ряда). 3) По наличию случайной составляющей: детерминированные и стохастические. 4) Стохастические модели Бокса-Дженкинса: AR(p) — авторегрессия порядка p, текущее значение зависит от p предыдущих; MA(q) — скользящее среднее, зависит от прошлых ошибок; ARMA(p,q) — комбинация двух предыдущих; ARIMA(p,d,q) — для нестационарных рядов с d-кратным дифференцированием; SARIMA — с учётом сезонности; SARIMAX — с экзогенными переменными. 5) Модели экспоненциального сглаживания: простое (для рядов без тренда), модель Хольта (с трендом), модель Хольта-Уинтерса (с трендом и сезонностью), модели ETS. 6) Модели с условной гетероскедастичностью: ARCH, GARCH — учитывают изменчивость дисперсии (применяются в финансах). 7) Структурные модели пространства состояний (State Space Models), модель Калмана. 8) Многомерные модели: VAR (векторная авторегрессия), VECM (модели коррекции ошибок). 9) Модели машинного обучения: рекуррентные нейронные сети RNN, LSTM, GRU, Transformer, Prophet (Facebook), N-BEATS. Выбор модели определяется свойствами ряда: стационарность, сезонность, наличие тренда, длина ряда.

# 7. Алгоритмы предварительной обработки данных. Очистка данных

Предварительная обработка — приведение исходных данных к виду, пригодному для анализа и моделирования, занимает 60–80% времени всего проекта Data Mining. Качество подготовки напрямую определяет качество модели по принципу «garbage in — garbage out». Очистка данных решает несколько ключевых задач. Обработка пропущенных значений: удаление записей или признаков с большим числом пропусков, заполнение средним/медианой/модой, методы импутации (kNN, регрессия, многомерная импутация). Обнаружение и обработка выбросов: статистические методы (правило 3-сигма, межквартильный размах IQR), графические (boxplot), алгоритмические (Isolation Forest, LOF); выбросы удаляются, корректируются или выделяются отдельно. Устранение дубликатов — полных и частичных (приблизительное сопоставление строк). Исправление ошибок ввода и противоречий: опечатки, несогласованные значения в связанных полях. Унификация форматов: даты, единицы измерения, регистр строк, кодировки. Сглаживание шумов — биннинг, регрессия, кластеризация. Для категориальных данных — приведение синонимичных значений к единым категориям. Очистка должна документироваться, чтобы обеспечить воспроизводимость анализа.

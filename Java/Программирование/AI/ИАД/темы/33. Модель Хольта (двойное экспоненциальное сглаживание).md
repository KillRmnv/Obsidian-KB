# 33. Модель Хольта (двойное экспоненциальное сглаживание)

Модель Хольта (Holt's Linear Trend Method) — расширение простого экспоненциального сглаживания для прогнозирования временных рядов с трендом, но без сезонности. Также называется двойным экспоненциальным сглаживанием, так как использует два уравнения сглаживания: одно для уровня ряда, другое для тренда. Уравнения модели: **уровень Lₜ = α·yₜ + (1 − α)·(Lₜ₋₁ + Tₜ₋₁)**, **тренд Tₜ = β·(Lₜ − Lₜ₋₁) + (1 − β)·Tₜ₋₁**, где Lₜ — оценка текущего уровня, Tₜ — оценка текущего тренда (среднего прироста за период), α и β — параметры сглаживания (0 < α, β < 1). Формула прогноза на h периодов вперёд: ŷₜ₊ₕ = Lₜ + h·Tₜ — прогноз представляет прямую линию с наклоном, равным текущей оценке тренда. Содержательно: уровень обновляется как взвешенная сумма нового наблюдения и предсказания (прошлый уровень плюс тренд), тренд обновляется как взвешенная сумма свежей оценки наклона (разность уровней) и прошлой оценки тренда. Параметр α управляет скоростью реакции уровня на изменения, β — устойчивостью оценки тренда. Инициализация: L₁ = y₁, T₁ = y₂ − y₁ (или среднее приращение по первым нескольким точкам). Параметры α и β подбираются оптимизацией ошибки прогноза (минимизация MSE). Недостаток базовой модели Хольта — линейный тренд экстраполируется бесконечно, что нереалистично на длинных горизонтах. Для исправления применяется модификация с затухающим трендом (damped trend method) с дополнительным параметром φ (0 < φ < 1), при котором рост постепенно замедляется. Применяется для прогнозирования продаж, спроса и других показателей с устойчивым трендом без выраженной сезонности.

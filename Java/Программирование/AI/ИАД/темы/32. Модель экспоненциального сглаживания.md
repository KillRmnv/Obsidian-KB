# 32. Модель экспоненциального сглаживания

Простое (одинарное) экспоненциальное сглаживание (Simple Exponential Smoothing, SES) — метод прогнозирования временных рядов без выраженного тренда и сезонности, в котором сглаженное значение представляет собой взвешенную сумму всех прошлых наблюдений с экспоненциально убывающими весами. Основная формула рекуррентного вида: **Sₜ = α·yₜ + (1 − α)·Sₜ₋₁**, где Sₜ — сглаженное значение в момент t, yₜ — фактическое наблюдение, α — параметр сглаживания (0 < α < 1). Прогноз на любой горизонт вперёд равен последнему сглаженному значению: ŷₜ₊ₕ = Sₜ. Раскрытие рекуррентной формулы показывает, что каждое прошлое наблюдение учитывается с весом α(1−α)ᵏ, то есть веса убывают по геометрической прогрессии — более свежие данные влияют сильнее. Параметр α определяет «скорость забывания»: при α близком к 1 модель быстро реагирует на изменения, опираясь почти только на последние наблюдения (низкое сглаживание); при α близком к 0 модель инертна, сильно сглаживает, медленно реагирует на изменения уровня. Оптимальное значение α подбирается путём минимизации MSE (или другой метрики ошибки) на исторических данных. Инициализация: S₁ обычно полагается равным y₁ или среднему по первым нескольким значениям. Преимущества: простота вычислений, малое число параметров, малая потребность в данных, легко реализуется в реальном времени. Недостатки: не учитывает тренд (плохо прогнозирует растущие/убывающие ряды), не учитывает сезонность, прогноз на любой горизонт — константа. Для устранения этих ограничений разработаны расширения: модель Хольта (с трендом) и Хольта-Уинтерса (с трендом и сезонностью). Простое экспоненциальное сглаживание широко применяется в управлении запасами и оперативном прогнозировании.

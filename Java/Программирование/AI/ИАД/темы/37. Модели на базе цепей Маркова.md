# 37. Модели на базе цепей Маркова

Цепь Маркова — стохастическая модель случайного процесса с дискретным временем, в котором будущее состояние системы зависит только от текущего состояния и не зависит от предыстории (марковское свойство, или свойство отсутствия памяти). Формально: P(Xₜ₊₁ = j | X₀, X₁, …, Xₜ) = P(Xₜ₊₁ = j | Xₜ). Модель задаётся: 1) множеством возможных состояний {s₁, s₂, …, sₙ}; 2) начальным распределением вероятностей по состояниям; 3) матрицей переходных вероятностей P, где элемент pᵢ — вероятность перехода из состояния i в состояние j за один шаг (строки матрицы суммируются в 1). Существуют цепи с дискретным временем (DTMC) и непрерывным временем (CTMC); по числу состояний — конечные и бесконечные; по характеру — однородные (вероятности перехода не зависят от времени) и неоднородные. Цепь Маркова n-го порядка учитывает n предыдущих состояний — обобщение базовой модели. Вероятности перехода оцениваются эмпирически из исторических данных как доля переходов из i в j от всех переходов из i. Для прогнозирования распределения вероятностей через k шагов используется возведение матрицы P в степень k: π_k = π₀·Pᵏ. Стационарное распределение π удовлетворяет уравнению π = π·P и существует для эргодических цепей. Расширение — скрытые марковские модели (HMM), где состояния не наблюдаются напрямую, а доступны только связанные с ними наблюдения. Применения: моделирование поведения клиентов и оттока (CRM), кредитный скоринг и миграция кредитных рейтингов, анализ последовательностей кликов на сайтах, распознавание речи и текста, прогнозирование погоды на категориальном уровне, моделирование надёжности систем, генетический анализ. Преимущества: математическая простота, интерпретируемость, эффективность для категориальных и дискретных процессов. Недостатки: марковское допущение часто нарушается в реальности, плохо описывает долгосрочные зависимости, неприменима к непрерывным числовым данным без предварительной дискретизации.

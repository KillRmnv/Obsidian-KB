# 43. Кластер. Определение. Свойства

Кластер — это группа объектов, обладающих сходными характеристиками, выделенная по результатам кластерного анализа таким образом, что внутри группы объекты максимально похожи между собой, а с объектами других групп — максимально различны. Формального общепринятого определения кластера не существует — это одно из ключевых отличий кластерного анализа от классификации (где классы заранее определены). В практическом плане кластер определяется как множество объектов, в котором расстояния (или иная мера несходства) между парами объектов внутри множества систематически меньше, чем расстояния до объектов вне множества. Основные свойства кластеров. 1) Внутренняя однородность (компактность) — объекты внутри кластера должны быть похожи между собой, минимизируется внутрикластерное расстояние; формально это малая сумма квадратов отклонений от центроида (within-cluster sum of squares, WCSS). 2) Внешняя разделимость (изолированность) — кластер должен быть отделим от других кластеров, межкластерные расстояния должны быть значительно больше внутрикластерных. 3) Плотность — точки внутри кластера расположены плотно, образуют «сгусток» в признаковом пространстве. 4) Связность — все объекты кластера связаны цепочкой коротких переходов через близких соседей (важно для плотностных методов). 5) Форма и размер кластеров могут существенно различаться: сферические, эллипсоидальные, произвольной формы, с разной плотностью и масштабом. 6) Стабильность (устойчивость) — хорошие кластеры воспроизводимы при небольших изменениях данных, разных запусках алгоритма, разных подвыборках. 7) Интерпретируемость — выделенные группы должны иметь содержательное объяснение, отражать реальные различия в данных. 8) Полнота покрытия — в зависимости от метода каждый объект относится строго к одному кластеру (жёсткая кластеризация, hard clustering) или с разными вероятностями к нескольким (мягкая, soft clustering, fuzzy clustering); некоторые методы (DBSCAN) выделяют шумовые точки, не входящие ни в один кластер. Структура: кластеры могут быть плоскими (одноуровневыми) или иерархическими (вложенными).

# 34. Модель Хольта-Уинтерса (тройное экспоненциальное сглаживание)

Модель Хольта-Уинтерса (Holt-Winters Method) — обобщение модели Хольта на временные ряды с трендом и сезонностью; называется также тройным экспоненциальным сглаживанием, так как использует три уравнения: для уровня, тренда и сезонной компоненты. Существуют две версии модели в зависимости от характера сезонности. Аддитивная модель (применяется при постоянной амплитуде сезонных колебаний): уровень Lₜ = α·(yₜ − Sₜ₋ₘ) + (1 − α)·(Lₜ₋₁ + Tₜ₋₁); тренд Tₜ = β·(Lₜ − Lₜ₋₁) + (1 − β)·Tₜ₋₁; сезонность Sₜ = γ·(yₜ − Lₜ) + (1 − γ)·Sₜ₋ₘ; прогноз: **ŷₜ₊ₕ = Lₜ + h·Tₜ + Sₜ₊ₕ₋ₘ**. Мультипликативная модель (применяется при росте амплитуды сезонности пропорционально уровню ряда): уровень Lₜ = α·(yₜ / Sₜ₋ₘ) + (1 − α)·(Lₜ₋₁ + Tₜ₋₁); тренд аналогично; сезонность Sₜ = γ·(yₜ / Lₜ) + (1 − γ)·Sₜ₋ₘ; прогноз: ŷₜ₊ₕ = (Lₜ + h·Tₜ)·Sₜ₊ₕ₋ₘ. Здесь m — период сезонности (12 для месячных данных с годовой сезонностью, 4 для квартальных, 7 для недельных), α, β, γ — параметры сглаживания (0 < α, β, γ < 1). Параметры оптимизируются минимизацией ошибки прогноза. Инициализация требует данных хотя бы за один-два полных сезонных цикла для оценки начальных сезонных коэффициентов. Преимущества: учитывает все три компоненты ряда (уровень, тренд, сезонность), интуитивно понятна, хорошо работает на относительно коротких рядах, низкая вычислительная сложность. Недостатки: не учитывает экзогенные факторы, плохо реагирует на структурные сдвиги, требует данных за несколько сезонных циклов. Модель Хольта-Уинтерса входит в семейство ETS-моделей (Error-Trend-Seasonality) и активно применяется в розничной торговле, энергетике, туризме.

# 45. Метрики расстояния: случай качественных переменных

Для качественных (категориальных, бинарных, номинальных, порядковых) переменных классические числовые метрики неприменимы напрямую, требуются специальные меры сходства/различия. Для бинарных переменных строится таблица сопряжённости 2×2 для двух объектов: a — оба имеют признак (1,1), b — только первый (1,0), c — только второй (0,1), d — оба не имеют (0,0). 1) Простое сопоставление (Simple Matching Coefficient): SMC = (a + d) / (a + b + c + d); учитывает совпадения как по наличию, так и по отсутствию признака; расстояние = 1 − SMC; подходит для симметричных бинарных признаков. 2) Коэффициент Жаккара (Jaccard): J = a / (a + b + c); не учитывает совместное отсутствие признака, важен для асимметричных признаков (например, наличие редких товаров в корзине); расстояние = 1 − J. 3) Коэффициент Дайса (Sørensen-Dice): D = 2a / (2a + b + c); расширение Жаккара с большим весом совпадений. 4) Расстояние Хэмминга — число позиций, в которых сравниваемые строки/векторы различаются; для бинарных признаков совпадает с b + c. Для номинальных переменных с более чем двумя категориями: 5) Метрика равенства/неравенства — число несовпадающих признаков, делённое на общее число (обобщение Хэмминга). 6) Метрика Гауэра (Gower distance) — универсальная мера, применимая к смешанным типам данных (количественным, порядковым, бинарным, номинальным): для каждого признака рассчитывается своё нормализованное расстояние, затем берётся взвешенное среднее; широко применяется в реальных задачах со смешанными данными. Для порядковых переменных: 7) Метрики на основе ранговой разности — превращение порядковых значений в ранги с применением числовых метрик. Для строк/последовательностей: 8) Расстояние Левенштейна (редакционное расстояние) — минимальное число операций вставки, удаления и замены символов для превращения одной строки в другую; применяется в обработке текста и биоинформатике. 9) Расстояние Жаро-Винклера — для сравнения коротких строк (имён, идентификаторов). При работе со смешанными данными рекомендуется метрика Гауэра или предварительное кодирование (one-hot, target encoding) с применением числовых метрик.

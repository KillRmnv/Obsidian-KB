# 29. Выбор длины окна для скользящей средней

При использовании метода скользящей средней для сглаживания временных рядов и краткосрочного прогнозирования ключевой параметр — длина окна (период сглаживания) n, определяющий, сколько последних наблюдений участвуют в расчёте каждого значения. Выбор n существенно влияет на свойства результата и представляет компромисс. При малых значениях n (короткое окно) сглаженный ряд хорошо повторяет реальные колебания, быстро реагирует на изменения уровня ряда, но плохо подавляет случайный шум — результат остаётся «зашумлённым». При больших n (длинное окно) сглаживание сильнее, шум подавляется лучше, но появляется значительное запаздывание реакции на изменения тренда, теряются важные детали, краевые эффекты увеличиваются (теряется n−1 значений в начале ряда). Основные правила выбора длины окна. 1) Если ряд содержит сезонность с периодом T, длина окна должна быть равна периоду сезонности (n = T) или кратна ему — это полностью нейтрализует сезонную компоненту. Например, для месячных данных с годовой сезонностью n = 12, для квартальных n = 4. 2) Для ряда без выраженной сезонности длина окна выбирается исходя из соотношения «уровень шума / реактивность»: для зашумлённых данных — больше, для стабильных — меньше. 3) Эмпирическое правило — n обычно лежит в диапазоне от 3 до 12 для коротких рядов. 4) Объективный подход — перебор различных значений n с расчётом метрик качества (MAE, MSE, RMSE) на скользящей или отложенной выборке, выбор оптимального. 5) Для нечётных n результат удобно центрировать (значение относится к среднему наблюдению окна); для чётных применяют центрированную скользящую среднюю с дополнительным сглаживанием. Выбор длины окна — итеративный процесс, требующий анализа структуры ряда и целей сглаживания.

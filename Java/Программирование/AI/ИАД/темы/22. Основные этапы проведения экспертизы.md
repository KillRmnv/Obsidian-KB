# 22. Основные этапы проведения экспертизы

Экспертиза — это процедура получения и обработки мнений экспертов по поставленной проблеме с целью принятия решения или построения прогноза. Основные этапы проведения экспертизы. 1) Постановка задачи — чёткое формулирование цели экспертизы, определение объекта и предмета оценки, выбор критериев и шкал измерения. 2) Формирование рабочей группы — назначение организаторов, аналитиков, технического персонала для подготовки материалов и обработки результатов. 3) Подбор экспертов — определение требуемой компетенции, оценка кандидатов по объективным (стаж, публикации) и субъективным (самооценка, взаимная оценка) показателям, расчёт коэффициента компетентности, формирование экспертной группы оптимального размера (обычно 7–15 человек). 4) Разработка инструментария — составление анкет, опросников, шкал оценивания, сценариев интервью; шкалы могут быть номинальными, ранговыми, интервальными. 5) Проведение опроса экспертов — выбранным методом (Дельфи, мозговой штурм, ранжирование, парные сравнения); может быть очным или заочным, в один или несколько туров. 6) Обработка результатов — статистическая обработка оценок, расчёт средних значений, медиан, согласованности мнений (коэффициент конкордации Кендалла W). 7) Анализ согласованности и достоверности — если согласованность низкая, проводится дополнительный тур или пересмотр состава группы. 8) Интерпретация и оформление результатов — формулировка выводов, подготовка отчёта с обоснованием рекомендаций. 9) Принятие решения на основе экспертных оценок. Качество экспертизы определяется компетентностью экспертов, корректностью методики и качеством обработки данных.

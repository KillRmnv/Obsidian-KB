# 31. Модели ARIMA(p,d,q), ARIMAX(p,d,q)

ARIMA (AutoRegressive Integrated Moving Average) — обобщённая модель Бокса-Дженкинса для прогнозирования нестационарных временных рядов, объединяющая авторегрессию (AR), интегрирование (I) и скользящее среднее (MA). Параметры модели: p — порядок авторегрессии (число лагов yₜ), d — порядок интегрирования (число последовательных дифференцирований для приведения ряда к стационарности), q — порядок скользящего среднего (число лагов ошибки). Общая идея: исходный нестационарный ряд преобразуется в стационарный с помощью d-кратного взятия разностей Δyₜ = yₜ − yₜ₋₁, после чего к преобразованному ряду применяется модель ARMA(p,q). Формула в операторной записи: **(1 − Σφᵢ Lⁱ)(1 − L)ᵈ yₜ = c + (1 + Σθ Lʲ)εₜ**, где L — оператор сдвига. Этапы построения модели (методология Бокса-Дженкинса): 1) проверка стационарности (тест Дики-Фуллера ADF, KPSS), при необходимости — дифференцирование для определения d; 2) идентификация порядков p и q по графикам ACF и PACF; 3) оценка параметров методом максимального правдоподобия; 4) диагностика остатков (тест Льюнга-Бокса на отсутствие автокорреляции); 5) прогнозирование с расчётом доверительных интервалов. Выбор оптимальных p, d, q обычно осуществляется по информационным критериям AIC, BIC. Расширения модели: SARIMA(p,d,q)(P,D,Q)ₘ — добавляет сезонные компоненты с периодом m; ARIMAX(p,d,q) — включает экзогенные (внешние) объясняющие переменные X, влияющие на ряд (например, цены конкурентов, погодные условия при прогнозировании продаж). Преимущества ARIMA: статистически обоснованная модель, подходит для широкого класса рядов, даёт интервальные прогнозы. Недостатки: требует стационарности после дифференцирования, чувствительна к выбору порядков, плохо работает на длинных горизонтах, не учитывает нелинейности.

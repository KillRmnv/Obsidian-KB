# 23. Метод суммирования рангов

Метод суммирования рангов — один из наиболее распространённых методов обработки результатов экспертного оценивания, основанный на ранжировании. Суть метода: каждый эксперт упорядочивает (ранжирует) все оцениваемые объекты (альтернативы, факторы) по степени их значимости, присваивая ранг 1 наиболее важному, ранг 2 — следующему по значимости и так далее до ранга n. После сбора оценок от всех m экспертов для каждого j-го объекта вычисляется сумма рангов: **S = Σᵢ rᵢ**, где rᵢ — ранг, присвоенный i-м экспертом j-му объекту. Объекты упорядочиваются по возрастанию суммы рангов: чем меньше сумма, тем более важным считается объект по мнению группы экспертов. На основе сумм рангов рассчитываются средние ранги и итоговое групповое ранжирование. Если у эксперта возникают затруднения и несколько объектов кажутся равнозначными, применяются связанные (стандартизованные) ранги — каждому из таких объектов присваивается среднее арифметическое мест, которые они занимают. Для оценки согласованности мнений экспертов рассчитывается коэффициент конкордации Кендалла W, значения которого лежат в диапазоне [0, 1]: чем ближе к 1, тем выше согласованность; значимость W проверяется по критерию χ². Преимущества метода: простота, наглядность, не требует от экспертов абсолютных оценок. Недостатки: теряется информация о степени превосходства между объектами (только порядок), при большом числе объектов ранжирование становится затруднительным. Метод применяется в маркетинге (приоритизация факторов), управлении (выбор стратегий), при отборе проектов.

# 20. Временные ряды. Классификация

Временной ряд — последовательность наблюдений количественной величины, упорядоченных во времени и измеренных через равные (или неравные) интервалы. Формально: Y = {y₁, y₂, …, yₙ}, где индекс соответствует моменту наблюдения. Особенность временных рядов — наличие зависимости между наблюдениями (автокорреляции), нарушающее предположение о независимости в классической статистике. Классификация временных рядов проводится по нескольким признакам. По характеру измерений: моментные (значения на момент времени, например запас на складе) и интервальные (значения за период, например продажи за месяц). По характеру данных: детерминированные (значения известны точно или описываются функцией) и стохастические (случайные, описываются вероятностно). По стационарности: стационарные (статистические характеристики — среднее, дисперсия, автокорреляция — не меняются во времени) и нестационарные (свойства меняются); большинство реальных рядов нестационарны. По компонентному составу: одномерные (univariate) и многомерные (multivariate, несколько связанных рядов). По периодичности: с регулярными равными интервалами и нерегулярные. По частоте: высокочастотные (тики, минуты) и низкочастотные (квартальные, годовые). Любой временной ряд можно разложить на компоненты: тренд (T) — долгосрочная тенденция; сезонность (S) — периодические колебания фиксированной длительности; цикличность (C) — нерегулярные колебания большей длительности; случайная компонента (ε) — шум. Модели разложения: аддитивная Y = T + S + C + ε и мультипликативная Y = T·S·C·ε. Анализ временных рядов применяется для прогнозирования (ARIMA, экспоненциальное сглаживание, Prophet, LSTM), выявления структуры и обнаружения аномалий.

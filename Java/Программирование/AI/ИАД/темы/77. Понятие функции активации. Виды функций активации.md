# 77. Понятие функции активации. Виды функций активации

Функция активации — нелинейное преобразование, применяемое к взвешенной сумме входов нейрона, преобразующее z = Σwᵢxᵢ + b в выходное значение y = φ(z). Главное назначение — внесение нелинейности в модель: без неё многослойная сеть математически сводилась бы к одному линейному преобразованию независимо от числа слоёв, что лишает смысла построение глубоких архитектур. Функция активации также определяет диапазон выходных значений и свойства градиента, влияющие на обучаемость. Основные виды функций активации. 1) Пороговая (step function): φ(z) = 1 при z ≥ 0, иначе 0; используется в исходном персептроне, не дифференцируема — непригодна для обратного распространения. 2) Сигмоида (логистическая): **φ(z) = 1/(1 + e⁻ᶻ)**, диапазон (0, 1), гладкая, дифференцируемая, исторически популярна; недостатки — насыщение и затухание градиента в краях (vanishing gradient), несимметричность относительно нуля. 3) Гиперболический тангенс (tanh): φ(z) = (eᶻ − e⁻ᶻ)/(eᶻ + e⁻ᶻ), диапазон (−1, 1), симметрична, но также страдает от насыщения. 4) ReLU (Rectified Linear Unit): **φ(z) = max(0, z)**, современный стандарт, простая, не насыщается при положительных z, ускоряет сходимость; недостаток — «умирающие» нейроны (dying ReLU) при отрицательных z. 5) Leaky ReLU: φ(z) = max(αz, z) с малым α (0,01), решает проблему «умирающих» нейронов. 6) ELU, SELU, GELU, Swish, Mish — современные гладкие варианты, применяются в архитектурах вроде BERT и GPT. 7) Softmax — для выходного слоя многоклассовой классификации: **softmax(zᵢ) = eᶻⁱ / Σ eᶻ**, возвращает распределение вероятностей по K классам. Выбор функции активации: ReLU и её варианты для скрытых слоёв, sigmoid для бинарной классификации на выходе, softmax для многоклассовой, линейная для регрессии.

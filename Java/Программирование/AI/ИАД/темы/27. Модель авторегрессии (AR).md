# 27. Модель авторегрессии (AR)

Модель авторегрессии (AutoRegressive, AR) — стохастическая модель временного ряда, в которой текущее значение ряда выражается как линейная комбинация его собственных предыдущих значений и случайной ошибки. Формула модели AR порядка p: **yₜ = c + φ₁yₜ₋₁ + φ₂yₜ₋₂ + … + φₚyₜ₋ₚ + εₜ**, где c — константа, φᵢ — коэффициенты авторегрессии, εₜ — белый шум (независимые случайные величины с нулевым средним и постоянной дисперсией), p — порядок модели (количество лагов). Базовая идея: будущее значение зависит от собственного прошлого, что естественно для многих экономических, природных и технических процессов с инерционностью. Порядок p определяет «глубину памяти» модели: AR(1) учитывает только предыдущее значение, AR(2) — два предыдущих и т.д. Условие стационарности AR(p): корни характеристического уравнения 1 − φ₁z − … − φₚzᵖ = 0 должны лежать вне единичного круга на комплексной плоскости; для AR(1) это эквивалентно |φ₁| < 1. Параметры модели оцениваются методом наименьших квадратов или методом максимального правдоподобия. Порядок p выбирается по графику частной автокорреляционной функции (PACF): значимые лаги в PACF указывают порядок модели; также применяются информационные критерии AIC, BIC. Диагностика: остатки должны быть белым шумом, что проверяется тестом Льюнга-Бокса. Преимущества: простота, интерпретируемость, эффективность для стационарных рядов с инерционностью. Недостатки: применима только к стационарным рядам (для нестационарных используется ARIMA), не учитывает сезонность напрямую. AR — базовый элемент более сложных моделей ARMA, ARIMA, SARIMA.

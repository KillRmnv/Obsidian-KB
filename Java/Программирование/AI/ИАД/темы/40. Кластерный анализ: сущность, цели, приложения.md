# 40. Кластерный анализ: сущность, цели, приложения

Кластерный анализ — метод многомерного статистического анализа и машинного обучения, направленный на разбиение множества объектов на группы (кластеры) таким образом, чтобы объекты внутри одного кластера были максимально похожи между собой, а объекты из разных кластеров — максимально различны. Это задача обучения без учителя (unsupervised learning), в которой заранее неизвестны ни метки классов, ни количество групп — кластеры выявляются на основе самой структуры данных. Сходство объектов измеряется через метрики расстояния: евклидово, манхэттенское, Чебышёва, косинусное расстояние, метрика Махаланобиса; для категориальных данных — расстояние Хэмминга, Жаккара. Цели кластерного анализа: 1) выявление естественной структуры данных и скрытых закономерностей; 2) сегментация объектов по похожести для последующих специфических действий; 3) сжатие данных и снижение размерности (представление через центроиды кластеров); 4) обнаружение аномалий — объекты, не вошедшие ни в один кластер; 5) предварительный анализ перед применением других методов; 6) построение таксономии и классификации в предметных областях. Основные классы методов кластеризации: иерархические (агломеративные и дивизивные, дендрограмма), методы на основе разбиения (k-means, k-medoids/PAM, fuzzy c-means), плотностные (DBSCAN, OPTICS, HDBSCAN), на основе моделей (Gaussian Mixture Models, EM-алгоритм), сеточные (STING, CLIQUE), спектральные, ансамблевые. Оценка качества кластеризации: внутренние метрики (силуэт, индекс Дэвиса-Болдина, индекс Калински-Харабаса), внешние метрики (при наличии эталонных меток — индекс Рэнда, ARI, NMI). Приложения: маркетинговая сегментация клиентов (RFM-анализ), биоинформатика (классификация генов и белков), медицина (выделение групп пациентов и подтипов заболеваний), компьютерное зрение (сегментация изображений), обработка текстов (тематическое моделирование), обнаружение мошенничества и аномалий, анализ социальных сетей и сообществ, рекомендательные системы, городское планирование (зонирование), обработка геоданных. Кластерный анализ — один из ключевых инструментов разведочного анализа данных (EDA).

## 51. Метод локтя (Elbow Method)

Метод локтя (Elbow Method) — один из наиболее распространённых эвристических подходов к выбору оптимального числа кластеров k в алгоритмах разбиения (k-means, k-medoids). Идея метода основана на анализе зависимости качества кластеризации от числа кластеров. Для каждого значения k из заданного диапазона (обычно от 1 до 10–15) алгоритм запускается, и рассчитывается метрика внутрикластерного разброса — суммарная сумма квадратов внутрикластерных отклонений от центроидов: **WCSS(k) = Σᵢ Σ_{x ∈ Cᵢ} ‖x − μᵢ‖²** (также называется inertia или distortion). Эта величина монотонно убывает с ростом k: чем больше кластеров, тем плотнее каждый из них (в предельном случае при k = n WCSS = 0). Однако скорость убывания не постоянна: сначала, при добавлении кластеров до «истинного» числа, WCSS падает быстро, так как новые кластеры действительно отражают структуру данных; после прохождения этого числа дальнейшее увеличение k даёт лишь незначительное улучшение, так как новые кластеры начинают делить уже однородные группы. На графике зависимости WCSS от k появляется характерный «излом», похожий на согнутый локоть — это и есть искомая точка оптимума: значение k, после которого скорость уменьшения WCSS резко замедляется. Графически: участок до излома — крутой спуск, после излома — пологий «хвост». Достоинства метода: простота реализации, наглядность, не требует знания истинных меток классов, применим к любым алгоритмам с метрикой компактности. Недостатки: субъективность определения точки излома — на реальных данных он часто размыт или отсутствует; неоднозначность при наличии нескольких «локтей»; неприменим, когда кластеры имеют разную плотность или сильно различаются по размеру; чувствительность к масштабу признаков; зависимость от инициализации (требует усреднения по нескольким запускам). Альтернативы и развитие метода: метод силуэта (более объективен), статистика гэп Тибширани (Gap Statistic) — сравнение WCSS с эталонным равномерным распределением, что формализует понятие «локтя», индекс Калински-Харабаса, индекс Дэвиса-Болдина, X-means. На практике метод локтя часто применяется совместно с другими методами для повышения надёжности выбора k.

## 52. Метод силуэта (Silhouette Method)

Метод силуэта (Silhouette Method) — один из наиболее эффективных и популярных методов оценки качества кластеризации и выбора оптимального числа кластеров, предложенный Питером Руссо в 1987 году. В отличие от метода локтя, силуэт даёт количественную, более объективную оценку и применим к любому алгоритму кластеризации. Силуэт рассчитывается для каждого объекта отдельно и показывает, насколько хорошо объект соответствует своему кластеру по сравнению с соседними. Для объекта i вычисляются: a(i) — среднее расстояние от i до всех остальных объектов того же кластера (мера внутрикластерной близости); b(i) — минимальное среднее расстояние от i до объектов любого другого кластера (мера расстояния до ближайшего соседнего кластера). Коэффициент силуэта объекта определяется формулой: **s(i) = (b(i) − a(i)) / max(a(i), b(i))**. Значение s(i) лежит в диапазоне от −1 до +1 и имеет содержательную интерпретацию: s(i) ≈ 1 — объект хорошо приписан к своему кластеру и далёк от соседних (отличная кластеризация); s(i) ≈ 0 — объект лежит на границе двух кластеров (неоднозначное отнесение); s(i) ≈ −1 — объект, скорее всего, ошибочно отнесён, ближе к соседнему кластеру. Общая оценка качества кластеризации — средний силуэт по всем объектам: **S = (1/n)·Σ s(i)**. Эмпирическая интерпретация средних значений: S > 0,7 — сильная структура кластеризации; 0,5–0,7 — разумная структура; 0,25–0,5 — слабая структура, требует проверки; S < 0,25 — структура практически отсутствует. Выбор оптимального k: для каждого k из заданного диапазона рассчитывается S, и выбирается k с максимальным значением среднего силуэта. Дополнительный инструмент — диаграмма силуэта (silhouette plot): горизонтальные столбики s(i) для каждого объекта, сгруппированные по кластерам, отсортированные внутри кластера по убыванию. По диаграмме визуально оценивается равномерность кластеров (примерно равные «треугольники» для каждого кластера), наличие плохо приписанных объектов (отрицательные значения), сбалансированность размеров кластеров. Достоинства: объективная количественная оценка, наглядность, применимость к разным алгоритмам, выявление плохо классифицированных объектов. Недостатки: вычислительно дороже метода локтя (O(n²) для попарных расстояний), может быть неинформативен при кластерах сложной формы и разной плотности (предпочитает компактные сферические), чувствителен к выбору метрики расстояния.

## 53. Классификационные правила

Классификационные правила — простейшая и наиболее интерпретируемая форма представления знаний в задачах классификации, имеющая вид логических выражений «если-то» (if-then rules): «ЕСЛИ выполняется условие на признаки, ТО объект относится к классу C». Общая форма правила: IF (X₁ = a₁) AND (X₂ < a₂) AND … AND (Xₙ ∈ A) THEN Class = C. Левая часть (антецедент, условие) — конъюнкция простых условий на признаки; правая часть (консеквент, заключение) — предсказываемый класс. Совокупность правил образует классификатор: при классификации нового объекта проверяются условия правил, и принимается решение по сработавшему правилу. Виды наборов правил. 1) Упорядоченные списки правил (decision lists) — правила проверяются последовательно, первое сработавшее определяет класс; включает финальное правило «по умолчанию» для неклассифицированных объектов. 2) Неупорядоченные множества правил (rule sets) — все правила равноправны; при срабатывании нескольких применяются стратегии разрешения конфликтов (голосование, выбор по достоверности). Свойства качественных правил — каждое правило характеризуется метриками: покрытие (coverage, support) — доля объектов выборки, для которых выполняется условие; точность (accuracy, confidence) — доля правильно классифицированных среди покрываемых объектов; ёмкость (capture) — доля объектов класса, охваченных правилом. Хорошие правила имеют высокое покрытие и высокую точность, но обычно есть компромисс. Методы построения правил. 1) Прямое извлечение из деревьев решений: каждый путь от корня к листу соответствует одному правилу. 2) Алгоритмы покрытия (covering algorithms): последовательно строят правила, каждое покрывает часть оставшихся объектов одного класса (CN2, RIPPER, AQ, PRISM). 3) Ассоциативные классификаторы — на основе ассоциативных правил с фильтрацией по классу (CBA, CMAR). 4) 1R — простейший алгоритм одиночных правил. Преимущества классификационных правил: высокая интерпретируемость (легко объяснить решение), компактность, возможность экспертной проверки и редактирования, эффективная классификация. Недостатки: трудность построения оптимального набора, склонность к переобучению при большом числе правил, сложность работы с непрерывными признаками (требуется дискретизация), потенциальные конфликты между правилами. Применения: экспертные системы, медицинская диагностика, кредитный скоринг, диагностика технических неисправностей — задачи, где важна прозрачность решения.

## 54. 1R-алгоритм классификации

1R-алгоритм (One Rule, или OneR) — простейший и одновременно один из самых поучительных алгоритмов классификации, предложенный Робертом Холтом в 1993 году. Несмотря на свою простоту, в исследовании Холта на множестве реальных наборов данных 1R показал результаты, удивительно близкие к гораздо более сложным алгоритмам — это иллюстрирует принцип «бритвы Оккама»: для многих задач простые модели работают почти так же хорошо, как сложные. Идея алгоритма: построить классификационное правило, основанное только на одном (наилучшем) признаке — отсюда название «1R». Алгоритм работы. 1) Для каждого признака X строится набор правил вида «если X = vᵢ, то Class = Cᵢ»: для каждого значения признака определяется наиболее часто встречающийся класс среди объектов с этим значением (мажоритарное голосование). 2) Для каждого набора правил (то есть для каждого признака) подсчитывается ошибка на обучающей выборке — число объектов, для которых правило даёт неверный класс. 3) Выбирается признак с минимальной ошибкой — на нём и строится итоговый одиночный набор правил (классификатор). Работа с непрерывными признаками: предварительная дискретизация (биннинг) — диапазон значений разбивается на интервалы; в простейшей версии 1R интервалы формируются жадно, чтобы внутри каждого преобладал один класс, с ограничением минимального числа объектов в интервале для предотвращения переобучения. Обработка пропущенных значений: пропуск рассматривается как отдельное значение признака. Например, для классификации погоды (играть/не играть в гольф) 1R может выбрать признак «прогноз» с правилами: «если солнечно — не играть, если облачно — играть, если дождь — не играть», и других признаков не использовать. Преимущества: максимальная простота и интерпретируемость (одно правило!), высокая скорость, минимальная склонность к переобучению, отличная базовая модель (baseline) для сравнения с более сложными методами, низкие требования к данным. Недостатки: игнорирует взаимодействия между признаками, не использует комбинации (что ограничивает максимальную точность), плохо работает при сложных нелинейных зависимостях и большом числе важных факторов. Применение: предварительный анализ данных, оценка минимально достижимой ошибки и базовой точности задачи, выявление наиболее значимого признака, обучение принципам классификации. Если 1R даёт точность, близкую к сложным моделям, это сигнал, что задача проста и в данных доминирует один признак.

## 55. Наивный байесовский классификатор

Наивный байесовский классификатор (Naive Bayes) — вероятностный алгоритм классификации, основанный на теореме Байеса с упрощающим («наивным») предположением о независимости признаков. Несмотря на сильное и часто нереалистичное допущение, на практике классификатор демонстрирует высокую эффективность во многих задачах. Теоретическая основа — теорема Байеса: **P(C|X) = P(X|C)·P(C) / P(X)**, где P(C|X) — апостериорная вероятность класса C при наблюдаемых признаках X = (x₁, x₂, …, xₙ); P(C) — априорная вероятность класса; P(X|C) — правдоподобие (вероятность наблюдать признаки при условии класса); P(X) — полная вероятность признаков (нормирующая константа, одинакова для всех классов и при сравнении опускается). «Наивное» предположение состоит в том, что признаки условно независимы при фиксированном классе: P(X|C) = ∏ P(xᵢ|C). Это резко упрощает оценку — вместо моделирования совместного распределения признаков достаточно оценить одномерные распределения P(xᵢ|C). Итоговое правило классификации (правило максимума апостериорной вероятности, MAP): **Ĉ = argmax_C P(C)·∏ P(xᵢ|C)**. На практике для численной устойчивости используют логарифм: log P(C) + Σ log P(xᵢ|C). Этапы обучения: 1) оценка априорных вероятностей классов P(C) — обычно как доля объектов класса в обучающей выборке; 2) оценка условных вероятностей P(xᵢ|C) для каждого признака и класса. Виды наивных байесовских классификаторов в зависимости от модели распределения признаков. 1) Multinomial Naive Bayes — для дискретных счётных данных (например, частоты слов в тексте); классический выбор для классификации текстов и спам-фильтров. 2) Gaussian Naive Bayes — для непрерывных признаков, предполагает нормальное распределение в каждом классе; параметры μ, σ оцениваются по выборке. 3) Bernoulli Naive Bayes — для бинарных признаков (наличие/отсутствие). 4) Categorical Naive Bayes — для произвольных категориальных признаков. Сглаживание Лапласа (add-one smoothing): к каждой частоте добавляется единица — это решает проблему нулевых вероятностей для значений, не встречавшихся в обучающей выборке. Применения: классификация текстов (новости по рубрикам), фильтрация спама (один из исторически первых эффективных методов), анализ тональности, медицинская диагностика, рекомендательные системы, baseline-классификатор для сравнения.

## 56. Преимущества и недостатки наивного байесовского классификатора

Наивный байесовский классификатор — один из наиболее популярных простых алгоритмов классификации благодаря балансу простоты и эффективности. Преимущества. 1) Высокая скорость обучения и предсказания — алгоритм имеет линейную сложность O(n·d), требует только подсчёта частот и оценки параметров распределений, без итеративной оптимизации; пригоден для real-time классификации и потоковых данных. 2) Малые требования к объёму обучающей выборки — благодаря допущению о независимости признаков параметров требуется значительно меньше, чем для моделирования совместного распределения; работает даже на малых выборках. 3) Хорошая масштабируемость на большие наборы данных и пространства высокой размерности — особенно эффективен в задачах с тысячами признаков (классификация текстов). 4) Естественная работа с многоклассовой классификацией без специальных модификаций (one-vs-rest и подобных). 5) Вероятностный выход — алгоритм возвращает не только класс, но и его вероятность, что позволяет ранжировать предсказания и оценивать уверенность модели. 6) Устойчивость к шуму и пропускам — пропущенные значения легко обрабатываются игнорированием соответствующего сомножителя. 7) Простота реализации и интерпретации. 8) Высокая точность на многих практических задачах, особенно текстовой классификации, несмотря на сильное упрощающее предположение. 9) Легко обновляется (инкрементальное обучение). Недостатки. 1) «Наивное» предположение о независимости признаков почти всегда нарушается в реальных данных — между признаками обычно есть корреляции, что теоретически должно ухудшать качество (на практике классификатор удивительно устойчив к этому нарушению, особенно когда нарушения «компенсируют» друг друга). 2) При наличии сильно коррелированных признаков их влияние «учитывается дважды», что искажает вероятности. 3) Проблема нулевой вероятности (zero-frequency problem): если в обучающей выборке некоторое значение признака никогда не встречалось с определённым классом, P(xᵢ|C) = 0, что обнуляет всё произведение; решение — сглаживание Лапласа или другие методы. 4) Калибровка вероятностей — выдаваемые вероятности часто плохо откалиброваны: классификатор склонен выдавать значения близкие к 0 или 1 (избыточно уверен); для получения корректных вероятностей применяется калибровка (Platt scaling, isotonic regression). 5) Чувствительность к выбору модели распределения для непрерывных признаков (Gaussian NB предполагает нормальность); при сильном отклонении от предположения качество падает. 6) Не моделирует взаимодействия между признаками, что ограничивает максимальную точность на задачах со сложной структурой. 7) Уступает современным методам (градиентный бустинг, нейросети) на сложных задачах с большим объёмом данных. Классификатор остаётся одним из лучших baseline-моделей и стандартом для текстовой классификации.

## 57. Деревья решений: общее представление, приложения

Дерево решений (Decision Tree) — один из самых популярных и интерпретируемых методов машинного обучения, представляющий модель в виде иерархической древовидной структуры из узлов и ветвей, реализующей последовательность логических проверок для принятия решения. Структура дерева. 1) Корневой узел (root) — начальная точка, содержит всю обучающую выборку и первое (наиболее информативное) разделение. 2) Внутренние узлы (internal nodes) — содержат правила разделения по одному из признаков (например, «возраст < 30» или «цвет = красный»). 3) Ветви (edges) — соответствуют возможным исходам проверки в узле. 4) Листья (leaves, терминальные узлы) — конечные узлы, содержащие итоговое предсказание: класс для классификации (классификационное дерево) или числовое значение для регрессии (регрессионное дерево). Принцип работы: для классификации/предсказания нового объекта он проходит по дереву от корня к листу, на каждом узле проверяется правило разделения, и в соответствии с результатом выбирается ветвь; класс/значение в достигнутом листе — итоговое предсказание. Каждый путь от корня к листу можно записать как классификационное правило вида «если-то». Алгоритмы построения деревьев: ID3 (Iterative Dichotomiser 3, Куинлан, 1986) — использует прирост информации, только для категориальных признаков; C4.5 — развитие ID3, работает с непрерывными признаками, обрабатывает пропуски, применяет обрезку; C5.0 — коммерческая улучшенная версия; CART (Breiman, 1984) — использует индекс Джини для классификации и MSE для регрессии, бинарные разделения, основа большинства современных реализаций; CHAID — статистический подход на основе критерия χ². Преимущества: высокая интерпретируемость (модель легко визуализируется и объясняется), не требуют нормализации и кодирования (работают с числовыми и категориальными признаками напрямую), нечувствительны к выбросам и масштабу, автоматически отбирают значимые признаки, отражают нелинейные зависимости и взаимодействия, быстрые в предсказании. Недостатки: склонность к переобучению при большой глубине, высокая дисперсия (нестабильность к малым изменениям данных), кусочно-постоянные предсказания (плохая аппроксимация гладких функций), смещение в сторону признаков с большим числом уникальных значений (требует поправок типа Gain Ratio), greedy-построение не гарантирует глобальный оптимум. Для устранения недостатков отдельных деревьев созданы ансамблевые методы: Random Forest, бустинг (XGBoost, LightGBM, CatBoost), которые показывают одни из лучших результатов в задачах со структурированными данными. Приложения: кредитный скоринг (одобрение кредита), медицинская диагностика (определение заболевания по симптомам), маркетинг (сегментация и таргетирование клиентов, прогнозирование оттока), HR (отбор кандидатов), промышленность (диагностика неисправностей), биология (классификация видов), системы поддержки принятия решений, экспертные системы.

## 58. Энтропия. Прирост информации

Энтропия (entropy, информационная энтропия Шеннона) — фундаментальная мера неопределённости, или «беспорядка», в распределении значений случайной величины, введённая Клодом Шенноном в 1948 году в теории информации. В задачах построения деревьев решений энтропия используется для количественной оценки однородности выборки по целевому признаку (классу). Формула энтропии для дискретного распределения по K классам: **H(S) = − Σᵢ pᵢ·log₂(pᵢ)**, где pᵢ — доля объектов класса i в множестве S. Свойства энтропии: 1) H(S) = 0, если все объекты принадлежат одному классу (полная определённость, «чистое» множество); 2) H(S) максимальна и равна log₂(K), когда классы представлены равными долями (максимальная неопределённость); 3) для бинарной классификации максимум H = 1 бит при p = 0,5; 4) энтропия неотрицательна и симметрична относительно перестановок классов. Интуитивно энтропия отвечает на вопрос: «сколько в среднем бит информации нужно для определения класса случайно взятого объекта из выборки?». Чем выше однородность по классу, тем ниже энтропия. Прирост информации (Information Gain, IG) — ключевой критерий выбора признака для разделения в алгоритме ID3 и его развитии C4.5; показывает, насколько уменьшается энтропия (неопределённость) при разделении выборки по выбранному признаку. Формула: **IG(S, A) = H(S) − Σᵥ (|Sᵥ|/|S|)·H(Sᵥ)**, где A — признак разделения, Sᵥ — подмножество S, где признак A принимает значение v; второе слагаемое — взвешенная средняя энтропия дочерних подмножеств. Большое значение IG означает, что разделение по признаку A существенно повышает «чистоту» получаемых подмножеств — такой признак является информативным. Алгоритм построения дерева на основе IG: на каждом узле перебираются все доступные признаки, вычисляется IG для разделения по каждому, и выбирается признак с максимальным IG. Недостаток прироста информации: смещение в сторону признаков с большим числом уникальных значений (например, ID-номера) — такие признаки дают идеальное разделение на множество мелких чистых подмножеств с высоким IG, но не несут реальной обобщающей способности (пример переобучения). Решение — нормированная версия Gain Ratio (коэффициент прироста), используемая в C4.5: GR(S, A) = IG(S, A) / SplitInfo(A), где SplitInfo учитывает количество и размеры подмножеств, штрафуя излишне дробящие признаки. Альтернативные критерии разделения: индекс Джини (используется в CART) и χ²-критерий (CHAID); все они служат той же цели — выбору признака, максимально уменьшающего неоднородность.

## 59. Этапы построения дерева решений

Построение дерева решений — итеративный алгоритм рекурсивного разбиения обучающей выборки, реализующий жадную стратегию (на каждом шаге выбирается локально оптимальное разделение без учёта будущих шагов). Основные этапы. 1) Подготовка данных — сбор обучающей выборки с размеченными метками целевой переменной, очистка от выбросов и обработка пропусков (большинство алгоритмов имеют встроенные механизмы), кодирование признаков при необходимости. 2) Инициализация — все обучающие объекты помещаются в корневой узел; выбирается критерий разделения (Information Gain, Gain Ratio, Gini, MSE/RMSE — в зависимости от задачи и алгоритма) и критерии остановки. 3) Выбор лучшего разделения в текущем узле — для каждого доступного признака рассматриваются возможные точки/множества разделения: для категориальных признаков — каждое значение или подмножество значений, для непрерывных — пороговые значения (часто медианы между значениями, отсортированными по возрастанию); для каждого варианта рассчитывается выбранный критерий, и выбирается признак и точка разделения, обеспечивающие максимальный прирост информации (или минимум индекса Джини, дисперсии). 4) Разделение узла — текущий узел становится внутренним, выборка делится на дочерние подмножества согласно выбранному правилу; алгоритм CART создаёт всегда бинарные разделения, ID3/C4.5 могут создавать k-арные. 5) Рекурсивное применение шагов 3–4 к каждому дочернему узлу — построение продолжается «вниз», пока не сработает критерий остановки. 6) Критерии остановки (pre-pruning, ранняя остановка): все объекты в узле принадлежат одному классу (узел «чистый» — становится листом); достигнута максимальная глубина дерева (max_depth); число объектов в узле меньше порога (min_samples_split, min_samples_leaf); прирост от разделения ниже минимального порога (min_impurity_decrease); закончились доступные признаки. 7) Назначение классов листьям — для классификации лист помечается мажоритарным классом среди попавших в него объектов; для регрессии — средним значением целевой переменной. 8) Обрезка дерева (post-pruning, отсечение ветвей) — для борьбы с переобучением; готовое дерево упрощается путём удаления ветвей, не дающих значимого улучшения на валидационной выборке. Основные подходы: Reduced Error Pruning (REP) — удаление узлов, если это не ухудшает точность на отложенной выборке; Cost-Complexity Pruning (метод стоимости-сложности, или α-pruning, в CART) — минимизация комбинации ошибки и числа листьев с параметром α. 9) Оценка качества модели на тестовой выборке (accuracy, precision, recall, F1, AUC для классификации; RMSE, MAE, R² для регрессии). 10) Подбор гиперпараметров (глубина, min_samples_leaf, α обрезки) по кросс-валидации. 11) Интерпретация и визуализация дерева, извлечение правил.

## 60. Выбор типа ветвления (criterion)

Критерий ветвления (splitting criterion) определяет, по какой математической мере оценивается качество разделения выборки в узле дерева; от его выбора зависит структура итогового дерева, скорость построения и качество модели. Основные критерии различаются для задач классификации и регрессии. Критерии для классификации. 1) Прирост информации (Information Gain) на основе энтропии Шеннона: IG = H(S) − Σ(|Sᵥ|/|S|)·H(Sᵥ); используется в алгоритме ID3; имеет недостаток — смещение в сторону признаков с большим числом значений. 2) Gain Ratio (нормированный прирост информации): GR = IG / SplitInfo, где SplitInfo = − Σ(|Sᵥ|/|S|)·log₂(|Sᵥ|/|S|) — штраф за дробление; применяется в C4.5 для устранения смещения IG; может быть нестабилен при сильно несбалансированных разделениях. 3) Индекс Джини (Gini Impurity): **Gini(S) = 1 − Σ pᵢ²**, где pᵢ — доля класса i; измеряет вероятность ошибочной классификации при случайном выборе; для разделения минимизируется взвешенная сумма Gini дочерних узлов; используется в CART, scikit-learn по умолчанию; вычислительно эффективнее энтропии (нет логарифма), даёт практически идентичные деревья; диапазон значений [0, 1−1/K]; равен 0 для чистого узла. 4) Misclassification Error (ошибка классификации): 1 − max(pᵢ); прост, но менее чувствителен к изменениям в распределении классов, поэтому редко используется для построения, чаще — для обрезки. 5) χ²-критерий — статистический тест на независимость, применяется в CHAID. Критерии для регрессии. 1) MSE (Mean Squared Error, дисперсия): минимизация суммы квадратов отклонений от среднего в дочерних узлах: Σ(yᵢ − ȳ)²; стандартный критерий CART для регрессии, чувствителен к выбросам. 2) MAE (Mean Absolute Error): минимизация суммы абсолютных отклонений от медианы; более устойчив к выбросам, но вычислительно тяжелее. 3) Friedman MSE — модификация MSE, используемая в градиентном бустинге; более устойчива в условиях бустинга. 4) Poisson deviance — для подсчётных данных. Сравнение Gini и Entropy: оба дают схожие результаты в большинстве случаев; Gini немного быстрее (не требует вычисления логарифма) и слегка предпочитает изолировать самый большой класс в отдельную ветвь; Entropy чуть лучше сбалансирована при равных классах. Эмпирически разница в качестве итоговой модели обычно незначительна — это вопрос инженерных предпочтений. Практические рекомендации по выбору: для классификации в большинстве случаев — Gini (быстрее, стандарт); Entropy/IG — если важна теоретико-информационная интерпретация; Gain Ratio — при наличии категориальных признаков с разным числом значений; для регрессии — MSE по умолчанию; MAE — при наличии существенных выбросов; в современных реализациях (XGBoost, LightGBM) используются специализированные критерии на основе градиентов и гессианов функции потерь. Выбор критерия — гиперпараметр, который можно подбирать по кросс-валидации, но обычно его влияние на итоговое качество модели меньше, чем влияние глубины дерева, размера выборки и обрезки.

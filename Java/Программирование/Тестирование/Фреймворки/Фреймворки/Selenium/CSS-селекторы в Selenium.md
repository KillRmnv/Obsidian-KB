# CSS-селекторы в Selenium (Java)

> **Теги:** `#css` `#селекторы` `#selenium` `#java`  
> **Актуально для:** Selenium 4.x

##  Введение

CSS-селекторы — это мощный и быстрый способ поиска элементов в Selenium. Они используют синтаксис таблиц стилей CSS и часто предпочтительнее XPath из-за производительности и читаемости. Однако они менее гибкие, чем XPath (например, нет поиска по тексту или навигации к родителю).

---

##  Базовые селекторы

| Тип | Синтаксис | Пример | Описание |
|-----|-----------|--------|----------|
| **ID** | `#id` | `#login` | По значению атрибута `id` |
| **Класс** | `.class` | `.btn-primary` | По значению атрибута `class` (одному из) |
| **Тег** | `tagname` | `div` | По имени тега |
| **Универсальный** | `*` | `*` | Все элементы (редко используется) |
| **Атрибут** | `[attr='value']` | `[type='text']` | По точному значению атрибута |
| **Атрибут (содержит)** | `[attr*='value']` | `[class*='search']` | Атрибут содержит подстроку |
| **Атрибут (начинается)** | `[attr^='value']` | `[href^='https']` | Атрибут начинается с подстроки |
| **Атрибут (заканчивается)** | `[attr$='value']` | `[src$='.png']` | Атрибут заканчивается на подстроку |
| **Атрибут (содержит слово)** | `[attr~='value']` | `[class~='highlight']` | Атрибут содержит целое слово в списке |

---

##  Комбинаторы (Combinators)

Комбинаторы задают отношения между элементами.

| Комбинатор | Синтаксис | Пример | Описание |
|------------|-----------|--------|----------|
| **Потомок (пробел)** | `A B` | `div input` | Все `input` внутри `div` (любой вложенности) |
| **Дочерний (>) ** | `A > B` | `ul > li` | Только прямые дочерние `li` у `ul` |
| **Соседний (+)** | `A + B` | `h1 + p` | Элемент `p`, непосредственно следующий за `h1` |
| **Родственный (~)** | `A ~ B` | `h1 ~ p` | Все элементы `p`, следующие за `h1` (не обязательно непосредственно) |

---

##  Псевдоклассы (Pseudo-classes)

Псевдоклассы добавляют условия к селекторам.

| Псевдокласс | Синтаксис | Пример | Описание |
|-------------|-----------|--------|----------|
| `:first-child` | `A:first-child` | `li:first-child` | Первый дочерний элемент среди своих братьев |
| `:last-child` | `A:last-child` | `li:last-child` | Последний дочерний элемент |
| `:nth-child(n)` | `A:nth-child(n)` | `tr:nth-child(2)` | n-й дочерний элемент (счёт с 1) |
| `:nth-of-type(n)` | `A:nth-of-type(n)` | `div:nth-of-type(3)` | n-й элемент указанного типа среди братьев |
| `:not(selector)` | `A:not(B)` | `input:not([disabled])` | Элементы, не соответствующие B |
| `:empty` | `A:empty` | `div:empty` | Элементы без дочерних узлов |
| `:enabled` / `:disabled` | `A:enabled` | `input:enabled` | Активные / заблокированные элементы форм |
| `:checked` | `A:checked` | `input:checked` | Выбранные чекбоксы/радиокнопки |

---

##  Комбинирование селекторов

Можно объединять несколько условий без пробелов (в одном элементе):
```css
input#email.form-control[type='text']
```
Это найдёт `input` с `id="email"`, классом `form-control` и атрибутом `type='text'`.

##  Примеры для разных сценариев

| Что ищем | CSS-селектор |
|----------|--------------|
| Элемент по ID | `#loginBtn` |
| Элемент по классу | `.header` |
| Элемент с классом и тегом | `div.container` |
| Поле ввода с типом text | `input[type='text']` |
| Ссылка с точным href | `a[href='https://example.com']` |
| Ссылка, содержащая 'google' в href | `a[href*='google']` |
| Изображение с расширением .png | `img[src$='.png']` |
| Первая строка таблицы | `table tbody tr:first-child` |
| Все активные чекбоксы | `input[type='checkbox']:checked` |
| Все кнопки, кроме заблокированных | `button:not([disabled])` |
| Все `li` внутри `ul` с классом `menu` | `ul.menu > li` |
| Элемент, следующий за заголовком | `h2 + p` |

##  Использование в Java

```java
import org.openqa.selenium.By;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.WebDriver;

// Поиск одного элемента
WebElement emailField = driver.findElement(By.cssSelector("input[type='email']"));

// Поиск нескольких элементов
List<WebElement> items = driver.findElements(By.cssSelector("ul.nav > li"));

// Сложный селектор с комбинаторами
WebElement activeItem = driver.findElement(By.cssSelector("ul.nav li.active"));
```

##  Сравнение CSS и XPath

| Критерий | CSS | XPath |
|----------|-----|-------|
| Скорость |  Быстрее (оптимизирован браузерами) |  Медленнее |
| Читаемость |  Короткий и понятный синтаксис |  Часто громоздкий |
| Поиск по тексту |  Нет (кроме хакеров через `:contains()`, но не поддерживается) |  `text()`, `contains(text())` |
| Навигация к родителю |  Нет (только от родителя к потомку) |  `parent::`, `ancestor::` |
| Поиск по части атрибута |  `^=`, `$=`, `*=`, `~=` |  `contains()`, `starts-with()` |
| Логические условия |  `:not()`, комбинации без пробелов |  `and`, `or` в предикатах |
| Индексы |  `:nth-child(n)` |  `[n]`, `position()` |
| Кроссбраузерность |  Отлично |  Хорошо (но может быть медленнее в старых IE) |

**Рекомендация:** Используйте CSS везде, где возможно, и переходите на XPath только когда нужен поиск по тексту или навигация к родителю.

##  Проверка CSS-селекторов в браузере

**Chrome / Edge / Firefox:**
1. Открыть DevTools (F12)
2. Вкладка Console
3. Ввести:
   ```javascript
   document.querySelectorAll("input[type='text']")   // вернёт NodeList
   ```
Или в Elements нажать `Ctrl+F` и ввести селектор — браузер подсветит совпадения.

##  Лучшие практики

1. **Отдавайте предпочтение ID** (`#id`) — он самый быстрый и уникальный.
2. **Для классов используйте `.class`** — но помните, что у элемента может быть несколько классов (например, `class="btn primary"`), тогда селектор `.primary` сработает.
3. **Избегайте слишком длинных цепочек** — они замедляют поиск.
4. **Используйте атрибуты `data-*`** — они специально созданы для тестирования.
5. **Для динамических элементов** используйте селекторы по части атрибута (`*=`, `^=`, `$=`).
6. **Не используйте `:nth-child`** если структура может меняться — лучше искать по уникальному атрибуту.
7. **Комбинируйте условия** для повышения точности: `input#email.form-control[type='text']`.

##  Шпаргалка (быстрый поиск)

| Что нужно | CSS-селектор |
|-----------|--------------|
| По ID | `#myId` |
| По классу | `.myClass` |
| По тегу + классу | `div.myClass` |
| По атрибуту | `[name='username']` |
| По части атрибута | `[href*='google']` |
| По началу атрибута | `[href^='https']` |
| По концу атрибута | `[src$='.png']` |
| Прямой потомок | `ul > li` |
| Любой потомок | `ul li` |
| Следующий сосед | `h1 + p` |
| Все последующие соседи | `h1 ~ p` |
| Первый дочерний | `li:first-child` |
| Последний дочерний | `li:last-child` |
| N-й дочерний | `li:nth-child(2)` |
| Не активный | `button:not([disabled])` |
| Отмеченный чекбокс | `input:checked` |

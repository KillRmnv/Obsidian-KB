# HTTP статусы и методы

Справочная таблица HTTP-методов и кодов статусов.

Связанные темы: [[REST API]], [[HTTP сервер]], [[HTTP клиент]]

---

## HTTP методы

| Метод | Использование | Идемпотентность |
|-------|---------------|-----------------|
| GET | Получение данных | Да |
| POST | Создание ресурса | Нет |
| PUT | Полное обновление | Да |
| PATCH | Частичное обновление | Нет |
| DELETE | Удаление | Да |
| HEAD | Только заголовки | Да |
| OPTIONS | Доступные методы | Да |

---

## HTTP статус-коды

| Код | Статус | Описание |
|-----|--------|----------|
| 200 | OK | Успех |
| 201 | Created | Создано |
| 204 | No Content | Успех, нет тела |
| 400 | Bad Request | Ошибка валидации |
| 401 | Unauthorized | Не авторизован |
| 403 | Forbidden | Доступ запрещен |
| 404 | Not Found | Не найдено |
| 500 | Internal Server Error | Ошибка сервера |

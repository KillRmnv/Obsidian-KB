 В Java потоки могут блокировать друг друга несколькими способами:

## 1. Взаимная блокировка (Deadlock)

Два или более потоков блокируются **навсегда**, ожидая друг друга:

java

`// Поток 1 synchronized (objectA) {     synchronized (objectB) { /* ... */ } } // Поток 2 synchronized (objectB) {     synchronized (objectA) { /* ... */ }  // Блокируется, ждёт поток 1 }`

Оба потока ждут освобождения ресурсов, которые удерживает другой — программа зависает.

## 2. Блокировка через `synchronized`

Поток захватывает монитов (блокировку) на объекте, и другие потоки **блокируются**, пытаясь войти в синхронизированный блок:

java

`synchronized (lock) {     // Только один поток здесь, остальные ждут }`

Потоки, ожидающие вход в `synchronized` блок, переходят в состояние **BLOCKED**.

## 3. Блокировка через `wait()` / `notify()`

Поток вызываем `wait()` на объекте и **блокируется**, пока другой поток не вызовет `notify()`/`notifyAll()`.[](https://ru.hexlet.io/qna/java/questions/kak-izbezhat-deadlock-java)

## 4. Блокировка через `Lock` (например, `ReentrantLock`)

java

`lock.lock();  // Если занято — поток блокируется try { /* ... */ } finally { lock.unlock(); }`

Можно использовать `tryLock(timeout)` с таймаутом, чтобы избежать вечной блокировки.[](https://ru.hexlet.io/qna/java/questions/kak-izbezhat-deadlock-java)

## 5. Блокировка ввода-вывода

Поток блокируется при выполнении блокирующего I/O (файлы, сокет) до завершения операции.[](https://www.reddit.com/r/java/comments/1gwblu8/java_24_stops_pinning_virtual_threads_almost/)

## Как избежать deadlock

|Способ|Описание|
|---|---|
|Избегай вложенных блокировок|Всегда блокируй объекты в **одинаковом порядке**[](https://ru.hexlet.io/qna/java/questions/kak-izbezhat-deadlock-java)|
|Используй таймауты|`tryLock(timeout)` — не ждать вечно[](https://ru.hexlet.io/qna/java/questions/kak-izbezhat-deadlock-java)|
|Неблокирующие алгоритмы|`.concurrent` структуры (`ConcurrentHashMap`, `AtomicInteger`)[](https://ru.hexlet.io/qna/java/questions/kak-izbezhat-deadlock-java)|
|Минимизируй синхронизацию|Используй `synchronized` только когда нужно[](https://ru.hexlet.io/qna/java/questions/kak-izbezhat-deadlock-java)|
|Инструменты диагностики|`jstack`, `JConsole` для поиска deadlock[](https://ru.hexlet.io/qna/java/questions/kak-izbezhat-deadlock-java)|

Потоки блокируют друг друга — это не баг, а особенность многопоточности, которую нужно правильно контролировать

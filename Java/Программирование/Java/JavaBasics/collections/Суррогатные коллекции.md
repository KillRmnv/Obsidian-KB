Суррогатные коллекции в Java (в контексте Java Collections Framework) — это специальные реализации коллекций, которые не хранят свои элементы самостоятельно обычным образом, а выступают в роли "оберток" (wrappers) или легковесных заменителей над другими структурами данных. Они создаются с помощью статических фабричных методов утилитарного класса `java.util.Collections`.

Чаще всего такие коллекции используются для защиты данных, оптимизации памяти или обеспечения потокобезопасности.

## Основные виды суррогатных коллекций

## 1. Неизменяемые коллекции (Unmodifiable Wrappers)

Эти коллекции служат оберткой над существующей изменяемой коллекцией. Они перехватывают все попытки модификации (`add`, `remove`, `clear` и т.д.) и выбрасывают исключение `UnsupportedOperationException`, при этом запросы на чтение перенаправляются в оригинальную коллекцию. Это частичная защита при публикации объекта (чтобы тот, кому вы отдали коллекцию, не мог её изменить).

- Примеры методов: `Collections.unmodifiableList(list)`, `Collections.unmodifiableSet(set)`, `Collections.unmodifiableMap(map)`.
    

## 2. Синхронизированные коллекции (Synchronized Wrappers)

Создают потокобезопасную обертку вокруг обычной (не потокобезопасной) коллекции. Все методы в такой суррогатной коллекции синхронизированы по мьютексу (внутреннему замку) перед тем, как делегировать вызов оригинальной коллекции.[](https://arenda-server.cloud/blog/uchebnik-po-kollekcijam-java-spiski-mnozhestva-otobrazhenija/)

- Примеры методов: `Collections.synchronizedList(list)`, `Collections.synchronizedMap(map)`.
    

## 3. Пустые коллекции

Легковесные, иммутабельные (неизменяемые) коллекции, которые не содержат ни одного элемента и не занимают лишнюю память (не создают внутренних массивов или узлов). Полезны, когда метод должен вернуть коллекцию, но возвращать нечего, чтобы избежать возврата `null` (что приводит к `NullPointerException`).[](https://inponomarev.github.io/java-mipt/slides07/)

- Примеры методов: `Collections.emptyList()`, `Collections.emptySet()`, `Collections.emptyMap()`.[](https://inponomarev.github.io/java-mipt/slides07/)
    

## 4. Коллекции из одного элемента (Singletons)

Создают неизменяемую коллекцию, содержащую ровно один указанный элемент. Внутри не используется массив, элемент просто хранится как переменная класса, что очень экономит память.[](https://inponomarev.github.io/java-mipt/slides07/)

- Примеры методов: `Collections.singletonList(item)`, `Collections.singleton(item)`, `Collections.singletonMap(key, value)`

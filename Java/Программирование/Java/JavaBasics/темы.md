Вот полный список тем **Java SE** по блокам:skillbox+2

## 1. [[Основы языка]]

- JVM, JDK, JRE, байт-код, classloader
    
- Типы данных (primitive vs reference), autoboxing/unboxing
    
- Операторы, управляющие конструкции (`if`, `switch`, циклы)
    
- Массивы
    
- Строки: `String`, `StringBuilder`, `StringBuffer`
    

## 2. [[ООП  шпаргалка]]

- Классы, объекты, конструкторы
    
- Наследование, полиморфизм, инкапсуляция, абстракция
    
- `abstract` классы vs интерфейсы
    
- `static`, `final`, `this`, `super`
    
- Блоки инициализации (static / instance)
    
- Вложенные, анонимные, внутренние классы
    
- Enums, Records (Java 16+)
    

## 3. [[Generics]]

- Синтаксис дженериков
    
- Wildcards (`? extends`, `? super`)
    
- Type erasure
    

## 4. [[Исключения]]

- Checked vs Unchecked
    
- `try-catch-finally`, `try-with-resources`
    
- Создание собственных исключений
    

## 5. [[Collections Framework]]

- `List`, `Set`, `Queue`, `Map` — интерфейсы и реализации
    
- `ArrayList`, `LinkedList`, `HashMap`, `TreeMap`, `LinkedHashMap`, `HashSet`, `TreeSet`
    
- `Comparable` vs `Comparator`
    
- `Iterator`, `ListIterator`
    

## 6. [[Функциональное программирование (Java 8+)]]

- Lambda-выражения
    
- Functional interfaces (`Predicate`, `Function`, `Consumer`, `Supplier`)
    
- Stream API
    
- Method references
    
- `Optional`
    

## 7. [[Многопоточность (Concurrency)]]

- `Thread`, `Runnable`, `Callable`
    
- `synchronized`, `volatile`
    
- `wait/notify`
    
- `java.util.concurrent`: `ExecutorService`, `Future`, `locks`
    
- Атомарные классы (`AtomicInteger` и др.)
    
- `ThreadLocal`
    
- Проблемы: deadlock, starvation, race condition
    

## 8. [[Память и JVM]]

- Stack vs Heap
    
- Garbage Collector (GC): алгоритмы, поколения
    
- `equals` / `hashCode` контракт
    
- `==` vs `equals`
    
- String pool
    

## 9. [[I/O]]

- Байтовые и символьные потоки
    
- `InputStream`, `OutputStream`, `Reader`, `Writer`
    
- NIO / NIO.2 (`Path`, `Files`, `Channels`)
    
- Сериализация (`Serializable`, `transient`)
    

## 10. [[Рефлексия и аннотации]]

- `Class`, `Method`, `Field`
    
- Создание объектов через рефлексию
    
- Аннотации: встроенные и пользовательские
    

## 11. [[Новые фичи (Java 8–21)]]

- `var` (Java 10)
    
- Records (Java 16)
    
- Sealed classes (Java 17)
    
- Pattern matching (`instanceof`)
    
- Text blocks
    
- Virtual threads (Java 21)

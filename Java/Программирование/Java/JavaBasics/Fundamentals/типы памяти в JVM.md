1. **Heap (куча)**
    
    - Общая область для всех потоков.
        
    - Здесь живут **все объекты и массивы**, созданные через `new`.topjava+2
        
    - Управляется сборщиком мусора (GC): когда объект становится недостижимым, его память может быть освобождена.habr+1
        
2. **Stack (стек потоков)**
    
    - У **каждого потока** свой собственный стек.javarush+1
        
    - В каждом стеке хранятся **кадры вызовов методов**: локальные переменные, параметры, адрес возврата, промежуточные данные.javarush+1
        
    - Размер стека ограничен; переполнение приводит к `StackOverflowError`.
        
3. **Method Area / Metaspace**
    
    - Область для **метаданных классов**: структуры классов, пул констант, статические поля, байткод методов.arenda-server+1
        
    - Начиная с Java 8, реализация HotSpot хранит её в нативной памяти как **Metaspace**, заменив старый PermGen.proselyte+2
        
4. **Native Method Stack (стек нативных методов)**
    
    - Отдельные стеки для вызовов нативного кода (через JNI и т.п.).arenda-server+1
        
5. **Прочая non‑heap / native memory**
    
    - Буферы (NIO direct buffers), кэш JIT‑скомпилированного кода, структуры GC, интернированные строки и т.п..habr+1

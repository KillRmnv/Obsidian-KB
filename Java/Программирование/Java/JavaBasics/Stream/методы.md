Вот структурированная шпаргалка по методам Java Stream API. Методы разделены на две основные категории: **промежуточные** (возвращают новый `Stream` и выполняются лениво) и **терминальные** (запускают вычисление и возвращают результат).[devmark](https://devmark.ru/article/stream-api-intermediate-opers)

## Промежуточные операции (Intermediate Operations)

Эти методы не выполняются до тех пор, пока не будет вызвана терминальная операция.[devmark](https://devmark.ru/article/stream-api-intermediate-opers)

|Метод|Описание|Требования и нюансы|
|---|---|---|
|**`filter(Predicate<T>)`**|Отсеивает элементы, не удовлетворяющие условию [devmark](https://devmark.ru/article/stream-api-intermediate-opers).|Требует лямбду, возвращающую `boolean`. Исходные объекты не изменяются.|
|**`map(Function<T, R>)`**|Преобразует каждый элемент в другой объект/тип [devmark](https://devmark.ru/article/stream-api-intermediate-opers).|Возвращает стрим нового типа `R`. Требует функцию, принимающую `T` и возвращающую `R`.|
|**`flatMap(Function<T, Stream<R>>)`**|Преобразует каждый элемент в стрим, а затем "сплющивает" все стримы в один.|Функция должна возвращать именно объект типа `Stream`. Часто используется для "разворачивания" вложенных коллекций (например, `List<List<T>>` в `Stream<T>`).|
|**`distinct()`**|Убирает дубликаты из стрима [devmark](https://devmark.ru/article/stream-api-intermediate-opers).|Элементы стрима должны корректно переопределять методы `equals()` и `hashCode()` [devmark](https://devmark.ru/article/stream-api-intermediate-opers).|
|**`sorted()`**|Сортирует элементы в естественном порядке [devmark](https://devmark.ru/article/stream-api-intermediate-opers).|Элементы стрима **обязаны** реализовывать интерфейс `Comparable`. В противном случае при выполнении выбросится `ClassCastException` [devmark](https://devmark.ru/article/stream-api-intermediate-opers).|
|**`sorted(Comparator<T>)`**|Сортирует по заданному правилу [devmark](https://devmark.ru/article/stream-api-intermediate-opers).|Требуется передать компаратор. Интерфейс `Comparable` у элементов не обязателен.|
|**`peek(Consumer<T>)`**|Выполняет действие над каждым элементом, ничего не меняя [devmark](https://devmark.ru/article/stream-api-intermediate-opers).|Предназначен в основном для отладки (логирования). Нельзя изменять состояние элементов, если они немутабельны.|
|**`limit(long n)`**|Оставляет только первые `n` элементов [devmark](https://devmark.ru/article/stream-api-intermediate-opers).|Передаваемое число `n` не может быть отрицательным. Метод short-circuiting (может завершить бесконечный стрим).|
|**`skip(long n)`**|Пропускает первые `n` элементов [devmark](https://devmark.ru/article/stream-api-intermediate-opers).|Передаваемое число `n` не может быть отрицательным. Если `n` больше размера стрима, возвращается пустой стрим.|
|**`takeWhile(Predicate<T>)`** _(Java 9)_|Берет элементы, пока условие истинно. Как только ложно — обрывает стрим.|Для неупорядоченных стримов результат недетерминирован.|
|**`dropWhile(Predicate<T>)`** _(Java 9)_|Пропускает элементы, пока условие истинно. Как только ложно — берет все оставшиеся.|Аналогично, для неупорядоченных стримов результат непредсказуем.|

## Терминальные операции (Terminal Operations)

Завершают цепочку вызовов, после их выполнения стрим "закрывается" и больше недоступен для использования.

|Метод|Описание|Требования и нюансы|
|---|---|---|

|Метод|Описание|Требования и нюансы|
|---|---|---|
|**`forEach(Consumer<T>)`**|Выполняет действие для каждого элемента.|Не гарантирует порядок выполнения при параллельных стримах. Для гарантии порядка используйте `forEachOrdered()`.|
|**`collect(Collector)`**|Собирает элементы в коллекцию (List, Set, Map) или строку.|Чаще всего используются статические фабричные методы класса `Collectors` (например, `Collectors.toList()`, `Collectors.groupingBy()`).|
|**`toArray()`**|Возвращает массив `Object[]`.|Для получения типизированного массива нужно передать генератор: `.toArray(String[]::new)`.|
|**`reduce(BinaryOperator<T>)`**|Аккумулирует элементы, сводя их к одному значению (например, сумма всех чисел).|Операция (функция) должна быть ассоциативной (т.е. `(a+b)+c == a+(b+c)`). Возвращает `Optional`.|
|**`min(Comparator<T>)` / `max(Comparator<T>)`**|Ищет минимальный/максимальный элемент.|Обязательно требует `Comparator`, даже если элементы реализуют `Comparable`. Возвращает `Optional`.|
|**`count()`**|Возвращает количество элементов в стриме.|Тип возвращаемого значения — `long`.|
|**`anyMatch(Predicate<T>)`**|Вернет `true`, если **хотя бы один** элемент удовлетворяет условию.|Short-circuiting: прерывает обход стрима, как только найдет первое совпадение.|
|**`allMatch(Predicate<T>)`**|Вернет `true`, если **все** элементы удовлетворяют условию.|Short-circuiting: прерывает обход стрима, как только найдет первое несовпадение. Для пустого стрима всегда вернет `true`.|
|**`noneMatch(Predicate<T>)`**|Вернет `true`, если **ни один** элемент не удовлетворяет условию.|Short-circuiting: прерывает обход на первом совпадении. Для пустого стрима всегда вернет `true`.|
|**`findFirst()`**|Возвращает первый элемент стрима.|Возвращает `Optional`. Часто используется после `filter`.|
|**`findAny()`**|Возвращает любой подходящий элемент.|Возвращает `Optional`. В последовательном стриме работает как `findFirst()`, но в параллельных (`parallelStream()`) возвращает первый попавшийся поток для увеличения производительности.|

## Базовые стримы примитивов

Помимо стандартного `Stream<T>`, в Java есть оптимизированные стримы для примитивов: **`IntStream`**, **`LongStream`** и **`DoubleStream`**. Они позволяют избежать накладных расходов на автоупаковку (autoboxing).

- **Как получить:** из обычного стрима с помощью `mapToInt()`, `mapToLong()`, `mapToDouble()`.
    
- **Особые методы:** в примитивных стримах есть методы, которых нет в обычном `Stream<T>` — например, `sum()`, `average()`, `summaryStatistics()`.

Имя бина в Spring может быть задано **явно** (через атрибуты аннотаций или XML) или сгенерировано **автоматически** на основе соглашений. Правила генерации зависят от способа объявления бина.

### 1. Стереотипные аннотации (`@Component`, `@Service`, `@Repository`, `@Controller` и др.)

- **Явное имя:** указывается в скобках аннотации, например:  
  `@Component("myCustomName")` → имя бина `"myCustomName"`.
- **Автоматически (по умолчанию):** если значение не задано, Spring берёт **простое имя класса** и делает первую букву строчной (decapitalize).  
  Пример: класс `MyService` → бин с именем `"myService"`.  
  Не зависит от имени метода, потому что методы здесь не участвуют.

### 2. Аннотация `@Bean` в Java-конфигурации

- **Явное имя:** задаётся через атрибут `name` или `value`:  
  `@Bean(name = "explicitName")` или `@Bean("explicitName")`.
- **По умолчанию:** если имя не указано, **имя бина = имя метода**, на котором стоит `@Bean`.  
  ```java
  @Bean
  public DataSource myDataSource() { ... }
  ```
  Бин получит имя `"myDataSource"`.

### 3. XML-конфигурация (`<bean>`)

- **Явное имя:** через атрибуты `id` или `name`:  
  `<bean id="myBean" class="..."/>` → имя `"myBean"`.  
  Можно указать несколько псевдонимов через `name="alias1,alias2"`.
- **Автоматически:** если ни `id`, ни `name` не заданы, Spring генерирует имя по схеме: полное имя класса + `#` + порядковый номер, например `"com.example.MyBean#0"`. На практике так почти не делают.

### Важное различие

- Для `@Bean` источником имени по умолчанию служит **метод**.
- Для `@Component` (и производных) источником имени служит **класс**.
- В обоих случаях явное указание в аннотации перекрывает поведение по умолчанию.
- В XML имя всегда задаётся явно (предпочтительно через `id`), иначе генерируется техническое имя.

**Пример комбинации:**  
```java
@Configuration
public class AppConfig {
    @Bean("customName")
    public MyBean someMethod() {
        return new MyBean();
    }
}
```
Бин будет зарегистрирован с именем `"customName"`, а не `"someMethod"`.

Таким образом, ваш тезис верен: имя берётся **либо из явного указания** (в поле аннотации или атрибуте XML), **либо из названия метода** (только в случае `@Bean` без явного имени). Для стереотипных аннотаций без явного имени используется имя класса.

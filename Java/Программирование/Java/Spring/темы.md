## 4. Spring MVC (базово)

- Архитектура: `DispatcherServlet` как фронт‑контроллер, `HandlerMapping`, `Controller`, `ViewResolver`.github+1
    
- Основные аннотации: `@Controller`, `@RestController`, `@RequestMapping`/`@GetMapping`/`@PostMapping`, `@PathVariable`, `@RequestParam`, `@RequestBody`, `@ResponseBody`.github+1
    
- Обработка ошибок: `@ExceptionHandler`, `@ControllerAdvice`, статус коды.javastudy+1
    

Spring vs сервлеты: Spring MVC поверх Servlet API; `DispatcherServlet` сам мапится как один сервлет, далее роутит на контроллеры.

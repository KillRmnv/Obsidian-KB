Вот аналогичный structured-список тем для **C++ Core / Modern C++**, сопоставимый по полноте и глубине с вашим Java-перечнем:

  

1. **[[Основы языка и компиляция C++]]**
    

- Процесс сборки: Препроцессинг, Компиляция, Линковка (Translation Units, `include`, `define`, `pragma once`)
    
      
    
- Фундаментальные типы, квалификаторы (`const`, `volatile`, `constexpr`, `consteval`, `constinit`)
    
      
    
- Указатели, ссылки (`&`), lvalue/rvalue, ссылки на rvalue (`&&`)
    
      
    
- Операторы, область видимости (`namespaces`), преобразования типов (`static_cast`, `dynamic_cast`, `reinterpret_cast`, `const_cast`)
    
      
    
- Массивы (C-style) и c-strings (`const char*`)
    
      
    

2. **[[Объектно-ориентированное программирование (ООП) C++]]**
    
      
    

- Классы, структуры (`struct` vs `class`), доступ (`public`, `protected`, `private`)
    
      
    
- Конструкторы (по умолчанию, копирования, перемещения, explicit), деструктор
    
      
    
- `rule of 0 / 3 / 5` (Правило ноля / трех / пяти)
    
      
    
- Наследование, виртуальные функции, Таблица виртуальных функций (`vtable` / `vptr`), чисто виртуальные функции, интерфейсы
    
      
    
- Перегрузка операторов, ключевые слова `override`, `final`, `mutable`, `friend`
    
      
    

3. **[[Шаблоны и обобщенное программирование (Templates) C++]]**
    
      
    

- Шаблоны функций и классов, специализация (полная и частичная)
    
      
    
- `SFINAE` (`std::enable_if`), `type_traits`
    
      
    
- Variadic templates (шаблоны с переменным числом аргументов), fold expressions
    
      
    
- Concepts и Constraints (C++20)
    
      
    

4. **[[Обработка ошибок и исключения C++]]**
    
      
    

- Механизм исключений (`try`, `catch`, `throw`), гарантии безопасности исключений
    
      
    
- `noexcept` спецификатор и его влияние на оптимизацию
    
      
    
- Альтернативы исключениям: `std::optional`, `std::variant`, `std::expected` (C++23)
    
      
    

5. **[[Стандартная библиотека шаблонов (STL)  Контейнеры и итераторы]]**
    
      
    

- Последовательные контейнеры: `std::vector`, `std::array`, `std::deque`, `std::list`, `std::forward_list`
    
      
    
- Ассоциативные контейнеры: `std::map`, `std::set`, `std::multimap`, `std::multiset` (Red-Black Trees)
    
      
    
- Неупорядоченные контейнеры: `std::unordered_map`, `std::unordered_set` (Hash tables)
    
      
    
- Итераторы: категории итераторов, invalidated iterators rules
    
      
    

6. **[[STL  Алгоритмы и Функциональные возможности]]**
    
      
    

- Стандартные алгоритмы (`<algorithm>`, `<numeric>`)
    
      
    
- Лямбда-выражения (захват по ссылке/значению, `mutable`, шаблоны в лямбдах)
    
      
    
- `std::function`, `std::bind`, `std::invoke`
    
      
    
- Ranges library (C++20)
    
      
    

7. **[[Управление памятью и RAII]]**
    
      
    

- RAII (Resource Acquisition Is Initialization) — базовый паттерн C++
    
      
    
- Ручное управление: `new` / `delete`, `placement new`, выравнивание (`alignof`, `alignas`)
    
      
    
- Умные указатели: `std::unique_ptr`, `std::shared_ptr`, `std::weak_ptr` (устройство, `control block`)
    
      
    
- Move-семантика: `std::move`, `std::forward`, Perfect Forwarding
    
      
    

8. **[[Многопоточность и асинхронность (Concurrency) C++]]**
    
      
    

- Управление потоками: `std::thread`, `std::jthread` (C++20)
    
      
    
- Синхронизация: `std::mutex`, `std::lock_guard`, `std::unique_lock`, `std::scoped_lock`, `std::condition_variable`
    
      
    
- Атомарные операции (`std::atomic`), модели памяти и упорядочивание (`memory_order`)
    
      
    
- Асинхронные задачи: `std::async`, `std::future`, `std::promise`, `std::packaged_task`
    
      
    
- Проблемы: Deadlock, Race Condition, Data Race
    
      
    

9. **[[Модель памяти и низкоуровневое устройство C++]]**
    
      
    

- Сегменты памяти: Stack, Heap, BSS, Data, Text
    
      
    
- UB (Undefined Behavior), Unspecified Behavior, Implementation-defined Behavior
    
      
    
- `std::string_view` и `std::span` (невладеющие представления)
    
      
    
- `std::allocator` и пользовательские аллокаторы
    
      
    

10. **Эволюция C++ (C++11 — C++23)**
    
      
    

- **C++11/14:** `auto`, `decltype`, range-based `for`, `nullptr`, `enum class`
    
      
    
- **C++17:** Structured binding, `if/switch` с инициализацией, `std::filesystem`
    
      
    
- **C++20:** Concepts, Coroutines, Modules (`import`), Ranges, `std::format`
    
      
    
- **C++23:** `std::expected`, `deducing this`, multidimensional subscript (`operator[]`)

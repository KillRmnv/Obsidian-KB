Базовые команды для диагностики сети.

| Команда                     | Назначение                                     |
| --------------------------- | ---------------------------------------------- |
| `ip a`                      | Просмотр сетевых интерфейсов (вместо ifconfig) |
| `ip link`                   | Список сетевых интерфейсов                     |
| `ip route`                  | Таблица маршрутизации                          |
| `ping <адрес>`              | Проверка доступности хоста                     |
| `curl <url>` / `wget <url>` | Загрузка данных из сети                        |
| `ssh <пользователь>@<хост>` | Удалённый доступ                               |
| `scp` / `rsync`             | Копирование файлов между системами             |
| `netstat -tulpn`            | Просмотр открытых портов                       |
| `ss -tulpn`                 | Современная альтернатива netstat               |
| `dig` / `nslookup`          | DNS-запросы                                    |

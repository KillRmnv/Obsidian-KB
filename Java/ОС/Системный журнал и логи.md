Понимание логов помогает диагностировать проблемы.

|Команда|Назначение|
|---|---|
|`journalctl`|Просмотр логов systemd|
|`journalctl -xe`|Логи с пояснениями (для отладки)|
|`journalctl -f`|Живой просмотр логов (как tail -f)|
|`journalctl -u <служба>`|Логи конкретной службы|
|`dmesg`|Логи ядра (сообщения из буфера ядра)|
|`/var/log/`|Директория с логами (syslog, auth.log)|
|`tail -f /var/log/syslog`|Живой просмотр системного лога|

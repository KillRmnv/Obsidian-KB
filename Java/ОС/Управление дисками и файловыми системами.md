Для работы с дисками и разделами.

| Команда                                      | Назначение                           |
| -------------------------------------------- | ------------------------------------ |
| `lsblk`                                      | Просмотр блочных устройств (дисков)  |
| `fdisk -l`                                   | Информация о разделах                |
| `df -h`                                      | Использование дискового пространства |
| `du -sh <папка>`                             | Размер папки                         |
| `mount <устройство> <точка_монтирования>`    | Примонтировать устройство            |
| `umount <точка_монтирования>`                | Отмонтировать устройство             |
| `blkid`                                      | Просмотр UUID устройств              |
| `/etc/fstab`                                 | Файл с настройками монтирования      |
| `mkfs.ext4 <устройство>`                     | Создать файловую систему ext4        |
| `fsck <устройство>`                          | Проверка файловой системы            |
| `mount -o loop <образ> <точка_монтирования>` | Примонтировать ISO-образ             |

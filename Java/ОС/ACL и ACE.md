## Определения

**ACL (Access Control List)** — список управления доступом, прикрепляемый к защищаемому объекту (файлу, папке, процессу и т.д.). Содержит все правила доступа к объекту.

**ACE (Access Control Entry)** — отдельная запись (элемент) внутри ACL. Одна ACE содержит:
- **SID (Security Identifier)** — идентификатор субъекта (пользователя, группы), к которому применяется правило
- **Access Mask** — набор прав доступа (разрешение, запрет, аудит)

Соотношение: **ACL — это список, ACE — один пункт в этом списке**.

---

## Типы ACL в Windows

У объекта может быть два типа ACL:

| Тип | Назначение |
|-----|------------|
| **DACL (Discretionary ACL)** | Определяет, какие пользователи/группы имеют доступ к объекту (разрешает или запрещает). Основной список для принятия решения о доступе. |
| **SACL (System ACL)** | Определяет, какие попытки доступа нужно записывать в журнал аудита (например, неудачные попытки входа). |

---

## Типы ACE в Windows

Шесть основных типов ACE, три из которых базовые:

| Тип ACE | Назначение | Размещение |
|---------|------------|------------|
| **Access-Denied ACE** | Запрещает указанные права доступа субъекту | DACL |
| **Access-Allowed ACE** | Разрешает указанные права доступа субъекту | DACL |
| **System-Audit ACE** | Генерирует запись в журнале безопасности при попытке выполнения действий | SACL |

Дополнительно существуют:
- **Объектно-зависимые ACE** — используются в службах каталогов (Active Directory)
- **Условные ACE** — проверяют динамические условия перед предоставлением доступа

---

## Алгоритм проверки доступа

1. Система анализирует DACL объекта
2. ACE проверяются последовательно, сверху вниз
3. Если найдено правило **запрета** — доступ немедленно отклоняется (даже если ниже есть разрешающее правило)
4. Если найдено правило **разрешения** — доступ предоставляется
5. Принцип: "сначала запреты, потом разрешения"

Особые случаи:
- Если у объекта нет DACL → система предоставляет полный доступ всем
- Если DACL существует, но не содержит ACE → доступ запрещён для всех

## ACL в сетевых устройствах (Cisco)

В сетевом оборудовании ACL используются как фильтры сетевого трафика. Каждая ACE (правило) описывает:
- Условия: IP-адрес источника, порт назначения и т.д.
- Действие: разрешить или запретить прохождение пакета

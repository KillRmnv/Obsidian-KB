Контроль за запущенными программами.

|Команда|Назначение|
|---|---|
|`ps aux`|Список всех процессов|
|`ps -ef`|Альтернативный формат вывода|
|`top` / `htop`|Интерактивный мониторинг процессов|
|`kill <PID>`|Завершить процесс|
|`kill -9 <PID>`|Принудительно завершить процесс|
|`pkill <имя>`|Завершить процесс по имени|
|`killall <имя>`|Завершить все процессы с указанным именем|
|`jobs`|Список фоновых задач|
|`fg`|Вернуть задачу в foreground|
|`bg`|Переместить задачу в background|
|`&`|Запустить процесс в фоне|
|`Ctrl+Z`|Приостановить процесс|
|`Ctrl+C`|Прервать процесс|
|`nohup`|Запустить процесс, устойчивый к завершению сессии|
|`screen` / `tmux`|Мультиплексоры терминалов|

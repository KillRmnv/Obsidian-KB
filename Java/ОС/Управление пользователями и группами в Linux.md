## Основные файлы

Информация о пользователях и группах хранится в системных файлах:

| Файл | Назначение |
|------|------------|
| `/etc/passwd` | Список пользователей (логин, UID, GID, домашняя директория, оболочка) |
| `/etc/shadow` | Хеши паролей пользователей (доступен только root) |
| `/etc/group` | Список групп и их членов |
| `/etc/gshadow` | Хеши паролей групп (доступен только root) |

## Работа с группами

### Просмотр информации

| Команда | Назначение |
|---------|------------|
| `groups` | Показать группы текущего пользователя |
| `groups <имя_пользователя>` | Показать группы указанного пользователя |
| `cat /etc/group` | Просмотреть все группы системы |
| `getent group <имя_группы>` | Получить информацию о конкретной группе |
| `id <имя_пользователя>` | Показать UID, GID и все группы пользователя |

### Создание и удаление групп

| Команда | Назначение | Пример |
|---------|------------|--------|
| `groupadd <имя_группы>` | Создать новую группу | `sudo groupadd group_iit1` |
| `groupdel <имя_группы>` | Удалить группу | `sudo groupdel group_iit1` |

### Изменение группы

| Команда | Назначение |
|---------|------------|
| `groupmod -n <новое_имя> <старое_имя>` | Переименовать группу |
| `groupmod -g <новый_GID> <имя_группы>` | Изменить GID группы |

## Работа с пользователями

### Просмотр информации

| Команда | Назначение |
|---------|------------|
| `whoami` | Показать имя текущего пользователя |
| `who` | Показать активных пользователей |
| `cat /etc/passwd` | Просмотреть всех пользователей системы |
| `getent passwd <имя_пользователя>` | Получить информацию о конкретном пользователе |

### Создание и удаление пользователей

| Команда | Назначение | Пример |
|---------|------------|--------|
| `useradd <имя>` | Создать пользователя | `sudo useradd iit11` |
| `useradd -m <имя>` | Создать пользователя с домашней директорией | `sudo useradd -m iit12` |
| `useradd -G <группа> <имя>` | Создать пользователя и добавить в группу | `sudo useradd -G group_iit1 iit11` |
| `useradd -s /bin/bash <имя>` | Создать пользователя с указанной оболочкой | `sudo useradd -s /bin/bash iit11` |
| `userdel <имя>` | Удалить пользователя | `sudo userdel iit11` |
| `userdel -r <имя>` | Удалить пользователя и его домашнюю директорию | `sudo userdel -r iit11` |

### Изменение пользователя

| Команда | Назначение |
|---------|------------|
| `passwd <имя>` | Установить/изменить пароль пользователя |
| `usermod -aG <группа> <имя>` | Добавить пользователя в группу (append) |
| `usermod -G <группа1,группа2> <имя>` | Заменить все группы пользователя на указанные |
| `usermod -l <новое_имя> <старое_имя>` | Переименовать пользователя |
| `usermod -d /новый/путь <имя>` | Изменить домашнюю директорию |
| `usermod -s /bin/zsh <имя>` | Изменить оболочку пользователя |

## Управление членством в группах

| Команда | Назначение | Пример |
|---------|------------|--------|
| `usermod -aG <группа> <пользователь>` | Добавить пользователя в группу | `sudo usermod -aG group_iit1 iit11` |
| `gpasswd -d <пользователь> <группа>` | Удалить пользователя из группы | `sudo gpasswd -d iit11 group_iit1` |
| `gpasswd -M <пользователь1,пользователь2> <группа>` | Установить список членов группы | `sudo gpasswd -M iit11,iit12 group_iit1` |

## Предоставление административных привилегий

### Добавление пользователя в группу wheel (администраторы)

```bash
sudo usermod -aG wheel <имя_пользователя>
```

После этого пользователь сможет выполнять команды через `sudo`.

### Настройка sudo (если не работает)

1. Открыть файл `sudoers`:
   ```bash
   sudo visudo
   ```

2. Найти и раскомментировать строку для группы `wheel`:
   ```
   %wheel ALL=(ALL) ALL
   ```

3. Сохранить и выйти.

## Проверка эффективных прав

Для проверки, как система видит права пользователя после всех изменений, используйте:

```bash
# Текущий пользователь
id

# Конкретный пользователь
id iit11

# Только группы
groups iit11
```

## Переключение между пользователями

Для тестирования доступа от лица разных пользователей:

| Команда | Назначение |
|---------|------------|
| `su - <имя_пользователя>` | Переключиться на другого пользователя (требуется пароль) |
| `sudo -u <имя_пользователя> <команда>` | Выполнить команду от имени другого пользователя |
| `sudo su - <имя_пользователя>` | Переключиться на другого пользователя через sudo |

## Пример для лабораторной работы

```bash
# 1. Создать группы
sudo groupadd group_iit1
sudo groupadd group_iit2

# 2. Создать пользователей
sudo useradd -m -G group_iit1 -s /bin/bash iit11
sudo useradd -m -G group_iit1 -s /bin/bash iit12
sudo useradd -m -G group_iit2 -s /bin/bash iit21
sudo useradd -m -G group_iit2 -s /bin/bash iit22
sudo useradd -m -s /bin/bash iit3

# 3. Предоставить iit21 административные привилегии
sudo usermod -aG wheel iit21

# 4. Проверить
id iit11
groups iit21

# 5. Для удаления в конце работы
sudo userdel -r iit11
sudo userdel -r iit12
sudo userdel -r iit21
sudo userdel -r iit22
sudo userdel -r iit3
sudo groupdel group_iit1
sudo groupdel group_iit2
```

## Типичные ошибки

| Ошибка | Решение |
|--------|---------|
| `useradd: Permission denied` | Нужно использовать `sudo` |
| `useradd: user 'iit11' already exists` | Пользователь уже существует — удалите его или пропустите создание |
| `groupadd: group 'group_iit1' exists` | Группа уже существует — удалите её или пропустите создание |
| `usermod: group 'wheel' does not exist` | Группа wheel отсутствует — создайте её или используйте другую группу для sudo |
| `Cannot lock /etc/passwd` | Нет прав на запись системных файлов — используйте `sudo` |

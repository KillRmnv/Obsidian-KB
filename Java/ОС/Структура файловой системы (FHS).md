Понимание иерархии каталогов — основа навигации.

|Каталог|Назначение|
|---|---|
|`/`|Корневой каталог, вершина иерархии|
|`/bin`|Базовые системные утилиты (ls, cp, mv)|
|`/sbin`|Системные утилиты для администрирования (fdisk, mkfs)|
|`/etc`|Конфигурационные файлы системы и служб|
|`/home`|Домашние директории пользователей|
|`/var`|Данные, которые часто меняются (логи, кэши)|
|`/tmp`|Временные файлы (очищается при перезагрузке)|
|`/usr`|Пользовательские программы и библиотеки|
|`/usr/bin`|Большинство исполняемых программ|
|`/proc`|Виртуальная файловая система с информацией о процессах|
|`/dev`|Файлы устройств (диски, терминалы)|
|`/boot`|Загрузочные файлы (ядро, initramfs)|
|`/opt`|Дополнительное ПО (сторонние приложения)|
|`/mnt` / `/media`|Точки монтирования внешних устройств|

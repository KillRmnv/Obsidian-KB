Управление окружением.

|Команда|Назначение|
|---|---|
|`env`|Показать все переменные окружения|
|`echo $PATH`|Показать содержимое переменной PATH|
|`export PATH=$PATH:/новый/путь`|Добавить каталог в PATH (временное)|
|`export ПЕРЕМЕННАЯ=значение`|Создать переменную окружения|
|`unset ПЕРЕМЕННАЯ`|Удалить переменную окружения|
|`/etc/environment`, `~/.bashrc`, `~/.profile`|Места для постоянных переменных|
|`source ~/.bashrc`|Применить изменения в bashrc без перезагрузки|

- **Один экземпляр сервлета**
    
    - Контейнер обычно создаёт **один объект** сервлета на объявление (на mapping) и использует его для обработки всех запросов.proselyte+3
        
    - `init()` и `destroy()` вызываются ровно один раз за жизненный цикл этого экземпляра.jsehelper.blogspot+1
        
- **Новый поток и новые Request/Response на каждый запрос**
    
    - На каждый HTTP‑запрос контейнер создаёт **отдельный поток** и новые объекты `HttpServletRequest` и `HttpServletResponse`.java-ru-blog.blogspot+3
        
    - Для каждого запроса вызывается `service()` → `doGet`/`doPost` этого же сервлета в отдельном потоке.coderlessons+2
        

Из этого следует ключевой момент собеседования:

> Один инстанс сервлета обслуживает множество запросов **одновременно в разных потоках**, поэтому нельзя хранить request‑специфичные данные в полях сервлета и нужно внимательно относиться к потокобезопасности.javarush+4

Хорошая фраза:

> Поля сервлета — общие для всех потоков, локальные переменные внутри `doGet`/`doPost` — потокобезопасны, т.к. живут в стеке конкретного потока.
